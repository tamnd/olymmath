Given $n(n \geqslant 5)$ distinct real numbers $a_{1}<a_{2}<\cdots<a_{n}$, all the $\frac{1}{2} n(n-1)$ sums $a_{i} + a_{j}(1 \leqslant i, j \leqslant n, i \neq j)$ are distinct if and only if $a_{1}, a_{2}, \cdots, a_{n}$ form an arithmetic sequence.

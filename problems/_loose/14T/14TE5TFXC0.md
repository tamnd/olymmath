Let $A$ be a set of positive integer $n$-tuples. An $n$-tuple $\left(a_{1}, a_{2}, \ldots, a_{n}\right)$ in the set is called minimal if there is no other distinct $\left(b_{1}, b_{2}, \ldots, b_{n}\right)$ in the set such that $b_{i} \leq a_{i}(1 \leq i \leq n)$. Prove that the set has only finitely many minimal elements.

In a number system with a base of 50, the square of any integer whose last digit is 25 or 26 ends with the same digit as the base, for example:

$$
\left({ }^{50)} 25\right)^{2}=12 \cdot 50+25
$$

Is there any other number that, when used as the base of a number system, has a case where the last digit of the base and its square are the same, and this last digit is neither 0 nor 1?

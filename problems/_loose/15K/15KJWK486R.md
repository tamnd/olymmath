For $n=1,2,3$, we will call a number of type $n$ any number that is either equal to 0, or belongs to the infinite geometric progression

1, $(n+2),(n+2)^{2}, \ldots$, or is the sum of several different terms of this progression. Prove that any natural number can be represented as the sum of a number of the first type, a number of the second type, and a number of the third type.

On an $n \cdot n$ chessboard (uncolored) $(n \geq 3)$, leaving all the squares of the $n$-th row and the $n$-th column, as well as the first square of the first row, empty, write a number of your choice on each of the other squares. Prove that it is possible to write a number on each of the empty squares so that the sum of the numbers in each row, each column, and both diagonals is the same. How many ways can this be done? Which of the originally written numbers does the constant sum depend on, which does the value of the numbers in the corner squares depend on, and which does the sum of the inner (i.e., non-corner) numbers in the $n$-th row and the $n$-th column depend on? Interpret the results for the cases $n=3,4$ separately.

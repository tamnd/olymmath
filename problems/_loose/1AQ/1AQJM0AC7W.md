The eighty-sixth question: Given several rectangular boxes, whose edge lengths are positive integers not greater than an odd positive integer $\mathrm{n}$ (allowing the three edge lengths to be the same), and the thickness of the box walls is negligible, each box has three pairs of opposite faces painted in red, yellow, and blue, respectively. If no box can be placed into another box with the same colored faces parallel, then these boxes are called "harmonious." Find the maximum number of harmonious boxes.

A number $A$ is written with $2n$ digits, each of which is $4$, and a number $B$ is written with $n$ digits, each of which is $8$. Prove that for each $n$, $A + 2B + 4$ is a perfect square.

Problem:
Un număr $A$ este scris cu $2n$ cifre, fiecare dintre acestea fiind $4$; un număr $B$ este scris cu $n$ cifre, fiecare dintre acestea fiind $8$. Demonstrați că, pentru orice $n$, $A + 2B + 4$ este pătrat perfect.

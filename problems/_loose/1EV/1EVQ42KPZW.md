A numerical set $M$, containing 2003 different positive numbers, is such that for any three different elements $a, b, c$ from $M$, the number $a 2+b c$ is rational. Prove that one can choose a natural number $n$ such that for any $a$ from $M$, the number $a \sqrt{n}$ is rational.

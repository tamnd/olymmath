For the function $f(x)(x \in D)$, if it simultaneously satisfies the following conditions:
A. $f(x)$ is monotonically increasing or monotonically decreasing on $D$;
B. There exists an interval $[a, b] \subseteq D$ such that the range of $f(x)$ on $[a, b]$ is $[a, b]$, then the function $f(x)(x \in D)$ is called a closed function.
(1) Find the interval $[a, b]$ that satisfies condition B for the closed function $y=-x^{3}$;
(2) Determine whether the function $y=2 x-\lg x$ is a closed function. If it is, provide the reason and find the interval $[a, b]$; if not, explain the reason;
(3) If $y=k+\sqrt{x+2}$ is a closed function, find the range of real numbers $k$.

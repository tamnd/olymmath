Several guys are standing in a circle. Each has a certain number of candies. Initially, each has an even number of candies. On command, each gives half of their candies to the person on their right. If after this, someone ends up with an odd number of candies, one candy is added from outside. This is repeated many times. Prove that there will come a time when everyone has the same number of candies.

The set A satisfies the following conditions:

(a) $A \subseteq\{1,2,3, \ldots, 100\}$;

(b) $|A|=50$;

(c) If $a_{i}$ and $a_{j}$ are elements of $A$, then $a_{i}+a_{j} \neq 100$.

Prove that $A$ contains an element that is a perfect square.

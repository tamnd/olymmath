(Teacher Hu Shengsen adapted from the 26th IMO Preliminary Problem) There are $m$ boxes, each containing some balls. Each time, one ball is added to each of $n (n < m)$ boxes. Prove: When $(m, n) = 1$, regardless of the initial distribution, it is always possible to add balls in the above manner a finite number of times so that the number of balls in each box is equal.

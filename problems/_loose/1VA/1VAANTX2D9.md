113 If a number can be decomposed into the product of $k$ consecutive natural numbers greater than 1, then we say this number has property $p(k)$.
(1) Find a number $k$, for which there exists a number $N$ that simultaneously has properties $p(k)$ and $p(k+2)$.
(2) Prove: A number that simultaneously has properties $p(2)$ and $p(4)$ does not exist.

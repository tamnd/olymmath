70 (1) Prove that the number of triangles with integer sides and the largest side length $l$ is
$$
\left\{\begin{array}{l}
\frac{1}{4}(l+1)^{2}, \text { when } l \text { is odd } \\
\frac{1}{4}(l+2), \text { when } l \text { is even }
\end{array}\right.
$$
(2) Let $f_{n}$ denote the number of triangles with sides not exceeding $2 n$, and $g_{n}$ denote the number of triangles with sides not exceeding $2 n+1$. Find the expressions for $f_{n}$ and $g_{n}$.

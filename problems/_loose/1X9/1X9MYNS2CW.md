What is the probability that she gets two heads in a row but she sees a second tail before she sees a second head? $\textbf{(A) } \frac{1}{36} \textbf{(B) } \frac{1}{24} \textbf{(C) } \frac{1}{18} \textbf{(D) } \frac{1}{12} \textbf{(E) } \frac{1}{6}$

For non-zero real numbers $a$ and $b$, where $a \neq -1$ and $b \neq -1$, the equation $\frac{a}{b+1} + \frac{b}{a+1} = 1$ holds. Which statement about the expression $\frac{a}{b} + \frac{b}{a} - \frac{1}{ab}$ is correct?

(A) The expression can take any value in the interval $(0,1]$.

(B) The expression can take any value in the interval $[1,2)$.

(C) The value of the expression is 1.

(D) The value of the expression is 2.

(E) We cannot say anything about the value of the expression.

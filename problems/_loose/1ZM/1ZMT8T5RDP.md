A calculator has a square key (i.e., pressing this key will make the input number become its square) and a reciprocal key (i.e., pressing this key will make the input number become its reciprocal). If a person starts by inputting a number $x$ not equal to zero, and then alternately presses the square key and the reciprocal key $n$ times each. Assuming the calculator is perfectly accurate, then $y$ should be
(A) $x^{(-2)^{n}}$.
(B) $x^{2 n}$.
(C) $x^{-2 n}$.
(D) $x^{1-2 n}$
(E) $x^{\left[(-1)^{n} 2 n\right]}$.
(35th American High School Mathematics Examination, 1984)

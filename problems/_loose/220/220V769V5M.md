In each cell of a $10 \times 10$ table, a number is written. In each row, the largest number (or one of the largest, if there are several) is underlined, and in each column, the smallest number (or one of the smallest) is underlined. It turns out that all underlined numbers are underlined exactly twice. Prove that all numbers written in the table are equal to each other.

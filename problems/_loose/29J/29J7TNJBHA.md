There are one hundred types of insects, and among any two, one can certainly eliminate the other (it is not necessarily transitive, i.e., if A can eliminate B, and B can eliminate C, it does not necessarily mean that A can eliminate C). Prove that it is possible to arrange these one hundred types of insects in a certain order such that each one can eliminate the one immediately following it.

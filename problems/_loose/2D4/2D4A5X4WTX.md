Four. (50 points) In a plane, there are 100 points, no three of which are collinear, and each point is colored either red or blue. A coloring is called "good" if and only if it is possible to connect some pairs of points of the same color with line segments such that no two line segments intersect (but they may share an endpoint), and any two points of the same color can be connected by these line segments. Is it possible for the number of all good colorings to be exactly $2^{99}$?

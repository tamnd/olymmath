Given a circle and a point outside it, draw a tangent to the circle through the point using a compass and a straightedge.

The first reaction of any normal person: why do we need a compass at all?! We can simply place the straightedge so that it passes through the given point and touches the given circle, - and that's it!

Nevertheless, we must limit ourselves to the allowed operations with the compass and straightedge: a straight line can only be drawn through two already constructed points, so we first need to construct the point of tangency. We will show how to do this (we will provide two different methods).

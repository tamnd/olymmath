Given the set $S=\{1,2,3, \ldots, 2022\}$ and the set $A=\left\{a_{1}, a_{2}, a_{3}, \ldots, a_{2022}\right\}$, which is a permutation of the set $S$. It is known that for any $1 \leqslant n, m \leqslant 2022$ the expression $a_{n}+a_{m}$ is divisible by the GCD $(n ; m)$. Find the number of possible sets $A$.

For a given convex pentagon $A B C D E$, a rectangle $F G H J$ is to be constructed that has the same area as the pentagon $A B C D E$.

a) Describe a construction that is feasible with any convex pentagon $A B C D E$ and yields four points $F, G, H, J$!

b) Prove that for any convex pentagon $A B C D E$, the points constructed according to your description are the vertices of a rectangle $F G H J$ that has the same area as $A B C D E$!

c) Perform the construction you described on a pentagon $A B C D E$ of your choice!

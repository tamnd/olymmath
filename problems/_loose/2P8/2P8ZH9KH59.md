Several boxes are arranged in a circle. Each of them can contain one or several balls (or it can be empty). In one move, it is allowed to take all the balls from any box and distribute them, moving clockwise, starting from the next box, placing one ball in each box.

a) Prove that if on each subsequent move the balls are taken from the box into which the last ball fell on the previous move, then at some point the initial arrangement of the balls will repeat.

b) Prove that in several moves, from any initial arrangement of balls in the boxes, any other arrangement can be obtained.

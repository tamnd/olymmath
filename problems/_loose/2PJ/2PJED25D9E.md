In a measure space (especially in a probability space), the term "almost all" is usually used to indicate that the complement of a set has zero measure. If we do not consider the limit of probabilities in $\mathcal{G}(n, p)$ as $n \rightarrow \infty$, but instead define a probability space on the set of all finite graphs (taking only one copy of each graph), and then study the properties of "almost all" graphs in this space according to the above idea, wouldn't this be more natural?

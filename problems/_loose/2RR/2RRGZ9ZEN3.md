The pirate law stipulates that, to divide the coins of a treasure, the captain must choose a group of pirates (excluding himself). Then, the captain must distribute the same number of coins to each of the pirates in this group, in such a way that it is not possible to give each of them any of the remaining coins (respecting the fact that each pirate receives the same amount). The remaining coins are then given to the captain. On Captain Barbarossa's ship, there are 100 pirates (excluding the captain). Barbarossa must divide a treasure that contains fewer than 1000 coins. If he chooses 99 pirates, he will be left with 51 coins, but if he chooses 77 pirates, he will be left with 29 coins.

a) How many coins does the treasure contain?

b) How many pirates should Barbarossa choose to end up with the maximum possible number of coins?

There are 2015 lamps numbered $1, 2, 3, \cdots 2015$, each controlled by a pull switch. If the pull switches of lamps numbered as multiples of 2, 3, and 5 are each pulled once, how many lamps will still be on?

So, the number of lamps that are on is: $2015-1009=1006$ (lamps).

Let $k, n$ be given integers, $n > k \geqslant 2$. For any $n$-element set $P$, consider the sums of the elements of all $k$-element subsets of $P$, and let the set of these sums be $Q$. The number of elements in the set $Q$ is denoted as $C_{Q}$. Find the maximum value of $C_{Q}$.

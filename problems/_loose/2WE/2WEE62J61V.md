A decimal number is called balanced if the sum of the digits before the decimal point is equal to the sum of the digits after the decimal point. For example, the number 25.133 is balanced. In each of the numbers 497 365.198 043 and 197 352.598 062, cross out some digits so that a) the largest balanced number is created, b) the balanced number with the most digits is created.

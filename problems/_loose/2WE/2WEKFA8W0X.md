\section*{Task 1 - 041021}

Four people have the first names Arnold, Bernhard, Conrad, and Dietrich. The last names of these people are also Arnold, Bernhard, Conrad, and Dietrich.

Furthermore, we know the following:

a) None of the four people have the same first and last name.

b) Conrad does not have the last name Arnold.

c) Bernhard's last name matches the first name of the person whose last name matches the first name of the person who has the last name Dietrich.

What are the first and last names of each of the four people?

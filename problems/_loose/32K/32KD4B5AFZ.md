A palindromic number is a positive integer (of one or more digits) that remains the same when the order of the digits is reversed. For example, 1245421 and 333 are palindromic numbers, but 345 and 100 are not. There is exactly one palindromic number $ n $ such that when you subtract 2018 from it, the result is also a palindromic number.

What is this number $ n $?

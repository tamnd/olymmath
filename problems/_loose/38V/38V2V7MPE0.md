Prove the identities

a) $C_{r}^{m} C_{m}^{k}=C_{r}^{k} C_{r-k}^{m-k}(0 \leq k \leq m \leq r)$

b) $C_{n+1}^{m+1}=C_{n}^{m}+C_{n}^{m+1}$;

c) $C_{2 n}^{n}=\left(C_{n}^{0}\right)^{2}+\left(C_{n}^{1}\right)^{2}+\ldots+\left(C_{n}^{n}\right)^{2}$

d) $C_{m+n}^{k}=C_{n}^{0} C_{m}^{k}+C_{n}^{1} C_{m}^{k-1}+\ldots+C_{n}^{k} C_{m}^{0}(0 \leq k \leq n)$;

e) $C_{n}^{k}=C_{n-1}^{k-1}+C_{n-2}^{k-1}+\ldots+C_{k-1}^{k-1}$.

(Try to prove these identities in three different ways: using the fact that $C_{n}^{k}$ is the number of $k$-element subsets in a set of $n$ elements; based on the fact that $C_{n}^{k}$ is the coefficient of $x^{k}$ in the polynomial $(1+x)^{n}$; using the "chess city" from problem $\left.\underline{60395}\right)$).

(CPP, 78). Let the function $f: \mathbf{R} \rightarrow \mathbf{R}$ be defined as follows: $f(x)=0$, if $x$ is irrational; $f(p / q)=1 / q^{3}$, if $p \in \mathbf{Z}, q \in \mathbf{N}$ and the fraction $p / q$ is irreducible. Prove that this function is differentiable at each point $x=\sqrt{k}$, where $k$ is a natural number that is not a perfect square.

Find all polynomials $p(x) \in \mathbb{Z}[x]$ such that for all positive integers $n,$ we have that $p(n)$ is a Palindrome number.

**Palindrome numbers:** *A number $q$ written in base $10$ is called a Palindrome number, if $q$ reads
the same from left to right, as it reads from right to left. For example : $121, -123321$ are Palindrome
numbers, but $113$ is not a Palindrome number.*

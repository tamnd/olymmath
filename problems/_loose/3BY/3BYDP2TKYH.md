Let $a, b, c, d, e$ be five numbers satisfying the following conditions:
$$
\begin{array}{l}
a+b+c+d+e=0, \text { and } \\
a b c+a b d+a b e+a c d+a c e+a d e+b c d+b c e+b d e+c d e=2008 .
\end{array}
$$

Find the value of $a^{3}+b^{3}+c^{3}+d^{4}+e^{3}$.

Let $f$ and $g$ be functions that we call similar if there exists a function $h$ that is defined for all real numbers, takes each real number exactly once, and for all real $x$, it holds that $h(f(x))=g(h(x))$.

For which parameters $a, b$ will the function $x^{2}+a x+b$ be similar to the function $x^{2}?$

Let $E$ be the intersection of the diagonals of convex quadrilateral $A B C D$, and let $P, Q, R$ and $S$ be the centers of the circumcircles of $\triangle A B E, \triangle B C E, \triangle C D E$ and $\triangle A D E$, respectively. Then
(A) $P Q R S$ is a parallelogram.
(B) $P Q R S$ is a parallelogram if and only if $A B C D$ is a rhombus.
(C) $P Q R S$ is a parallelogram if and only if $A B C D$ is a rectangle.
(D) $P Q R S$ is a parallelogram if and only if $A B C D$ is a parallelogram.
(E) None of the above is correct.
(28th American High School Mathematics Examination, 1977)

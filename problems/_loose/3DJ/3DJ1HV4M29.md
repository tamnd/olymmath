A circus arena is illuminated by $n$ different spotlights. Each spotlight illuminates a certain convex shape. It is known that if one arbitrary spotlight is turned off, the arena will still be fully illuminated, but if any two arbitrary spotlights are turned off, the arena will no longer be fully illuminated. For which values of $n$ is this possible?

From every integer, it is possible to take roots of all possible integer powers, which will generally be irrational numbers. With these roots, taken in any quantity, algebraic operations can be performed (addition, subtraction, multiplication, division, raising to rational powers). Will we thus exhaust all possible irrational numbers? Can any irrational number be represented using a known number of roots of rational numbers?

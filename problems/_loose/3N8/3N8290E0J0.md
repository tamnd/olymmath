Three machines print pairs of natural numbers on cards. The machines work as follows. The first machine, reading a card $(a ; b)$, outputs a new card $(a+1 ; b+1)$; the second, reading a card $(a ; b)$, outputs a card $(a / 2 ; b / 2)$ (it works only when $a$ and $b$ are even); the third machine, given two cards $(a ; b)$ and $(b ; c)$, outputs a card $(a ; c)$. Additionally, the machines return all read cards.

Suppose initially there is one card with the pair of numbers $(5 ; 19)$. Can we, using the machines in any order, obtain a card: a) $(1 ; 50)$? b) $(1 ; 100)$?

c) Suppose initially there is one card $(a ; b), a<b$, and we want to obtain a card $(1 ; n)$. For which $n$ is this possible?

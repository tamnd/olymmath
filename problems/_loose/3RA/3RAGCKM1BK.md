The positive difference list ( $P D L$ ) of a set of integers is a list, written in increasing order, of the positive differences between all possible pairs of integers in the set. For example, the set $\{2,5,12\}$ produces a PDL consisting of three integers $3,7,10$ which are distinct, while the set $\{3,4,6,9\}$ produces a PDL consisting of six integers $1,2,3,3,5,6$ which are not distinct.
(a) What is the PDL of the set of integers $\{3,6,13,21,32\}$ ?
(b) Suppose that $x>16$ and the sum of the integers in the PDL of the set $\{1,4,9,16, x\}$ is 112 . Determine the value of $x$.
(c) State a set of integers of the form $\{3, q, r, s, 14\}$ with $3<q<r<s<14$ for which the PDL contains no repeated integers.
(d) Prove that the PDL of every set of integers of the form $\{3, q, r, s, t\}$ with $3<q<r<s<t$ and $t<14$ contains repeated integers.

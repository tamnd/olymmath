Given the quadratic function $y=x^{2}+2 m x-n^{2}$.
(1) If $m, n$ vary, their graphs are different parabolas. If each parabola intersects the coordinate axes at three different points, and a circle is drawn through these three points, prove that all these circles pass through the same fixed point, and find the coordinates of this fixed point.
(2) If the graph of this quadratic function passes through the point $(1,1)$, and let the larger of the two numbers $m, n+4$ be $P$, try to find the minimum value of $P$.

For 2 by 2 matrix $P=\left(
\begin{array}{cc}
p & q \\
r & s
\end{array}
\right)$, define $Tr(P)=p+s$.

Let $a,\ b,\ c$ be real numbers such that $a\geq b>0,\ 0\leq c\leq 1$. Define matices $A,\ B,\ C,\ D$ as follows:

$A=\left(
\begin{array}{cc}
a & 0 \\
0 & b
\end{array}
\right),\ B=\left(
\begin{array}{cc}
b & 0 \\
0 & a
\end{array}
\right),\ C=\left(
\begin{array}{cc}
a^c & 0 \\
0 & b^c
\end{array}
\right),\
D=\left(
\begin{array}{cc}
b^{1-c} & 0 \\
0 & a^{1-c}
\end{array}
\right)$ and for real number $x,,\ U(x)=\left(
\begin{array}{cc}
\cos x & -\sin x \\
\sin x & \cos x
\end{array}
\right)$.

Answer the following questions:

(1) For each real number $t$, find the maximum value $m(t)$ of the function in $x$,

$$f(x)=Tr\left((U(t)AU(-t)-B)U(x)\left(
\begin{array}{cc}
1 & 0 \\
0 & -1
\end{array}
\right)U(-x)
\right)$$.

Note: You don't need to find $x$ for which $f(x)$ is maximized.

(2) Prove, for all real numbers $x$,
$$2Tr(U(t)CU(-t)D)\geq Tr(U(t)AU(-t)+B)-m(t)$$ holds.

Let $S=\{1,2,3,4,5,6\}.$ Find the number of bijective functions $f:S\rightarrow S$ for which there exist exactly $6$ bijective functions $g:S\rightarrow S$ such that $f(g(x))=g(f(x))$ for all $x\in S$.

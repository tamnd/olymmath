In a class, the number of boys and girls is the same (the class has no fewer than 4 people). They are arranged in a row in various ways. Determine if this row can be divided into two parts such that in each part, boys and girls each make up half. Let the number of arrangements that cannot be divided in this way be $a$, and the number of arrangements that can be divided in exactly one way be $b$. Prove: $b=2a$.
$(1972$, Hungarian Mathematical Olympiad)

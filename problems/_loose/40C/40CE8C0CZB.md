(1987 National High School Mathematics League Question) On the coordinate plane, points whose both coordinates are integers are called integer points. Try to prove that there exists a set of concentric circles such that (1) each integer point lies on one of the circles in this set; (2) each circle in this set has exactly one integer point on it.

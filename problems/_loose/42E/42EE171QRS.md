A non-empty set of integers is said to be balanced if the number of its elements is equal to the average of its elements. For example, the set $\{1,2,6\}$ is balanced, as it has 3 elements whose average is 3, but the set $\{1,2, \ldots, n\}$ is not balanced when $n \geqslant 2$, because it has $n$ elements whose average is $(n+1) / 2$.

Is it possible to partition the set $\left\{1,2, \ldots, 2021^{2}\right\}$ into several balanced sets that are pairwise disjoint?

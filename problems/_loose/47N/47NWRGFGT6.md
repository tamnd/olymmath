Let $A B C D$ be a convex quadrilateral and $Z$ a point inside it. We denote $\alpha_{1}$ the angle $\widehat{Z A D}, \alpha_{2}$ the angle $\widehat{Z A B}, \beta_{1}$ the angle $\widehat{Z B A}, \beta_{2}$ the angle $\widehat{Z B C}, \gamma_{1}$ the angle $\widehat{Z C B}, \gamma_{2}$ the angle $\widehat{Z C D}, \delta_{1}$ the angle $\widehat{Z D C}, \delta_{2}$ the angle $\widehat{Z D A}$. Show the following equality:

$$
\frac{\sin \alpha_{1}}{\sin \alpha_{2}} \frac{\sin \beta_{1}}{\sin \beta_{2}} \frac{\sin \gamma_{1}}{\sin \gamma_{2}} \frac{\sin \delta_{1}}{\sin \delta_{2}}=1
$$

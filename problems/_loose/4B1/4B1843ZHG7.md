At each integer point on the number line, there is a light bulb with a button. When the button is pressed, the light bulb changes its state - it turns on or off. Initially, all the light bulbs are off. A finite set of integers $S$ is given, which can be moved along the number line as a rigid shape and, when applied at any point, can change the state of all the light bulbs covered by the template. Prove that for any $S$, it is possible to achieve in several operations that exactly two light bulbs are on.

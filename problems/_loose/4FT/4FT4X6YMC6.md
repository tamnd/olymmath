For any triangle $A B C$, let $H$ be the foot of the perpendicular from $A$ to $B C$ and $W$ be the intersection of $B C$ with the angle bisector through $A$.

a) What must the base angle $\angle B A C$ of an isosceles triangle $A B C$ with $A C = B C$ be for the points $H$ and $W$ to coincide?

b) What must the angle $\angle W A H$ in an isosceles triangle $A B C$ with $A C = B C$ be if the base angle $\angle B A C$ is $70^{\circ}$?

c) Determine all possible values for the base angle $\angle B A C$ in an isosceles triangle $A B C$ with $A C = B C$ for which the angle $\angle W A H$ is $15^{\circ}$.

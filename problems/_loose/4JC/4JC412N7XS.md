a) Prove that if a polynomial $P(x)$ of degree $n$ takes integer values at $x=0,1,2, \ldots, n$, then it takes integer values for all integer values of $x$.[^4]b) Prove that any polynomial of degree $n$, which takes integer values at some $n+1$ consecutive integer values of $x$, takes integer values for any integer $x$.

c) Prove that if a polynomial $P(x)$ of degree $n$ takes integer values at $x=0,1,4,9,16, \ldots, n^{2}$, then it takes integer values for any integer $x$ that is a perfect square (but not necessarily for all integer $x$).

Provide an example of a polynomial that takes integer values for each integer $x$ that is a perfect square, but takes fractional values for some other integer $x$.

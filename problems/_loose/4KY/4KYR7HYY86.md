In each cell of an infinite cellular plane, one of the numbers 1, 2, 3, 4 is written, such that each number appears at least once. We will call a cell correct if the number of different numbers written in the four adjacent (by side) cells is equal to the number written in this cell. Can all cells of the plane be correct?

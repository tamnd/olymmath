Digits are written along the circumference, and it is known that if we start from a certain position and read these digits in a clockwise direction, the resulting 1953-digit number is divisible by 27. Prove that regardless of the starting position, reading the digits in a clockwise direction will always result in a 1953-digit number that is divisible by 27.
(16th Moscow Mathematical Olympiad, 1953)

Prove: A function $f(x)$ defined on $\mathbf{R}$ that is odd can be expressed as the sum of a periodic function and a linear function if and only if the graph of $f(x)$ has a center of symmetry $(a, b)$ different from the point $(0,0)$. (Note: A linear function refers to a function of the form $y=k x+h$, where $k$ and $h$ can be any real numbers.)

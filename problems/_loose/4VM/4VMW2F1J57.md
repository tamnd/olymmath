In a $3 n \times 3 n$ grid, there is a unicorn. It starts in a certain cell and can move one step to the right, up, or diagonally left down $\left(45^{\circ}\right)$ at each step. It cannot visit the same cell twice (except for the final step), and it eventually returns to the starting cell. The cells the unicorn has visited are colored red.
(1) Prove: The number of red cells is a multiple of 3;
(2) Prove: The number of red cells is at most $9 n^{2}-3$;
(3) Provide a walk such that exactly $9 n^{2}-3$ cells are red.

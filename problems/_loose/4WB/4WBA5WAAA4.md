If the set $M=A_{1} \cup A_{2} \cup \cdots \cup A_{n}$ and $A_{i} \cap A_{j}=\varnothing(1 \leqslant i<j \leqslant n)$, then the sets $A_{1}$, $A_{2}, \cdots, A_{n}$ are called an $n$-partition of the set $M$. Suppose the sets $A_{1}, A_{2}, \cdots, A_{n}$ and $B_{1}, B_{2}, \cdots, B_{n}$ are two $n$-partitions of the set $M$, and for any two disjoint sets $A_{i}, B_{j}(1 \leqslant i, j \leqslant n)$, we have $\left|A_{i} \cup B_{j}\right| \geqslant n$. Prove: $|M| \geqslant \frac{n^{2}}{2}$.

Experimental Textbook (from 6th grade, 2 points). In the testing of a new mathematics textbook, parallel seventh-grade classes from two schools, approximately equal in number, participated in the experiment. In each school, part of the seventh-graders studied using the experimental textbook, while the other part used the regular old textbook. At the end of the school year, a final test was conducted to determine how well the seventh-graders had mastered the material.

Table 1. Test results in the 1st school

| | Studied using the experimental textbook | Studied using the regular textbook |
| :--- | :---: | :---: |
| Passed the test well | $30 \%$ | $15 \%$ |
| Failed the test | $35 \%$ | $20 \%$ |
| Proportion of those who passed well | 0.46 | 0.43 |

Table 2. Test results in the 2nd school

| | Studied using the experimental textbook | Studied using the regular textbook |
| :--- | :---: | :---: |
| Passed the test well | $20 \%$ | $45 \%$ |
| Failed the test | $10 \%$ | $25 \%$ |
| Proportion of those who passed the test well | 0.67 | 0.64 |

In both schools, the proportion of those who passed the test well was higher in the group that studied using the experimental textbook. Therefore, it was concluded that the new textbook provides a higher quality of education.

Only the Absent-Minded Scholar spoke out against the new textbook and, to everyone's surprise, stated that those who studied using the new textbook performed worse on average than those who studied using the old one.

Who is right?

(Belarusian Mathematical Competition) Let sets $A, B \subset \mathbf{R}$, for any $\alpha>0$, we have $A \subseteq B+\alpha \mathbf{Z}, B \subseteq A+\alpha \mathbf{Z}$. (1) Does $A=B$ necessarily hold? (2) If $B$ is a bounded set, does (1) hold?
Note: $X+\alpha \mathbf{Z}=\{x+\alpha n \mid x \in X, n \in \mathbf{Z}\}$

In Gumi Country, only natural numbers less than ten thousand are recognized. They solve the description of these "gumi numbers" flexibly. The basic rule for describing gumi numbers is that every number is written in the smallest base number system so that the described number is at most four digits long. Unfortunately, the numbers thus described are not always decodable unambiguously; the four-digit 1101 gumi number, for example, simultaneously represents both 13 and 37. Is there a three-digit gumi number that simultaneously represents more than one natural number?

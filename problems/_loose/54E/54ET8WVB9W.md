Let $\rho$ be a relation on the set $\mathbb{R}$ defined as:

$$
x \rho y \text { if and only if } x^{2}-y^{2} \geqslant 0 \text {. }
$$

Examine whether the relation $\rho$ is reflexive, symmetric, antisymmetric, and transitive, whether it is an equivalence relation, and whether it is an order relation.

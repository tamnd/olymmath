Let $\mathcal{P}$ be the set of $n \times n$ matrices, where $n \geq 2$, that have exactly one element equal to 1 on each row and each column, and all other elements are equal to 0.

a) Prove that there exists a bijective function $\varphi: S_{n} \longrightarrow \mathcal{P}$, where $S_{n}$ is the set of permutations of order $n$.

b) Calculate $S=\sum_{A \in \mathcal{P}}(\operatorname{det}(A))^{2}$.

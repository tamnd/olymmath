In the convex quadrilateral $A B C D$, $A B=B C=C D$, and $A B C \angle=B C D \angle=150^{\circ}$. Prove that $A, B, C$, $D$ are four consecutive vertices of a regular 12-sided polygon. - Construct the remaining vertices of the 12-sided polygon using only a compass. Aim to use as few arcs as possible and minimize the number of times the compass width needs to be adjusted.

On the table, there are $n>3$ identical coins arranged in a circle, which can lie either heads up or tails up. If next to some coin there are two heads or two tails, then this coin can be flipped. Such an operation is allowed to be performed an unlimited number of times. For which $n$ is it possible, regardless of the initial position of the coins, to flip them all to the same side up?

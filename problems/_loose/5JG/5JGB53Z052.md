Given several red points and several blue points, some of which are connected by line segments. If more than half of the points connected to a point have a different color from that point, it is called a peculiar point. A peculiar point can be recolored: in each step, any peculiar point can be chosen and painted the other color. Prove that after several steps, there will be no more peculiar points.

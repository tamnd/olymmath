$$
\left|a_{i+1}-a_{i}\right|=2 \text { or } 3 \text {, }
$$

where, $i=1,2, \cdots, 10$, with the convention $a_{11}=a_{1}$.
If $a_{1}, a_{2}, \cdots, a_{10}$ have the maximum number $M$ and the minimum number $m$, then the maximum value of $M-m$ is ( ).
(A) 13
(B) 14
(C) 15
(D) 16

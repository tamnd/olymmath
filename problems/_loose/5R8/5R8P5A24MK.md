Let the function $f:(0,1) \rightarrow \mathbf{R}$ be defined as
$$
f(x)=\left\{\begin{array}{l}
x, \text { when } x \text { is irrational, } \\
\frac{p+1}{q}, \text { when } x=\frac{p}{q},(p, q)=1,0<p<q
\end{array}\right.
$$

Find the maximum value of $f(x)$ on the interval $\left(\frac{7}{8}, \frac{8}{9}\right)$.

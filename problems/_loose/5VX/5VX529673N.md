The school arranges for one student each from Class A and Class B to be on duty simultaneously every day, and only one of the students is replaced the next day. Students from both classes take turns on duty according to the order arranged in their respective classes, and after everyone has had a turn, the rotation starts again from the first person in the list. It is known that Class A has 29 students and Class B has 32 students. Can a duty schedule be devised such that within a certain period, each student from Class A works with each student from Class B exactly once, and then the first pair of students is on duty again?

In the convex quadrilateral $A B C D$, $S$ denotes the intersection of the diagonals. Let $P_{1}=P_{A B S}, P_{2}=P_{B C S}, P_{3}=P_{C D S}, P_{4}=P_{D A S}$. If

$$
P^{2}=P_{1} P_{3} \text { and } 2 P_{4}=P_{1}+P_{3} \text {, }
$$

prove that the quadrilateral $A B C D$ is a parallelogram.

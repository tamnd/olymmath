$f(x)$ has the domain $\mathbf{R}$, if $c \in \mathbf{R}$, such that $f(c)=c$, then $c$ is called a fixed point of $f(x)$. Suppose $f(x)$ has a finite number of fixed points, is the following statement correct? If correct, please provide a proof; if not correct, please provide a counterexample.
（1） If $f(x)$ is an odd function, then the number of fixed points of $f(x)$ is odd;
（2） If $f(x)$ is an even function, then the number of fixed points of $f(x)$ is even.
(1993 Peking University Science Experimental Class Admission Question).

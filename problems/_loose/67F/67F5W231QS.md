Prove that:
1) $ n $ lines lying on a plane, each two of which intersect, but no three pass through the same point, divide the plane into $ \frac{1}{2} (n^2 + n + 2) $ parts;
2) $ n $ planes, each three of which have one and only one common point, but no four pass through the same point, divide the space into $ \frac{1}{6} (n^3 + 5n + 6) $ parts.

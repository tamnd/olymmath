A cube with edge length $n, n \geqslant 3$, consists of $n^{3}$ unit cubes. Prove that it is possible to write an integer in each of these unit cubes such that all $n^{3}$ numbers are distinct, and the sums of the numbers in any row parallel to any edge of the cube equal zero.

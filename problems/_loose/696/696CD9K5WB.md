Given the number $2009^{2009^{2009}}$, written in the decimal number system. In one step, we perform the following operation: we erase the first and last digit and add their sum to the number that remains after erasing the first and last digit.

a) If after a finite number of steps a two-digit number remains, can this two-digit number be a perfect square.

b) If after a finite number of steps a one-digit number remains, determine the one-digit number.

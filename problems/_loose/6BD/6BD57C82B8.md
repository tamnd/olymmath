COUNTY SAVINGS BANK R. T.

sign can be rearranged to form the following sentence:

TATAR CHILD ASKS FOR MONEY.

We want to perform the rearrangement using swaps in the following two ways:

I. method: only adjacent letters can be swapped.

II. method: any distant letters can be swapped.

How many swaps are needed for each rearrangement method? (After a swap, both letters must take the other's place, and a new swap can only occur after this.)

Let $n \geqslant 2$ be a positive integer. On a circle, there are $2n$ points of $n$ different colors, with two points of each color. If a circular arc $L$ contains a number of colored points in the range $[1, 2n-1]$, then there exists a color such that $L$ contains exactly one point of that color. Prove: It is possible to remove two points of some color so that the above property is still preserved.

Write 49 ones and 50 zeros arbitrarily on a circle, then perform the following operation: write 0 between two identical numbers, and write 1 between two different numbers, and erase the original numbers, then perform the same operation again, and so on. Can all the numbers on the circle become 0 after a finite number of such operations?

On a circle, take any $n>2$ points, and connect each point with all the others by line segments. Can all these line segments be drawn in one stroke, such that the endpoint of the first line segment coincides with the starting point of the second line segment, the endpoint of the second line segment coincides with the starting point of the third line segment, and so on, until the endpoint of the last line segment coincides with the starting point of the first line segment?

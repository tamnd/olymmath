Given are $n$ light bulbs ($n>13$), each with its own switch. It is allowed to change the state of exactly 13 light bulbs simultaneously. Initially, some of the light bulbs are on, and some are off.

a) Is it possible to turn off all the light bulbs?

b) What is the minimum number of steps to turn off all the light bulbs if $n=111$ and all the light bulbs are initially on?

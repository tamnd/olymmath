There are 1996 points on a circle, which are colored with several different colors. Now, from each set of points of the same color, one point is taken to form an inscribed polygon with vertices of different colors. If the number of points of each color is different, to maximize the number of such polygons, how many different colors should the 1996 points be colored with? And how many points should be of each color?

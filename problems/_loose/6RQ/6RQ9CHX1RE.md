Let $S$ be a topological space with the Borel $\sigma$-algebra $\mathscr{E}$ generated by all open sets. Suppose also that for any closed set $F$ in $S$, there exists a decreasing sequence of open sets $G_{1} \supset G_{2} \supset \ldots$ such that $F=\bigcap_{n} G_{n}$. Show using the principle of suitable sets that any probability measure $\mu$ on $(S, \mathscr{E})$ is regular in the sense that for any Borel set $E \in \mathscr{E}$, the following equalities hold:

$$
\begin{aligned}
& \mu(E)=\mu^{*}(E)=\inf \{\mu(G): G \supseteq E, G-\text { open set }\}, \\
& \mu(E)=\mu_{*}(E)=\sup \{\mu(F): F \subseteq E, F-\text { closed set }\} .
\end{aligned}
$$

In particular, $(S, \mathscr{E})$ can be taken as $\left(\mathbb{R}^{d}, \mathscr{B}\left(\mathbb{R}^{d}\right)\right), d \geqslant 1$. Verify that in the latter case, for any Borel set $B \in \mathscr{B}\left(\mathbb{R}^{d}\right)$, the following equality holds:

$$
\mu(B)=\sup _{K}\{\mu(K): K \subseteq B, K-\text { compact }\} .
$$

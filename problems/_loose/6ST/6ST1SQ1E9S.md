If the function $f(x)$ defined on the real number set $D$ simultaneously satisfies the following two conditions:
(1) $f(x)$ is either a monotonically increasing function or a monotonically decreasing function on $D$;
(2) There exists an interval $[a, b] \subseteq D$ such that the range of $f(x)$ on $[a, b]$ is also $[a, b]$. Such a function is called a "closed function".
(1) Is the function $y=-x^{3}$ with domain $\mathbf{R}$ a "closed function"? Please explain your reasoning;
(2) If the function $f(x)=\frac{x^{2}}{2}-x+1(x \in[a, b])$, can it be a "closed function"? Please explain your reasoning.

Design a scheme to color all integer points in the Cartesian coordinate system, where each integer point is colored white, red, or black, such that:
(1) Points of each color appear on infinitely many lines parallel to the x-axis;
(2) For any white point $A$, red point $B$, and black point $C$, there always exists a red point $D$ such that $A B C D$ forms a parallelogram.

(Beijing, 63). A set of $2^{n}$ elements is partitioned into pairwise non-intersecting subsets. An operation is considered, consisting of transferring some elements from one subset to another, with the number of transferred elements being equal to the number of elements in the second set (which should contain no more elements than the first). Prove that using a finite number of such operations, one can obtain a subset that coincides with the original set.

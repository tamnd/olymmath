In an amoeba colony, each amoeba mutates every hour. If an amoeba had $m$ pseudopodia and $n$ nuclei before mutation, it will have $2 m-n$ pseudopodia and $2 n-m$ nuclei after. If the number of pseudopodia or nuclei in an amoeba becomes negative, it dies. Prove that sooner or later, only those amoebas will survive in the colony, which initially had the same number of pseudopodia as nuclei.

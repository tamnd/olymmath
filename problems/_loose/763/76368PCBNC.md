In a country, there are 64 cities. There are roads connecting certain pairs of cities, but Bob does not know which ones (the roads do not cross each other but can potentially pass over or under each other; furthermore, the roads can be traveled in both directions). Alice, on the other hand, knows the network perfectly. Bob can choose any pair of cities and ask Alice if they are directly connected by a road. Bob's goal is to determine whether it is possible to travel from any city to any other (by potentially using several successive roads). Show that there is no algorithm (i.e., no strategy based on Alice's successive answers) that allows him to be sure in fewer than 2016 questions.

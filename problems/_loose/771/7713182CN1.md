Natural number $m\geq 2$ is given. There are $n$ , $n\geq 3$ non-collinear points, pairwise connected by segments. Every segment is coloured one of the $m$ given colours (there are segments of each colour) so that the following condition is true : if in a triangle two sides coloured the same colour, then the third side is also coloured this colour. What is the maximum value of $n$ with the given $m$ ?

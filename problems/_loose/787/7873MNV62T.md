Let $s,t$ be given nonzero integers, $(x,y)$ be any (ordered) pair of integers. A sequence of moves is performed as follows: per move $(x,y)$ changes to $(x+t, y-s)$. The pair (x,y) is said to be *good * if after some (may be, zero) number of moves described a pair of integers arises that are not relatively prime.
a) Determine whether $(s,t)$ is itself a good pair;
bj Prove that for any nonzero $s$ and $t$ there is a pair $(x,y)$ which is not good.

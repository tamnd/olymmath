Given the function $f:[0, \pi / 2] \rightarrow[0, \infty)$ which is increasing. Prove that:
a) $\int_{0}^{\pi / 2}(f(x)-f(\pi / 4))(\sin x-\cos x) \mathrm{d} x \geq 0$.

b) There exists $a \in[\pi / 4, \pi / 2]$ such that $\int_{0}^{a} f(x) \sin x \mathrm{~d} x=\int_{0}^{a} f(x) \cos x \mathrm{~d} x$.

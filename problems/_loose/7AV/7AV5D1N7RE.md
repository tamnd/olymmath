Given that the function $f(x)$ is an odd function, there exists a constant $a>0$ such that $f(a)=1$, and $f\left(x_{1}-x_{2}\right)=$ $\frac{f\left(x_{1}\right) f\left(x_{2}\right)+1}{f\left(x_{2}\right)-f\left(x_{1}\right)}$.
(1) Find $f(2a)$;
(2) If $f(x)$ is defined, prove that there exists a constant $T>0$ such that $f(x+T)=f(x)$;
(3) If $x \in(0,2a)$, then $f(x)>0$ holds, prove: when $x \in(0,4a)$, $f(x)$ is a decreasing function.

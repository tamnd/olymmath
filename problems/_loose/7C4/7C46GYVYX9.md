4 Let $A$ be an infinite subset of the set of positive integers, and let $n (n>1)$ be a given integer. It is known that for any prime $p$ that does not divide $n$, the set $A$ contains infinitely many elements not divisible by $p$. Prove: For any integer $m (m>1), (m, n)=1$, the set $A$ contains finitely many distinct elements whose sum $S$ satisfies $S \equiv$ $1(\bmod m)$, and $S \equiv 0(\bmod n)$.

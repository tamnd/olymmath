In a table with 3 rows and $n$ columns, we want to write the numbers $1,2,3, \ldots, n$ such that each of the three rows contains all these numbers and the sum of the numbers in each column is the same.

a) Show by example that it is possible to do this for $n=9$.

b) Prove that $n$ cannot be an even number.

(a) Prove that if $\varphi(t)$ is a characteristic function, then so is the function $\exp [\lambda(\varphi(t)-1)]$ for each $\lambda>0$.

(b) Using the equality

$$
C_{\alpha} \int_{\mathbb{R}_{+}} \frac{1-e^{-x}}{x^{1+\alpha}} d x=1
$$

valid for some positive $C_{\alpha}$, prove the Schoenberg theorem: if the function $\exp [-a \psi(t)]$ is characteristic for all $a>0$ and some $\psi: \mathbb{R} \rightarrow \mathbb{R}_{+}$, then so is the function $\exp \left[-a \psi(t)^{\alpha}\right]$ for any $\alpha \in[0,1], a>0$.

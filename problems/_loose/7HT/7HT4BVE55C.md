Consider $k>0$ and the set $G=(-k, k)$ on which the composition law $x * y=\frac{k^{2}(x+y)}{k^{2}+x y}, \forall x, y \in G$ is defined. We assume that $(G, *)$ is a commutative group with the neutral element 0.

a) Calculate $x^{n}, n \in \mathbb{N}, n \geq 2$, where $x^{n}=\underbrace{x * x * \ldots * x}_{\text {of } n \text { times } x}$.

b) Show that $\operatorname{ord}(x)=+\infty, \forall x \in G, x \neq 0$.

c) Show that the groups $(G, *)$ and $\left(\mathbb{R}^{*}, \cdot\right)$ are not isomorphic.

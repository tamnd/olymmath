$$
\begin{aligned}
& p_{1}(x)= \begin{cases}0 & \text { if } x1, \\
0.5 & \text { if }-12 \\
0.5 & \text { if } 0<y \leq 2 .\end{cases}
\end{aligned}
$$

Find: 1) the distribution functions $F_{1}(x)$ and $F_{2}(y)$;

2) the density of the probability distribution of the system $(X, Y)$; 3) the distribution function of the system $(X, Y)$.

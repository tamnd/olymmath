Monochromatic pairs. In a box, there are $n$ white and $n$ black balls. Balls are drawn from the box in pairs - random pairs.

a) (from 9th grade. 2 points). Find the expected number of mixed-color pairs drawn from the box by the time it is empty.

b) (from 9th grade. 5 points). Suppose that if a pair is mixed-color, it is set aside, and if it is monochromatic, it is returned to the box. Such an operation is called an attempt. Find the expected number of attempts needed to set all the balls aside, leaving nothing in the box.

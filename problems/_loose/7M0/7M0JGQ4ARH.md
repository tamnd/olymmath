When modeling the development of a certain process over time $t$, a physicist derived the dependence $y_{1}(t)=2^{-4 t}$, while a mechanic obtained the dependence $y_{2}(t)$ for the same process, which turned out to be the inverse function of $y_{1}(t)$. A mathematician ended the scientific debate by proving that both of these dependencies are sufficiently close to a hyperbolic function $y_{3}(t)=\frac{c}{t}$, where $c$ is some constant, and the equations $y_{1}=y_{3}$ and $y_{2}=y_{3}$ have exactly two solutions in this time interval, which can be easily guessed if $c$ is known.
1) Find this value of $c$ and the minimal interval $\left[t_{1}, t_{2}\right]$ where the mathematician's statement is valid.
2) Determine how many exact solutions the equation $y_{1}=y_{2}$ has.

A book has 2020 pages. If a page number can form 2 or more (including 2) consecutive natural numbers, we call this page a "consecutive page." For example: "21", "213", "1324", "9789", "109" are page numbers formed by "2, 1", "1, 2, 3", "1, 2, 3, 4", "97, 98", "9, 10" respectively, so "21", "213", "1324", "9789", "109" are consecutive pages, but "22", "217", "122" are not consecutive pages. How many consecutive pages are there in this book?

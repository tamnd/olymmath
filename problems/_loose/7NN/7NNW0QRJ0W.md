Generalize Corollary 12.4.10 as follows: Let $H$ be a connected planar graph, $\mathcal{X}$ be any set of connected graphs containing $H$, and let $\mathcal{H}:=\{I X \mid X \in \mathcal{X}\}$. Prove: $\mathcal{H}$ has the Erdös-Pósa property, which can be supported by the function $f$ defined in the proof of Corollary 12.4.10. Explain why $f$ depends only on $H$ and not on any other graph in $\mathcal{X}$.

${ }^{+}$ Let $T$ be a tree with root $r$, and $\leqslant$ be the tree order on $V(T)$ associated with $T$ and $r$. Prove: $T$ does not contain a subdivision of the $\aleph_{1}$-regular tree $T_{\mathbb{N}_{1}}$ if and only if $T$ has an order labeling $t \longmapsto o(t)$ such that whenever $t < t^{\prime}$, we have $o(t) \geqslant o\left(t^{\prime}\right)$, but $T$ does not have more than countably many vertices with the same label.

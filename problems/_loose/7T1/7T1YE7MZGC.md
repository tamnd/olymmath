Find all numbers $n \in \mathbb{N}^*$ for which there exists a finite set of natural numbers $A=(a_1, a_2,...a_n)$ so that for any $k$ $(1\leq k \leq n)$ the number $a_k$ is the number of all multiples of $k$ in set $A$.

A planar binary tree is a graph on a plane that has no cycles and from each vertex either three or one edge emerges. We fix one vertex, from which one edge emerges, and call it the root. All other vertices from which exactly one edge emerges will be called leaves. Prove that the number of different planar binary trees with one root and $n$ leaves is $c_{n-1}$ (Cayley).

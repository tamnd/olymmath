In $\triangle A B C$, prove:
(1) $\tan n A+\tan n B+\tan n C=\tan n A \tan n B \tan n C, n$ is an integer;
(2) $\cot \frac{n A}{2}+\cot \frac{n B}{2}+\cot \frac{n C}{2}=\cot \frac{n A}{2} \cot \frac{n B}{2} \cot \frac{n C}{2}, n$ is an odd number.

In a box, there are 500 ball bearings that cannot be distinguished from each other externally; 499 balls have the same size and weight as each other, and one single ball, although the same size as any of the others, is lighter than they are.

Now, using a balance scale, the lighter ball is to be determined by repeated checks to see whether there is equilibrium between two equal numbers of these balls or not.

Show that six weighings are sufficient for this purpose, i.e.: No matter how the results of the 1st, 2nd, ..., 5th weighing turn out, one should always be able to perform the next weighing in such a way that after the 6th weighing, the lighter ball is uniquely determined.

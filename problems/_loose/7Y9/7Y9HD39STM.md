In a regular $n$-sided polygon, there is a magpie perched on each vertex. If startled, all the magpies fly away. After some time, they return to these vertices, with one magpie on each vertex, but not necessarily to their original vertices. Find all positive integers $n$, such that there must exist 3 magpies, for which the triangles formed by their initial and final positions are either all acute, all right, or all obtuse.
(2001 China Mathematical Olympiad Problem)

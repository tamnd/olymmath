Heidi, Manuela, Peggy, and Simone participated in the school sports festival, each girl in exactly one of the sports "Handball," "Pentathlon," "Pop-Gymnastics," "Swimming." Furthermore, it is known:

(1) Each of the four girls won exactly one medal; two girls gold, the other two silver.

(2) For girls with the same medal, it always holds that the name of each of these girls begins with the same letter as the sport of the other girl.

(3) Heidi received a medal of lesser value than Manuela.

(4) Simone did not win the same medal as the handball player.

Show that from these statements it can be uniquely determined:

a) in which sport each of the girls participated,

b) which medal each of the girls won!

Also, verify whether all statements (1) to (4) are satisfied with the determined sports and medals!

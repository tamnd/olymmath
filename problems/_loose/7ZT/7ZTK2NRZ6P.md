In the country, there are 64 cities, some pairs of which are connected by roads, but we do not know which ones. You can choose any pair of cities and get an answer to the question "is there a road between them?". We need to find out if it is possible to get from any city to any other city in this country by moving along the roads. Prove that there is no algorithm that can do this in fewer than 2016 questions.

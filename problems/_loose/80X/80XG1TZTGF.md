a) Prove that for each tetrahedron $ABCD$

$$
\Pi^{2} \geqslant 3 \sqrt{3} \Delta
$$

where equality holds only if the tetrahedron $ABCD$ is regular.

b) Prove that, moreover,

$$
\begin{aligned}
& \Pi^{2} \geqslant 3 \sqrt{3} \Delta + 1 / 2\left[\left(a + a_{1} - b - b_{1}\right)^{2} + \left(a + a_{1} - c - c_{1}\right)^{2} + \right. \\
& \left. + \left(b + b_{1} - c - c_{1}\right)^{2}\right] + 3 / 4\left[\left(a - a_{1}\right)^{2} + \left(b - b_{1}\right)^{2} + \left(c - c_{1}\right)^{2}\right]
\end{aligned}
$$

where, of course, equality also holds only if $a = b = c = a_{1} = b_{1} = c_{1}$.

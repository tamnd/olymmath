We are looking for all genuine five-digit natural numbers $z$ (i.e., $10000 \leq z < 100000$) with the following properties:

1. Each digit appears at most once.
2. The sum of the digits (digital sum) is 10.
3. If you add the number $z$ to the number $z^{\prime}$, which consists of the same digits as $z$ but in reverse order, the sum contains only identical digits.

(SFROI, 83). The function $\mathrm{f:} \mathbf{Z} \rightarrow \mathbf{R}$ satisfies the conditions

$$
f(n)= \begin{cases}n-10, & \text { if } n>100 \\ f(f(n+11)), & \text { if } n \leqslant 100\end{cases}
$$

for $n \in \mathbf{Z}$. Prove that for any value $n \leqslant 100$, the equality $f(n)=91$ holds.

(a) If $f(x)=\frac{x}{x-1}$ for $x \neq 1$, determine all real numbers $r \neq 1$ for which $f(r)=r$.

(b) If $f(x)=\frac{x}{x-1}$ for $x \neq 1$, show that $f(f(x))=x$ for all real numbers $x \neq 1$.

(c) Suppose that $k$ is a real number. Define $g(x)=\frac{2 x}{x+k}$ for $x \neq-k$. Determine all real values of $k$ for which $g(g(x))=x$ for every real number $x$ with $x \neq-k$ and $g(x) \neq-k$.

(d) Suppose that $a, b$ and $c$ are non-zero real numbers. Define $h(x)=\frac{a x+b}{b x+c}$ for $x \neq-\frac{c}{b}$. Determine all triples $(a, b, c)$ for which $h(h(x))=x$ for every real number $x$ with $x \neq-\frac{c}{b}$ and $h(x) \neq-\frac{c}{b}$.

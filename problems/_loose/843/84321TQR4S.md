Let $f(x)$ be an odd function defined on $\mathbf{R}$, and for any $a, b \in \mathbf{R}$, when $a+b \neq 0$, we have $\frac{f(a)+f(b)}{a+b}>0$.
(1) Prove: $f(x)$ is an increasing function on $\mathbf{R}$;
(2) If the inequality $f\left(m \cdot 2^{\prime}\right)+f\left(2^{\prime}-4^{\prime}+m\right)<0$ holds for all real numbers $x$, find the range of real numbers $m$.

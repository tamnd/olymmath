Let $n>1$ be an integer. We wish to colour an $n$ by $n$ grid of squares such as $n$ squares are green, $n$ squares are blue and the rest is red.

Let $A$ be the number of ways to colour the grid such that there is exactly one green square in each row and one blue square in each column.

Let $B$ be the number of ways to colour the grid such that there is exactly one green square in each row and one blue square in each row.

Determine, with proof, which of $A$ or $B$ is larger.

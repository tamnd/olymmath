A table tennis tournament proceeds according to the following rule. In each round, if the number of participants is odd, one is randomly selected to automatically advance to the next round. The remaining participants $\mathrm{z}$ are paired by random draw. The players of each pair compete against each other, and the winner of each pair advances to the next round. Let $f(n)$ denote the number of rounds in a tournament with $n$ participants. (For example, $f(5)=3$.) Determine $f(2013)$ and find the smallest natural number $n$ for which $f(n)=f(2013)$.

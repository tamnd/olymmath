The stubborn robot "Inverter" stands on an infinite plane and faces east. This robot understands only two commands: STEP and LEFT. When the robot sees the command STEP, it moves forward exactly 1 meter. When the robot sees the command LEFT, it turns left exactly $90^{\circ}$ while remaining in place. The robot is called stubborn because when a program (a sequence of commands) is input into it, it first executes the entire program, and then executes the same program, inverting the meaning of the commands: seeing the command STEP, it performs the command LEFT and vice versa. Using the command STEP exactly twice and the command LEFT as many times as needed, create a program for this robot so that after its stubborn execution, it returns to the starting point and faces east.

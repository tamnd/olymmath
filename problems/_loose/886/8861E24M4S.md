A binary number of $2n$ bits composed of $n$ ones and $n$ zeros, requires that the cumulative number of 1s is greater than the cumulative number of 0s when scanning the first $2n-1$ bits from left to right. Find the number of such numbers.  from point $O$ to point $A$ that only pass through points above the diagonal $OA$, which is equivalent to finding the number of paths from point $O'(0,1)$ to point $A'(n-1, n)$ without crossing the diagonal $OA$. Thus, it is transformed into the problem of the previous example.

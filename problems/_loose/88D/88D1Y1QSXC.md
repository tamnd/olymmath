Equal Fractions. Can you form three ordinary fractions (say, something like $\frac{1}{2}, \frac{1}{3}, \frac{1}{4}$ or $\frac{1}{9}$), using each of the nine digits exactly once? The fractions can be formed in one of the following ways:

$$
\text { either } \frac{a}{b}=\frac{c}{d}=\frac{e f}{g h j}, \text { or } \frac{a}{b}=\frac{c}{d e}=\frac{f g}{h j} \text {. }
$$

There are only five solutions, but the fifth one has a certain "twist" - a subtlety that might elude the reader.

A non-empty set of natural numbers is called perfect if it does not contain any (not necessarily distinct) numbers $a,b,c$ with which the equality $a^b = c$ holds. (For example, the set $\{2,3\}$ is perfect, while the set $\{2,3,9\}$ is not perfect, because $3^2 = 9$ .) Find the largest natural number $n\ge 3$ with which the set $\{2,3,4,...,n\}$ is the union of two perfect sets.

Let $n$ be a given positive integer, $S_{n} \subseteq\left\{\alpha \mid \alpha=\left(p_{1}, p_{2}, \cdots, p_{n}\right), p_{k} \in\{0,1\}, k=1,2, \cdots, n\right\}$. For any elements $\beta=\left(x_{1}, x_{2}, \cdots, x_{n}\right)$ and $\gamma=\left(y_{1}, y_{2}, \cdots, y_{n}\right)$ in the set $S_{n}$, the following conditions are satisfied:
(1) If $\beta=\gamma$, then $\sum_{i=1}^{n} x_{i} y_{i}$ is odd;
(2) If $\beta \neq \gamma$, then $\sum_{i=1}^{n} x_{i} y_{i}$ is even.
(1) When $n=5$, find the maximum number of elements in the set $S_{5}$;
(2) When $n \geqslant 6$, find the maximum number of elements in the set $S_{n}$.

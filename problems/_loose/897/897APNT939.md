In the 8th century AD, there was a problem that circulated in our country, supposedly proposed by a monk:

A Go board has 361 positions, which can be occupied by a black stone, a white stone, or left empty. How many different possible situations are there?

Clearly, this is a problem of repeated permutations, which involves 361 selections from the set $\{$ black stone, white stone, empty $\}$. Therefore, there are $3^{361}$ possible situations.

Through the above discussion, we can summarize a counting method for repeated permutations:

If $k$ selections are made sequentially from the same $n$-element set, and selected elements can be chosen again, then there are $n^{k}$ different ways of selection (i.e., repeated permutation ways).

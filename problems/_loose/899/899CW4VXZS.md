Find all quadratic polynomial $p(x)$ with rational coefficient such that the set of all roots of $p(x)$ is the same as the set of all coefficients of $p(x)$ .

Examples:
1. If $p(x) = x^2 - 3x + 2$ , then the set of all roots of $p(x)$ is $\{1, 2\}$ and the set of all coefficient of $p(x)$ is $\{1, -3, 2\}$ . This polynomial doesnt satisfies the problem condition.
2. If $p(x) = x^2$ , then the set of all roots of $p(x)$ is $\{0\}$ and the set of all coefficient of $p(x)$ is $\{0, 1\}$ , since $p(x) = x^2+0x+0$ .This polynomial also doesnt satisfies the problem condition.

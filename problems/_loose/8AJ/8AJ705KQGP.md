Let $\left\{A_{1}, A_{2}, A_{3}, \cdots \cdots A_{n}\right\}$ be the set of $n$ vertices of a polygon inscribed in a circle. (1) Which is more, the subsets of this set that contain the element $A_{1}$ or those that do not contain $A_{1}$? (2) Among the polygons with vertices from $\left\{A_{1}, A_{2} \cdots \cdots A_{n}\right\}$, which are more, the polygons that contain the vertex $A_{1}$ or those that do not contain the vertex $A_{1}$?

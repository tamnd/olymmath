On a plane, a convex pentagon $A B C D E$ is drawn. We construct point $A_{1}$, symmetric to point $A$ with respect to point $B$, point $B_{1}$, symmetric to point $B$ with respect to $C, \ldots$, point $E_{1}$, symmetric to point $E$ with respect to point $A$, and then erase the pentagon $A B C D E$. Prove that using a compass and a straightedge, knowing the positions of points $A_{1}, B_{1}, C_{1}, D_{1}, E_{1}$, one can reconstruct the pentagon $A B C D E$.

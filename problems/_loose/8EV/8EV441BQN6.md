A natural number will be called magical if and only if it can be expressed as the sum of two three-digit numbers written with the same digits but in reverse order. For example, the number 1413 is magical because $1413=756+657$; the smallest magical number is 202.

a) Determine the number of all magical numbers.

b) Show that the sum of all magical numbers is equal to 187000.

Given 2002 boxes, each containing some pebbles. In addition to these, an unlimited number of pebbles are available. In one step, we can place 1 pebble in each of any $k$ boxes. Is it possible to achieve, after a certain number of steps, that each box contains the same number of pebbles, if
a) $k=8$
b) $k=9$ ?

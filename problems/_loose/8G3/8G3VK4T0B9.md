Initially, 250 letters are written in a row - 125 letters A and 125 letters B in some order. Then, in one operation, you can take any segment of consecutive letters, where there are an equal number of letters A and B, and reverse the order of the letters in this segment, swapping all A's to B's and all B's to A's in this segment. (For example, from the string ABABBAAB, one operation can result in ABBAABAB.) Is it possible to write the initial string and perform several operations so that the resulting string is the same as the original string, but written in reverse order?

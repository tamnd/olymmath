Given a positive integer $n>1$. A mint needs to cast a set of $n$ different coin values $a_{1}, a_{2}, \cdots, a_{n}$, where $a_{i}$ is a positive integer (there are infinitely many coins of each value). If the set of values $\left\{a_{1}, a_{2}, \cdots, a_{n}\right\}$ satisfies: the sum of the values $a_{1}+a_{2}+\cdots+a_{n}$ can only be given in one unique way (i.e., using one coin of each value), then this set of values is called "lucky". Prove:
(1) There exists a set satisfying
$$
a_{1}+a_{2}+\cdots+a_{n} < n \cdot 2^{n-1}.
$$

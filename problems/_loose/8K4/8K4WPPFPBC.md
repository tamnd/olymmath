Let $S$ be the set of positive integers. For any $a$ and $b$ in the set we have $G C D(a, b)>1$. For any $a, b$ and $c$ in the set we have $G C D(a, b, c)=1$. Is it possible that $S$ has 2012 elements?

$\operatorname{GCD}(x, y)$ and $\operatorname{GCD}(x, y, z)$ stand for the greatest common divisor of the numbers $x$ and $y$ and numbers $x, y$ and $z$ respectively.

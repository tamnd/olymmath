\section*{Problem 3A - 311043A}

Let $f$ be a function defined for all positive integers $n$ and only for these, and whose function values $f(n)$ are all integers. Furthermore, it is assumed that for all positive integers $m, n$, the equation $f(f(m)+f(n))=m+n$ holds.

Determine all the numbers that can occur as the function value $f(1992)$ for such a function $f$.

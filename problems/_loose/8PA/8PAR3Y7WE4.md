\section*{Problem 3A - 111043A}

Let $A B C D$ be a convex kite with $A B = A D > B C = C D$. Furthermore, let $F$ be a point on $A B$ between $A$ and $B$ such that $A B : B C = B C : F B$.

Finally, let $E$ be the point inside $A B C D$ such that $E C = B C (= C D)$ and $F E = F B$.

Prove that $E$ lies on the perpendicular dropped from $D$ to the line through $A$ and $B$!

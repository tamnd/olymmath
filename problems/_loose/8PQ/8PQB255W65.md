Let $M \subset M_{3}\left(\mathbb{R}_{+}^{*}\right)$ be the set of matrices that have all elements on the main diagonal equal, and the product of the elements in each row and each column is equal to 1.

a) Provide an example of a matrix in $M$ that does not have all elements as rational numbers;

b) Prove that $\operatorname{det}(A) \geq 0, \forall A \in M$.

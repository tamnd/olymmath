For any two sets $A$ and $B$, let $A \Delta B = (A \cap \bar{B}) \cup (\bar{A} \cap B)$.
Given a natural number $n$ greater than 3, let the set $S = \{1, 2, \cdots, n\}$. Can all the subsets of the set $S = \{1, 2, \cdots, n\}$ be arranged in a sequence such that for any two adjacent subsets $A$ and $B$, it satisfies $|A \Delta B| = 3$? Prove your conclusion.

a) Investigate whether there exist real numbers $a \neq 0, b$, and $c$ such that the function $f$ defined for all real $x$ by

$$
f(x)=a x^{4}+b x^{2}+c
$$

has the function values $f(0)=1, f(2)=1$ and has a local extremum at $x=1$!

b) Given two arbitrary real numbers $x_{1}$ and $x_{2}$ with $0<x_{1}<x_{2}$.

Determine (in dependence on $x_{1}$ and $x_{2}$) all real $a \neq 0, b, c$ with the property that the function $f$ defined by (1) has the function values $f(0)=1, f\left(x_{2}\right)=1$ and has a local extremum at $x=x_{1}$!

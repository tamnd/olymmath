Let $x_{1}, x_{2}, \ldots, x_{n}$ all be positive numbers, prove:
(i) If $x_{1}+x_{2}+\cdots+x_{14}=c$, then the product $x_{1} x_{2} \cdots x_{n}$ has the maximum value $\left(\frac{c}{n}\right)^{n}$ when $x_{1}=x_{2}=\cdots=x_{n}=\frac{c}{n}$.
(ii) If $x_{1} x_{2} \cdots x_{n}=c$, then the sum $x_{1}+x_{2}+\cdots+x_{n}$ has the minimum value $n\sqrt[n]{c}$ when $x_{1}=x_{2}=\cdots=x_{n}=\sqrt[n]{c}$.

Let $y=f(x)$ be a function defined on $D$, for any $x \in D$, there is $|f(x)| \leqslant M$ (where $M \in \mathbf{R}^{+}$). Then $f(x)$ is called a bounded function on the domain $D$. Prove:
$$
(n-1) M^{n}+\prod_{i=1}^{n} f\left(x_{1}\right) \geqslant M^{n-1} \sum_{i=1}^{n} f\left(x_{1}\right),
$$

where $x_{1} \in D(i=1,2, \cdots, n)$, equality holds if and only if $f\left(x_{1}\right)=M(i=1,2, \cdots, n)$.

\section*{Problem 3B - 151043B}

In a plane with rectangular Cartesian coordinates $(x ; y)$, let the points $F_{1}(\sqrt{2} ; \sqrt{2})$ and $F_{2}(-\sqrt{2} ;-\sqrt{2})$ and the graph $k$ of the function $f$ be given, which is defined for all real $x \neq 0$ by $f(x)=\frac{1}{x}$.

Prove:

There exists a number $c$ such that $k$ in the xy-plane is the set of all points in the xy-plane for which the absolute value of the difference of the distances to the points $F_{1}$ and $F_{2}$ is equal to $c$. Determine this number $c$!

Let the function $f: R \rightarrow R$ be defined as follows: if $x$ is irrational, then $f(x)=0$; if $p \in Z, q \in Z$, and the fraction $\frac{p}{q}$ is in lowest terms, then
$$
f\left(\frac{p}{q}\right)=\frac{1}{q^{3}} .
$$

Prove: This function is differentiable at each point $x=\sqrt{k}$, where $k$ is a natural number but not a perfect square.

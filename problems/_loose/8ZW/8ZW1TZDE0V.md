Gnomes and the Thunderstorm. In a terrible thunderstorm, n gnomes are climbing up a rope ladder in a chain. If there is a thunderclap, each gnome, independently of the others, may fall with probability $p(0<p<1)$. If a gnome falls, they knock down all the gnomes below them. Find:

a) The probability that exactly $k$ gnomes will fall.

b) The expected number of gnomes that will fall.

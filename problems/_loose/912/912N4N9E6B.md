Let $G, G^{*}$ be dual plane graphs. Prove the following conclusions:
(i) If $G$ is 2-connected, then $G^{*}$ is also 2-connected;
(ii) If $G$ is 3-connected, then $G^{*}$ is also 3-connected;
(iii) If $G$ is 4-connected, then $G^{*}$ is not necessarily 4-connected.

A woodpecker visited 50 tree branches in one day. On the first branch, it pecked once, on the second branch, it pecked twice, and so on until on the 50th branch, it pecked 50 times. The woodpecker gets dizzy if it pecks 999 times in a day. Answer the following questions:

a) Did the woodpecker get dizzy that day?

b) How many times did it peck when it got dizzy?

c) How many times did it peck on the branch where it got dizzy?

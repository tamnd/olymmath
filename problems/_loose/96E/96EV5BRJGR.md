For connected multigraphs $G=(V, E)$ and $G^{\prime}=\left(V^{\prime}, E\right)$ with the same edge set, prove that the following statements are equivalent:
(i) $G$ and $G^{\prime}$ are abstract duals of each other;
(ii) For any set $F \subseteq E$, the multigraph $(V, F)$ is a tree if and only if $\left(V^{\prime}, E \backslash F\right)$ is a tree.

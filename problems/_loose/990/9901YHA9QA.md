Let $M \subseteq \{1,2, \cdots, 2011\}$. If $M$ satisfies: for any three elements $a, b, c$, it holds that $a b \neq c$, then $M$ is said to have property $P$. For convenience, we denote $M \in P$. A set with property $P$ that contains the maximum number of elements is called a maximal set. How many maximal sets with property $P$ are there? Provide a proof.

In a small town, there is only one tram line. It is circular, and trams run along it in both directions. There are stops on the loop: Circus, Park, and Zoo. The journey from Park to Zoo via Circus is three times longer than not via Circus. The journey from Circus to Zoo via Park is twice as short as not via Park. Which route from Park to Circus is shorter - via Zoo or not via Zoo - and by how many times?

(A.V. Shapovalov)

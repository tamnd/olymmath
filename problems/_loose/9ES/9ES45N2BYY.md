Let the function be:
$$
\begin{array}{l}
f(x)=\left\{\begin{array}{ll}
1, & \text { when }|x| \leqslant 1 \text {, } \\
0, & \text { when }|x|>1 \text {, }
\end{array} g(x)=\left\{\begin{array}{ll}
2-x^{2}, & \text { when }|x| \leqslant 1 \text {, } \\
2, & \text { when }|x|>1 \text {, }
\end{array}\right.\right. \\
\text { Find } f[f(x)], f[g(x)], g[f(x)], g[g(x)] \text {. } \\
\end{array}
$$

Find all values of the parameter $a$ for which the equation

$$
\frac{|\cos t-0.5|+|\sin t|-a}{\sqrt{3} \sin t-\cos t}=0
$$

has at least one solution on the interval $[0 ; \pi / 2]$. Specify the number of distinct solutions of this equation on the interval $[0 ; \pi / 2]$ for each found value of the parameter $a$. (12 points)

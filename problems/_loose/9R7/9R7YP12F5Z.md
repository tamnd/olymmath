A finite set $K_{0}$ is given on a plane (or in space). To it are added all points that can be obtained by symmetric reflection of one point of this set relative to another. The resulting set is denoted as $K_{1}$. Similarly, from the set $K_{1}$, $K_{2}$ is obtained, from $K_{2}$ - $K_{3}$, and so on.

a) Let the set $K_{0}$ consist of two points $A$ and $B$ at a distance of 1. For what smallest $n$ will the set $K_{n}$ contain a point at a distance of 1000 from point $A$?

b) Let $K_{0}$ consist of the three vertices of an equilateral triangle with an area of 1. Find the area of the smallest convex polygon containing the set $K_{n}$ (for $n=1,2, \ldots$).

In the following parts, $K_{0}$ is a set of four points that are the vertices of a regular tetrahedron with a unit volume.

c) Consider the smallest convex polyhedron containing all points of the set $K_{1}$. How many and what types of faces does this polyhedron have?

d) What is the volume of this polyhedron?

e)* Find the volume of the smallest convex polyhedron containing the sets $K_{n}$ (for $n=2,3, \ldots$).

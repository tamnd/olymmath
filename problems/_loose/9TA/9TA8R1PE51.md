In the cells of a $15 \times 15$ table, the numbers $1, 2, \ldots, 15$ are written. In each row and each column, each of these numbers appears exactly once. In cells symmetric with respect to the main diagonal of the table (running from the top left to the bottom right), the same numbers are written. Prove that all numbers are represented on the main diagonal.

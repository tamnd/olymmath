(1) Determine the constant numbers $ a,\ b,\ c,\ p,\ q,\ r,\ s$ such that the following equation is equality.

$ \ \ \ \ \ 4x = \{a(x + 1)^2 + b(x + 1) + c\}(x^2 + 1)^2 + \{(px + q)(x^2 + 1) + (rx + s)\}(x + 1)^3$.

(2) Evaluate the following definite integrals.

$ (a) \int_0^1 \frac {dx}{x + 1}\ \ \ \ \ \ \ \ \ (b)\ \int_0^1 \frac {dx}{(x + 1)^2}\ \ \ \ \ (c)\ \int_0^1 \frac {dx}{(x + 1)^3}$

$ (d) \int_0^1 \frac {x}{x^2 + 1}\ dx\ \ \ \ (e)\ \int_0^1 \frac {dx}{x^2 + 1}\ \ \ \ \ \ \ (f)\ \int_0^1 \frac {x}{(x^2 + 1)^2}\ dx$

$ (g) \int_0^1 \frac {dx}{(x^2 + 1)^2}\ \ \ \ (h)\ \int_0^1 \frac {4x}{(x + 1)^3(x^2 + 1)^2}\ dx$

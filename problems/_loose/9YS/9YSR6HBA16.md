A workshop has several machines. It is known that each worker in the workshop can operate exactly $k$ machines, and each machine is operable by exactly $k$ people. Prove: The workshop supervisor can always make appropriate arrangements so that each worker operates a machine they can operate, and each machine is assigned someone to operate it.

(Australia, 82). Find all numbers $d \in(0 ; 1]$, possessing the following property: if $f(x)$ is any continuous function defined for $x \in[0 ; 1]$, and $f(0)=f(1)$, then there exists a number $x_{0} \in[0 ; 1-d]$, such that

$$
f\left(x_{0}\right)=f\left(x_{0}+d\right)
$$

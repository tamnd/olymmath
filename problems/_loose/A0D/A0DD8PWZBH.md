Denote by $\mathbb{Q^+}$ the set of all positive rational numbers. Determine all functions $f:\mathbb{Q^+}\to\mathbb{Q^+}$ which satisfy the following equation for all
$x,y \in \mathbb{Q^+} : f(f(x)^2.y)=x^3.f(xy)$.

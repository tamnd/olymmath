Sets $A$ and $B$ are composed of all five-digit numbers that satisfy the following conditions: For every number in set $A$, the sum of its digits, when increased by 1 or decreased by 1, is a multiple of 5; For every number in set $B$, the sum of its digits is either a multiple of 5 or becomes a multiple of 5 when decreased by 2. Prove: The number of elements in set $A$ is equal to the number of elements in set $B$.

Let there be 3 sets $A, B, C$ defined as follows: Set $A$ represents all different ways to add 3 pairs of parentheses to the product of 5 numbers $a_{1} a_{2} a_{3} a_{4} a_{5}$; Set $B$ represents all different ways to divide a convex hexagon into 4 triangles; Set $C$ represents all arrangements of 4 black balls and 4 white balls in a row such that at any position, the number of white balls is not less than the number of black balls. Prove that $|A|=|B|=|C|$.

Professor Baltazar has a machine that is programmed in the following way:

$>$ a natural number $n$ is written into the machine (zero is not a natural number),

$>$ if the number $n$ is even, the machine divides it by 2 and prints the result, and

$>$ if the number $n$ is odd, the machine multiplies it by 3, adds 1 to the resulting number, and prints the result.

Professor Baltazar wrote a number into the machine, then wrote the printed result back into the machine, and repeated this process several times. After the sixth entry, the machine printed the number 4. Determine all possible initial values that Professor Baltazar could have written into the machine.

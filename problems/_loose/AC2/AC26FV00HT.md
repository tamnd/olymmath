In $\triangle A B C$, prove:
(1) $\sin n A+\sin n B+\sin n C$
$=4 \sin \frac{n \pi}{2} \cos \frac{n A}{2} \cos \frac{n B}{2} \cos \frac{n C}{2}, n$ is odd;
(2) $\sin n A+\sin n B+\sin n C$
$=-4 \cos \frac{n \pi}{2} \sin \frac{n A}{2} \sin \frac{n B}{2} \sin \frac{n C}{2}, n$ is even;
(3) $\cos n A+\cos n B+\cos n C$
$=1+4 \sin \frac{n \pi}{2} \sin \frac{n A}{2} \sin \frac{n B}{2} \sin \frac{n C}{2}, n$ is odd;
(4) $\cos n A+\cos n B+\cos n C$
$=-1+4 \cos \frac{n \pi}{2} \cos \frac{n A}{2} \cos \frac{n B}{2} \cos \frac{n C}{2}, n$ is even.

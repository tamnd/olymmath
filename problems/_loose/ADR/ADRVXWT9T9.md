Let $ Z $ denote the set of all integers. Prove that for any integers $ A, B $, there exists an integer $ C $ such that the set $ M_{1}=\left\{x^{2}+A x+B \mid x \in Z\right\} $, and the set $ M_{2}=\left\{2 x^{2}+2 x+C \mid x \in Z\right\} $ are disjoint.
(36th International Mathematical Olympiad Preliminary Problem, 1995)

There are many cubes of the same size, painted in six colors. Each cube is painted in all six colors, each face in its own color, but the arrangement of colors on different cubes can be different. The cubes are laid out on a table to form a rectangle. It is allowed to take any column of this rectangle, rotate it around its long axis, and put it back in place. The same is allowed to be done with rows. Is it always possible to achieve, using such operations, that all cubes will be facing up with faces of the same color?

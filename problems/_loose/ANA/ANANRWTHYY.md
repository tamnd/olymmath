Let $A$ be an infinite set of positive integers. It is known that if we take any finite subset $B$ of the set $A$, there exists a positive integer $b$ greater than 1 such that $b$ divides all the elements of the set $B$. Prove that there exists a positive integer $d$ greater than 1 that divides all the elements of the set $A$.

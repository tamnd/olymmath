Given $n \geqslant 2, n \in \mathbf{N}^{\cdot}$, set $M=\{1,2, \cdots, 2 n\}$, define function $f:\{M$'s $n-1$ element subsets $\} \rightarrow M$. Prove: regardless of how $f$ is defined, there always exists an $n$-element subset $T$ of $M$, such that for any $k \in T$, we have $f(T \backslash\{k\}) \neq k$.

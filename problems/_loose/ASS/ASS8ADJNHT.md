a) Can any six-digit number starting with the digit 5 be extended by adding 6 more digits so that the resulting 12-digit number is a perfect square?

b) The same question for a number starting with 1.

c) Find for each $n$ the smallest $k=k(n)$ such that any $n$-digit number can be extended by adding $k$ more digits so that the resulting $(n+k)$-digit number is a perfect square.

A $100 \times 100$ grid paper is colored with 100 colors, where each cell is either colored with one of these colors or left uncolored. If all the colored cells in each row and each column are of different colors, the coloring is considered valid. If (1) $100^{2}-1$, (2) $100^{2}-2$, (3) 100 cells have already been colored in a valid way, can the remaining cells be colored so that the entire grid paper is validly colored?

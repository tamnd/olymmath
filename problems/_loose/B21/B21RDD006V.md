\section*{Problem 6A - 161236A}

For each real number $x$ with $0 < x \leq \frac{\pi}{2}$, in a plane right-angled Cartesian coordinate system, a circle is drawn through the points $P(0 ; 1)$, $Q(x ; \cos x)$, and $R(-x ; \cos (-x))$.

a) Provide a function $f$ such that for each of these numbers $x$, the mentioned circle has the radius $r = f(x)$.

b) Calculate $\lim _{x \rightarrow \infty} f(x)$, if this limit exists.

c) Determine the range of the function $f$ with the set of all numbers $x$ for which $0 < x \leq \frac{\pi}{2}$ holds, as the domain.

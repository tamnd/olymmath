${ }^{+}$ Prove: The automorphisms of a graph $G=(V, E)$ act naturally on its ends, i.e., each automorphism $\sigma: V \rightarrow V$ can be extended to a map $\sigma: \Omega(G) \rightarrow \Omega(G)$ such that if $R$ is a ray in the end $\omega$, then $\sigma(R) \in \sigma(\omega)$. Prove: If $G$ is connected, then each automorphism $\sigma$ of $G$ fixes either a finite set of vertices or an end. If $\sigma$ does not fix a finite set of vertices, can it fix more than one end? At least three ends?

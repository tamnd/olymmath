Each of the 777 bankers has several safes. At a meeting, the Chief Oligarch gave each banker N diamonds and ordered them to distribute them among the safes so that each safe contains a different number of diamonds. The Chief Oligarch is certain that this task is feasible. Prove that the bankers can keep no more than two safes (and destroy the rest) so that the Chief Oligarch's task remains feasible (with the same value of N).

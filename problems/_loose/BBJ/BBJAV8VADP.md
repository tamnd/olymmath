The function $f$ is defined on the interval $0 \leq x \leq 1$, and $0 \leq f(x) \leq 1$. Show that if

$$
f(x)+f(y)=f(f(x)+y)
$$

for all pairs $(x ; y)$ for which both sides are defined, then $f(f(x))=f(x)$.

Prove that for all positive integers $n \geqslant 4$, there exists a set $S$ satisfying the following conditions:
(1) $S$ consists of $n$ positive integers, all less than $2^{n^{-1}}$;
(2) For any two distinct non-empty subsets $A$ and $B$ of $S$, the sum of the elements in set $A$ is not equal to the sum of the elements in set $B$.

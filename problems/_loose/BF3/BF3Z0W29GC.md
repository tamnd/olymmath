In a notebook, several numbers are written. It is allowed to append to the already written numbers any number equal to the arithmetic mean of two or more of them, provided that it is different from all the already written ones. Prove that, starting with the two numbers 0 and 1, using such additions, one can obtain:

a) the number $1 / 5$;

b)* any rational number between 0 and 1.

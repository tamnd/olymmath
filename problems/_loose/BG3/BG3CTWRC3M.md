In a $10 \times 10$ table, you need to record the digits $0,1,2,3, \ldots, 9$ in some order, so that each digit appears 10 times.

a) Can this be done in such a way that in each row and each column there are no more than four different digits?

b) Prove that there will be a row or column in which there are no fewer than four different numbers.

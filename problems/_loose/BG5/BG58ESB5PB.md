Given a finite number of cities, some of which are connected by bidirectional flights. Now, change each bidirectional flight to a unidirectional flight in some direction. Question: Is it possible to achieve the following result: for each city, the number of flights originating from it and the number of flights terminating at it differ by at most 1?

Ali defines a *pronunciation* of any sequence of English letters to be a partition of those letters into substrings such that each substring contains at least one vowel. For example, $\text{A } \vert \text{ THEN } \vert \text{ A}$, $\text{ATH } \vert \text{ E } \vert \text{ NA}$, $\text{ATHENA}$, and $\text{AT } \vert \text{ HEN } \vert \text{ A}$ are all pronunciations of the sequence $\text{ATHENA}$. How many distinct pronunciations does $\text{YALEMATHCOMP}$ have? (Y is not a vowel.)

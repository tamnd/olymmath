(Basic Theorem) Let $A, B, C, D$ be four distinct points in the same plane. $A D \cap B C = E, A B \cap D C = F, A C \cap B D = G$. (Such a figure is called a complete quadrilateral $ABCD$.) Let $E G \cap A B = H, E G \cap C D = I$. Prove: $A, H, B, F$ and $D, I, C, F$ are both harmonic ranges.

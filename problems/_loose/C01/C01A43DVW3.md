Draw a straight line. If we need to draw a circle, we use a compass. However, if we want to draw a straight line, we need a ruler or some other object with a straight edge. In other words, to draw a straight line, we look for another straight line, which is similar to using a coin, a saucer, or another round object when drawing a circle. Now imagine that you don't have any straight-edged objects or even a piece of string at hand. Could you come up with a simple tool that would allow you to draw straight lines, similar to how a compass is used to draw circles?

This question is interesting in itself, but it has no practical value. We will still use a straight edge.

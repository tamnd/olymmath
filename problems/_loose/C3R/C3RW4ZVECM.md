Given is a square $A B C D$ with side length 4. Determine the largest natural number $k$ such that, for any arrangement of $k$ points strictly inside the square $A B C D$, there always exists a square with side length 1, contained within the square $A B C D$ (whose sides do not have to be parallel to the sides of the square $A B C D$), in whose strict interior none of the observed $k$ points lie.

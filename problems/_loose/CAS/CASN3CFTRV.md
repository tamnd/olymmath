We fix an integer $n \geq 2$ and consider numbers $a_{1}, \ldots, a_{n}$ such that $-\frac{1}{2} \leq a_{i} \leq \frac{1}{2}$ for all $1 \leq i \leq n$. We assume that if we remove any one of these numbers, the sum of the remaining $n-1$ numbers is always an integer.

(1) If $n$ is even, show that $a_{1}=a_{2}=\cdots=a_{n}$.

(2) If $n$ is odd, do we always have $a_{1}=a_{2}=\cdots=a_{n}$?

Similar events. If a die is thrown, then the event $A=\{1,2,3\}$ consists of one of the faces 1, 2, or 3 appearing. Similarly, the event $B=\{1,2,4\}$ is favorable if the faces 1, 2, or 4 appear.

A die is thrown 10 times. It is known that the event $A$ occurred exactly 6 times.

a) (from 8th grade. 2 points) Find the probability that, under this condition, the event $B$ did not occur at all.

b) (from 9th grade. 3 points) Find the expected value of the random variable $X$ "The number of occurrences of event $B$".

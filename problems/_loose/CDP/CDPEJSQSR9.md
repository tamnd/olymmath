(Gerhard J. Woeginger) For a given integer $n \geq 4$, we investigate whether there exists a table with three rows and $n$ columns that can be filled with the numbers 1, 2, ..., 3n such that

- the same sum $z$ is achieved in each row and
- the same sum $s$ is achieved in each column.

Show:

(a) If $n$ is even, there is no such table.

(b) For $n=5$, there is such a table.

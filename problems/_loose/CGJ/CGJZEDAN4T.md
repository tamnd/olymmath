In an $n \times n$ table, it is allowed to add 1 to all numbers along any non-self-intersecting closed rook path. In the initial table, ones were placed along the diagonal, and all other cells were zeros. Is it possible to achieve, using several allowed transformations, that all numbers in the table become equal? (It is assumed that the rook has visited all cells of the table through which its path passes.)

$A B C D$ is a trapezium inscribed in a circle centred at $O$. It is given that $A B \| C D, \angle C O D=$ $3 \angle A O B$, and $\frac{A B}{C D}=\frac{2}{5}$.

Find the ratio
$$
\frac{\text { area of } \triangle B O C}{\text { area of } \triangle A O B} \text {. }
$$
(A) $\frac{3}{2}$;
(B) $\frac{7}{4}$;
(C) $\frac{\sqrt{3}}{\sqrt{2}}$;
(D) $\frac{\sqrt{5}}{2}$;
(E) $\frac{\sqrt{7}}{\sqrt{2}}$

The circus arena is illuminated by $n$ different spotlights. Each spotlight illuminates a convex shape. It is known that if any one spotlight is turned off, the arena will still be fully illuminated, but if any two spotlights are turned off, the arena will not be fully illuminated. For which $n$ is this possible?

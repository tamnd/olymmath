a) $x^{3}-3 x+2 \geq 0, \forall x \in[0, \infty)$

b) If $a, b, c \in(0, \infty)$ and $\frac{1}{a}+\frac{1}{b}+\frac{1}{c} \leq 3$, then $a^{2}+b^{2}+c^{2} \geq 3$.

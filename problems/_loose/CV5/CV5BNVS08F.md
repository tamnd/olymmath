Prove that for any numbers $a_{1}, \ldots, a_{m} \in \mathbf{N}$:

a) (Jury, PNR, 79) there exists a set of $n<2^{m}$ numbers, in which all subsets have different sums of numbers, and among these sums are all numbers $a_{1}, \ldots, a_{m}$
b) there exists a set of $n \leqslant m$ numbers, in which all subsets have different sums of numbers, and among these sums are all numbers $a_{1}, \ldots, a_{m}$.

4.22*. (Jury, PNR, 83). Does there exist a set $\mathbf{M \subset N}$, satisfying the following two conditions:

1) any number $n \in \mathbf{N}$, greater than 1, can be represented as $n=a+b$, where $a, b \in M$
2) if each of the numbers $a, b, c, d \in M$ is greater than 10, then the equality $a+b=c+d$ is possible only in the case $a=c$ or $a=d$?

In an $n \times n$ table $T$, we have written a number in each cell such that no number appears twice in any row. Prove that the numbers in $T$ can be rearranged so that in the rearranged table $T^{*}$, each row contains exactly the same numbers as the corresponding row in $T$, but no number appears twice in any column of $T^{*}$.

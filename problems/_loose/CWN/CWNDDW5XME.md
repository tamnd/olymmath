Let $P$ be a set of nine points in the Cartesian coordinate plane, no three of which lie on the same line. Call an ordering $\{Q_1, Q_2, \ldots, Q_9\}$ of the points in $P$ *special* if there exists a point $C$ in the same plane such that $CQ_1 < CQ_2 < \cdots < CQ_9$. Over all possible sets $P,$ what is the largest possible number of distinct special orderings of $P?$

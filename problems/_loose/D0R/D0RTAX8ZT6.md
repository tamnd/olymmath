A graph is called an interval graph if there exists a set of real intervals $\left\{I_{v} \mid v \in V(G)\right\}$, such that $I_{u} \cap I_{v} \neq \emptyset$ if and only if $u v \in E(G)$.
(i) Prove: Every interval graph has a chord.
(ii) Prove: The complement of every interval graph is a comparability graph.
(Conversely, if the complement of a chordal graph is a comparability graph, then this chordal graph is an interval graph, as proved by Gilmore and Hoffman (1964).)

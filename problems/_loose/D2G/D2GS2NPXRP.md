Each field of a $9 \times 9$ board is colored either blue or red. A row is said to be predominantly red if it has more red than blue fields, and a column is said to be predominantly blue if it has more blue than red fields. Let $C$ be the number of predominantly red rows, and $P$ be the number of predominantly blue columns.

a) Can it be that $C+P=18$?

b) Can it be that $C+P=17$?

c) Can it be that $C+P=16$?

Let $f$ be a quadratic function which satisfies the following condition. Find the value of $\frac{f(8)-f(2)}{f(2)-f(1)}$.

For two distinct real numbers $a,b$, if $f(a)=f(b)$, then $f(a^2-6b-1)=f(b^2+8)$.

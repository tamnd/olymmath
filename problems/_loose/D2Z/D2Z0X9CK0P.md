Let $S=\{1,2,3,4\}$, and an $n$-term sequence: $a_{1}, a_{2}, \cdots, a_{n}$ has the following property: for any non-empty subset $B$ of $S$ (the number of elements in $B$ is denoted by $|B|$), there are $|B|$ consecutive terms in the sequence that exactly form the set $B$. Find the minimum value of $n$.

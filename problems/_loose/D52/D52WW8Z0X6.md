Prove:

a) If there is a sphere $K$ that touches all six edges of a tetrahedron $A B C D$, then:

$$
A B + C D = A C + B D = A D + B C
$$

b) If (1) holds for a tetrahedron $A B C D$, then there is a sphere $K$ that touches all six edges of the tetrahedron.

Definition: A sphere $K$ touches a segment $s$ if and only if $K$ touches the line containing $s$ and the point of tangency lies on $s$.

For the letters $a, b, c, d, e, f$, natural numbers are to be inserted in the following tasks (1) to (6) so that correct equations result. The same letters should represent the same numbers, and different letters should represent different numbers.

(1) $a+b+c=21$,

(2) $b \cdot c=42$,

(3) $c+d=70: b$,

(4) $e: a=d$,

(5) $c=54: 9$,

(6) $a+b+c+d+e+f=60$

Find such an assignment and verify that it meets all the requirements!

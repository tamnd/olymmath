Let $f(x)$ be a differentiable function. Find the following limit value:

$$\lim_{n\to\infty} \dbinom{n}{k}\left\{f\left(\frac{x}{n}\right)-f(0)\right\}^k.$$

Especially, for $f(x)=(x-\alpha)(x-\beta)$ find the limit value above.

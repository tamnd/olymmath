A Lame Rook (this is a rook that can move only horizontally or only vertically exactly one square) has traversed a $10 \times 10$ board, visiting each square exactly once. In the first square the rook visited, we write the number 1, in the second square the number 2, in the third square the number 3, and so on up to 100. Could it be that the sum of the numbers written in two adjacent squares (sharing a side) is divisible by 4?

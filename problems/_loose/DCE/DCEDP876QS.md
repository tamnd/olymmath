Let $\xi$ be a non-negative random variable with a distribution function $F=F(x)$ such that $F(0)<1$ and the right derivative $F_{+}^{\prime}(0)=\lambda$ exists. Show that

$$
\text { the variable } \xi \text { is exponential } \Leftrightarrow \xi \wedge \eta \stackrel{d}{=} \xi / 2,
$$

where $\eta-$ is an independent copy of the variable $\xi$.

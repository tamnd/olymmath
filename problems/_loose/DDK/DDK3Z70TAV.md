(1975 Kyiv Mathematical Olympiad) Two people write a $2k$-digit number using the digits $1,2,3,4,5$. The first person writes the first digit, the second person writes the second digit, the third digit is written by the first person again, and so on. Can the second person ensure that the resulting number is divisible by 9, despite the first person's attempts to interfere? Discuss the following two cases:
(1) $k=10$.
(2) $k=15$.

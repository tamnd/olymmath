(Jury, PDR, 82). On an infinite chessboard in all directions, where initially tokens are placed exactly covering a rectangle of size $3 k \times n$, a game proceeds according to the following rules: any token can jump over any adjacent (vertically or horizontally) token, provided that the next cell is unoccupied, after which the token that was jumped over must be removed from the board. Prove that it is impossible for exactly one token to remain on the board.

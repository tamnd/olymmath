100 cubes are arranged in a row: 77 black and 23 white. They are approximately evenly distributed, i.e., if any number of consecutive cubes are marked in one place and the same number of consecutive cubes are marked in another place, the number of black cubes in the first set differs from the number of black cubes in the second set by no more than 1; moreover, if the first set is at the left edge, the number of black cubes in it is not greater than in the second set, and if the first set is at the right edge, the number of black cubes in it is not less than in the second set. Prove that if another set of 77 black and 23 white cubes is arranged so that the same conditions are met, then the white cubes will stand in the same places.

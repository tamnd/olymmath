In space, there are 200 points. Each pair of them is connected by a segment, and the segments do not intersect each other. Each segment is painted in one of $K$ colors. Petya wants to paint each point in one of these colors so that there are no two points and a segment between them, all painted in the same color. Will Petya always succeed if
a) $K=7$;
b) $K=10$?

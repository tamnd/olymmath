A $0-1$ sequence refers to a sequence where each term has two possible values: 0 or 1. If in a $0-1$ sequence, each term has at least one adjacent position that is 1, then it is called a "great $0-1$ sequence". For example, the sequence $0,1,1,0,0$, $1,1,1$ is an eight-term great $0-1$ sequence. Let $B_{n}$ represent the number of $n$-term great $0-1$ sequences. Find the smallest integer $n(n \geqslant 2)$ such that $B_{n}$ is divisible by 20. ${ }^{[1]}$

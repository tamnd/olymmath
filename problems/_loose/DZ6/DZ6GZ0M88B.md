Given quadratic trinomials $f_{1}(x), f_{2}(x), \ldots, f_{100}(x)$ with the same coefficients for $x^{2}$, the same coefficients for $x$, but different constant terms; each of them has two roots. For each trinomial $f_{i}(x)$, one root was chosen and denoted by $x_{i}$. What values can the sum $f_{2}\left(x_{1}\right)+f_{3}\left(x_{2}\right)+\ldots+f_{100}\left(x_{99}\right)+f_{1}\left(x_{100}\right)$ take?

Four friends, Axel, Bodo, Christian, and Dieter, bought a boat. They agreed that each of them should conduct one of the first four trips. When determining the order of these trips, they expressed the following wishes:

1. If Dieter should go first, Christian wanted to go third.

2. If Axel or Dieter should go second, then Christian wanted to go first.

3. Then and only then, if Axel should go third, Bodo wanted to go second.

4. If Dieter should go third, then Axel wanted to go second.

5. If Dieter should go last, then Christian wanted to go third and Axel wanted to go first.

Determine all possible orders in which the first four trips can be conducted so that these wishes are fulfilled!

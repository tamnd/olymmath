\section*{Problem 3A - 131043A}

a) Prove that for a given real $x_{0}$, the number $x_{0}^{2}+x_{0}+1$ can be determined graphically using the following method!

In a rectangular coordinate system with the origin $O$, construct the square $O P E Q$ such that $E$ has coordinates $(1 ; 1)$ and $Q, E$ lie on a line $q$ parallel to the x-axis.

On $q$, mark a point $X$ such that the directed segment $E X$ has the length $x_{0}$, taking into account the sign of $x_{0}$. At point $X$, draw a perpendicular to the line through $P$ and $X$; it intersects the y-axis at a point $Y$. Then, $Y$ has the ordinate $x_{0}^{2}+x_{0}+1$, which is the number to be determined.

b) Prove using this graphical method that the function $f(x)=x^{2}+x+1$ defined for all real $x$ has no real roots!

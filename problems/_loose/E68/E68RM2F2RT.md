Given $n$ points on a circle. The numbers $1,2, \ldots, n$ are written in some arbitrary order next to the given points (one number next to each point). For each pair of adjacent points, the absolute value of the difference of the numbers written next to the points is defined. Prove that the sum of these absolute values is greater than or equal to $2(n-1)$.

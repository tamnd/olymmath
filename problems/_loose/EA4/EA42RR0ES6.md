We equip the plane with an orthonormal coordinate system and color each point with integer coordinates red or blue. Show that we can find a rectangle whose sides are parallel to the axes and whose four vertices are integer-coordinate points of the same color.

Sometimes, we have to resort to an infinite version of the pigeonhole principle: if we put an infinite number of objects into a finite number of drawers, there will be a drawer that contains an infinite number of objects.

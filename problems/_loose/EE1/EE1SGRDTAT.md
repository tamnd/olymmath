Easy Numbers. In the city where the Absent-Minded Scientist lives, telephone numbers consist of 7 digits. The Scientist easily remembers a telephone number if the number is a palindrome, that is, it reads the same from left to right and from right to left.

For example, the number 4435344 the Scientist remembers easily, because this number is a palindrome. The number 3723627 is not a palindrome, so the Scientist has difficulty remembering such a number. Find the probability that the telephone number of a new random acquaintance the Scientist will remember easily.

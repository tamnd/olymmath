Two classes are organizing a joint club afternoon. To cover the costs, each student from class $A$ contributed $5 \mathrm{Ft}$, and each student from class $B$ contributed $3 \mathrm{Ft}$. If the entire cost had been covered by the students of class $A$, it would have cost each of them $K \mathrm{Ft}$. For the second such joint event, the students from class $A$ contributed $4 \mathrm{Ft}$, and those from class $B$ contributed $6 \mathrm{Ft}$, and this way, as much money was collected as if each student from class $B$ had contributed $K \mathrm{Ft}$. What is the value of $K$, and which class has more students?

Given is the set of all right-angled triangles $ABC$ with a (constant) hypotenuse $AB = c$. It is to be proven:

If one extends, in each of these triangles, one cathetus beyond $C$ by the length of the other cathetus, then the endpoints of these extensions all lie on the same circular arc.

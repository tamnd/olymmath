An old Russian problem. Four carpenters were hired by a certain host to build a house. And the first carpenter said: "If only I were to build that house alone, I would build it in one year." And the second said: "If only I were to build that house alone, I would build it in two years." And the third said: "If only I were to build that house alone, I would build it in three years." And the fourth said: "If only I were to build that house alone, I would build it in four years." And so all four carpenters began to build that house together. So how long did they take, calculate it for me.

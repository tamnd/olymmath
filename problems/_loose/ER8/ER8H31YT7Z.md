There is a tool for geometric constructions on a plane ("set square"), which allows you to do the following:

a) if two points are given, you can draw a line passing through them;

b) if a line and a point on it are given, you can erect a perpendicular to this line at the given point.

How can you use this tool to drop a perpendicular from a given point to a line that does not pass through this point?

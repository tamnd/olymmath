A convex $n$-gon and $n-3$ non-intersecting diagonals within the polygon form a figure called a triangulation graph. Prove that a triangulation graph is an Eulerian graph (i.e., it is possible to start from one vertex, traverse each edge exactly once, and return to the starting point) if and only if $3 \mid n$.

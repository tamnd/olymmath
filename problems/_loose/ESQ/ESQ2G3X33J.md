If through a point $O$, located inside the tetrahedron $A B C D$, segments $A A_{1}, B B_{1}, C C_{1}, D D_{1}$ are drawn, where $A_{1}$ lies on the face opposite vertex $A$, $B_{1}$ lies on the face opposite vertex $B$, and so on, then the following equality holds:

$$
A_{1} O / A_{1} A + B_{1} O / B_{1} B + C_{1} O / C_{1} C + D_{1} O / D_{1} D = 1
$$

Let's prove that if the value of the following expression (1) is 0, then the value of expression (2) is also 0. - Can we write down further expressions with a similar structure to (1) and (2) using the given letters, which are 0 if expression (1) is 0?

$$
\begin{aligned}
& \frac{a}{m}+\frac{b c+n p}{b p+c n} \\
& \frac{b}{n}+\frac{a c+m p}{a p+c m}
\end{aligned}
$$

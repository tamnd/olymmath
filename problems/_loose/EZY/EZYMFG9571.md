On line segment $AD$ there are two points $B, C$, and the lengths of line segments $AB, AC, AD$ are $a, b, c (a<b<c)$, respectively. If line segments $AB, CD$ are rotated around $B, C$ respectively, so that point $A$ coincides with point $D$ at point $E$, forming $\triangle BCE$, then which of the following three inequalities
( I ) $a<\frac{c}{2}$;
( II ) $b<a+\frac{c}{2}$;
( III ) $b<\frac{c}{2}$,

can be true?
(A) Only (I) is true.
(B) Only (II) is true.
(C) Only (I) and (II) are true.
(D) Only (II) and (III) are true.
(China Junior High School Mathematics Correspondence Competition, 1987)

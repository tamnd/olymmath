A set $A \subset \mathbb{N}$ is called hostile if for every pair $(a, b)$ of numbers from $A$, there exists $k \in \mathbb{N}_{0}$ such that $M(a, b)=2^{k}$. Does there exist an infinite set $S \subset \mathbb{N}$ with the property that the set of all possible sums of two distinct elements of $S$ is a hostile set?

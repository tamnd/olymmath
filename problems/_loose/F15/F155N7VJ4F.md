Prove: There are infinitely many positive integers $n$, with the following property: for each arithmetic sequence of integers $a_{1}, a_{2}, \cdots, a_{n}$ with $n$ terms, the arithmetic mean and standard deviation of the set $\left\{a_{1}, a_{2}, \cdots, a_{n}\right\}$ are both integers.
Note For any set of real numbers $\left\{x_{1}, x_{2}, \cdots, x_{n}\right\}$, the arithmetic mean of this set is defined as
$$
\bar{x}=\frac{1}{n}\left(x_{1}+x_{2}+\cdots+x_{n}\right) ;
$$

the standard deviation of this set is defined as
$$
x^{*}=\sqrt{\frac{1}{n} \sum_{j=1}^{n}\left(x_{j}-\bar{x}\right)^{2}} \text {. }
$$

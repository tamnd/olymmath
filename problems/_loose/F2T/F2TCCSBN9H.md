For any four-element subset $\mathrm{P}$ of the set $\{1,2,3, \ldots, 12\}$, denote

$$
\mathrm{Q}=\{3 x: x \in \mathrm{P}\} \text { and } \mathrm{R}=\{4 x: x \in \mathrm{P}\} \text {. }
$$

Determine the number of such sets $P$ for which the numbers from $P, Q, R$ give all possible non-zero remainders when divided by 13.

(Jaromír Šimša)

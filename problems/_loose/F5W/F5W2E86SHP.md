Given a set of points on a plane, it is allowed to add a point that is symmetric to one of its points with respect to a line that is the perpendicular bisector of a segment with endpoints in the points of this set. Is it possible, starting with three points, the pairwise distances between which are less than 1, to obtain a set containing two points, the distance between which is greater than 1?

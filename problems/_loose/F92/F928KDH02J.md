(26th Russian Mathematical Olympiad) Write the numbers $a_{1}=1, a_{2}, a_{3}, \cdots$ on the blackboard in sequence, according to the following rule: if $a_{n}-2$ is a natural number and has not been written before, then write $a_{n+1}=a_{n}-2$, otherwise write $a_{n+1}=a_{n}+3$. Prove: all perfect squares that appear in this sequence are obtained by adding 3 to the number written before them.

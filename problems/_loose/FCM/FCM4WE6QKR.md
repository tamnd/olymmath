Which of the following statements will be true if the first one is false? The second? ... The ninth?

(The number 1 is excluded from consideration everywhere.)

1) All the given numbers are composite.
2) Some of the given numbers are prime.
3) None of the given numbers are composite.
4) All the given numbers are prime.
5) Some of the given numbers are composite.
6) Not every given number is prime.
7) All the given numbers are not prime.
8) Only some of the given numbers are composite.
9) Only some of the given numbers are prime.

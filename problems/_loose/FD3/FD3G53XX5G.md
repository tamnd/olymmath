a) $R_{A}^{2}+R_{B}^{2}+R_{C}^{2}+R_{D}^{2} \geqslant \frac{\sqrt{3}}{2} \Delta$;

b) $R_{A}^{2}+R_{B}^{2}+R_{C}^{2}+R_{D}^{2} \geqslant \frac{1}{6} \Pi^{2}$.

In which case does each of these inequalities become an equality?

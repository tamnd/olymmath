Given two linear functions $f(x)$ and $g(x)$ such that the graphs $y=f(x)$ and $y=g(x)$ are parallel lines, not parallel to the coordinate axes. It is known that the graph of the function $y=(f(x))^{2}$ touches the graph of the function $y=11 g(x)$. Find all values of $A$ such that the graph of the function $y=(g(x))^{2}$ touches the graph of the function $y=A f(x)$.

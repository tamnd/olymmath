In the 539th exercise and the 945th problem, the interpretation of the number sequences can also be written as: $x_{1}=2, y_{1}=3$, and $x_{k+1}=x_{1} y_{k}+y_{1} x_{k}, y_{k+1}=y_{1} y_{k}+2 x_{1} x_{k}$, if $k=1,2,3, \ldots$ Show that generally

$$
\begin{gathered}
x_{k+r}=x_{r} y_{k}+y_{r} x_{k} \text { and } y_{k+r}=y_{r} y_{k}+2 x_{r} x_{k} \text {, } \\
\text { if } k=1,2,3, \ldots \text { and } r=1,2,3, \ldots
\end{gathered}
$$

In an isosceles triangle $A B C$ with $A C = B C \neq A B$, fix a point $P$ on the base $A B$. How many positions can a point $Q$ assume in the plane if we want the points $A, P$, and $Q$, taken in any order, to be the vertices of a triangle similar to $A B C$?
(A) 0
(B) 2
(C) 3
(D) 4
(E) 6.

In a certain country, every two cities are connected either by an airline or by a railway. Prove that

a) it is possible to choose a mode of transport so that from each city it is possible to reach any other city using only this mode of transport

b) from some city, choosing one mode of transport, it is possible to reach any other city with no more than one transfer (only the chosen mode of transport can be used);

c) every city has the property mentioned in point b);

d) it is possible to choose a mode of transport so that using only it, it is possible to travel from each city to any other city with no more than two transfers.

(Jury, England, 82). The sequence $a_{0}, a_{1}, \ldots$ satisfies for some parameter $a \in \mathbf{N}$ the relations

$$
a_{0}=0, a_{1}=1, a_{n+1}=2 a_{n}+(a-1) a_{n-i}
$$

for $n \in \mathrm{N}$. For a fixed prime number $p_{0}>2$, find the smallest value of $a$ for which the following two statements are true: a) if $p$ is a prime number and $p \leqslant p_{0}$, then the number $a_{p}$ is divisible by $p$; b) if $p$ is a prime number and $p>p_{0}$, then the number $a_{p}$ is not divisible by $p$.

17.19\%. (England, 78). Prove that there exists exactly one sequence of integers $a_{1}, a_{2}, \ldots$, satisfying the conditions

$$
a_{1}=1, a_{2}>1, a_{n+1}^{3}+1=a_{n} a_{n+2} \text { for } n \in \mathbf{N} .
$$

17.20\%. (CSSR, 70). For a given prime number $p$, find the number of different sequences of natural numbers $a_{0}, a_{1}, \ldots$, satisfying the equations

$$
\frac{a_{0}}{a_{1}}+\frac{a_{0}}{a_{2}}+\cdots+\frac{a_{0}}{a_{n}}+\frac{p}{a_{n+1}}=1 \text { for } n \in \mathbf{N}
$$

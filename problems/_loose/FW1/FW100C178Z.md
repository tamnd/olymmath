Let $d \in \mathbb{N}$ and $V:=\{0,1\}^{d}$, so $V$ is the set of all $0-1$ sequences of length $d$. Define a graph on $V$ such that two sequences form an edge if and only if they differ in exactly one position, this graph is called the $d$-dimensional cube. Determine the average degree, number of edges, diameter, girth, and circumference of this graph.

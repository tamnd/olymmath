On the game board, there is a regular n-gon with one vertex marked as a trap. Tom and Jerry play the following game. At the beginning, Jerry places a token on some vertex of the n-gon. In each step, Tom then says a natural number, and Jerry moves the token by this number of vertices in the direction of his choice, either clockwise or counterclockwise. Find all $n \geqq 3$ for which Jerry can move the token in such a way that it never lands on the trap. How does the answer change if Tom is $k$ times turned away from the board, knows only the given $n$, and does not see where Jerry initially places the token or where he moves it in each step?

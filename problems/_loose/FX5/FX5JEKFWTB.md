In the plane, there is a Cartesian coordinate system. Let's call the "new distance" between points $P\left(x_{1} ; y_{1}\right)$ and $Q\left(x_{2} ; y_{2}\right)$ the value $\left|x_{1}-x_{2}\right|+\left|y_{1}-y_{2}\right|$! Where do the points in the plane lie such that the "new distance" from two given points:

a) the sum ( "new ellipse");

b) the absolute value of the difference ( "new hyperbola") is a given constant?

Three, divide a $100 \times 100 \times 100$ cube into $100^{3}$ unit cubes. Call the edges of these unit cubes "E-edges," and call the faces of these unit cubes "F-faces." Let $\Omega$ be a set of 2020 distinct E-edges $e_{1}, e_{2}, \cdots, e_{2020}$, such that for any two E-edges $e_{i}, e_{j}(1 \leqslant i<j \leqslant 2020)$, they have a common endpoint if and only if $j-i=1$ or 2019. Prove: It is possible to color some of the F-faces blue, such that each E-edge in $\Omega$ is on an odd number of blue F-faces, while each E-edge not in $\Omega$ is on an even number of blue F-faces.

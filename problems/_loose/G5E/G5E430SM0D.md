Let the sequence $\left(a_{n}\right)_{n \geq 1}$ where $a_{1}=1$ and $a_{n+1}=\left\{\begin{array}{c}\frac{a_{n}}{n}+2 \text {, if } n \text { is even } \\ a_{n}+\frac{2}{n}, \text { if } n \text { is odd }\end{array}\right.$.

$$
\text { Show that } \lim _{n \rightarrow \infty} \frac{a_{n+1}}{a_{n}}=1
$$

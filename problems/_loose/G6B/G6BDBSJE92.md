Provide the set of all planar, convex, non-degenerate quadrilaterals $A B C D$ for which two of the following four statements are true and two of the statements are false:

(1) The quadrilateral $A B C D$ has at least one pair of parallel sides.

(2) The quadrilateral $A B C D$ has four equal sides.

(3) An interior angle of the quadrilateral $A B C D$ is a right angle.

(4) No interior angle of the quadrilateral $A B C D$ has a measure of $90^{\circ}$.

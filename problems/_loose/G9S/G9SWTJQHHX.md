Given twenty cards. Each digit from zero to nine inclusive is written on two of these cards (only one digit on each card). Can the cards be arranged in a row so that the zeros stand next to each other, there is exactly one card between the ones, two cards between the twos, and so on up to the nines, between which there should be nine cards?

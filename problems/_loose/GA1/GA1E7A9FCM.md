Using a given disk, for example a coin, a circle is drawn and a point $A$ is chosen on it. Using only the same disk, construct a point $B$ on the circle $k$ such that $A B$ is a diameter of the circle. (It is allowed to choose any point on any of the drawn circles, and using the disk, any circle containing two points at a distance less than the diameter of the circle can be constructed.)

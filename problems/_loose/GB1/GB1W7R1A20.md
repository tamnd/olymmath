Given that $f(x)$ is an odd function on $\mathbf{R}$, $f(1)=1$, and for any $x<0$,
$$
f\left(\frac{x}{x-1}\right)=x f(x) \text {. }
$$

Find the value of $\sum_{i=1}^{50} f\left(\frac{1}{i}\right) f\left(\frac{1}{101-i}\right)$.

Define an odd function $f(x)$ on $\mathbf{R}$, such that when $x \geqslant 0$, $f(x)=-x^{2}+2 x$. Another function $y=$ $g(x)$ has a domain of $[a, b]$, and a range of $\left[\frac{1}{b}, \frac{1}{a}\right]$, where $a \neq b, a, b \neq 0$. On $x \in[a, b]$, $f(x)=g(x)$. Question: Does there exist a real number $m$, such that the set $\{(x, y) \mid y=g(x), x \in[a, b]\} \cap$ $\left\{(x, y) \mid y=x^{2}+m\right\}$ contains exactly two elements?

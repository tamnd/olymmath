There are $n$ bags, each containing a sufficient number of coins. There are several different types of coins. Coins of different types have different weights, and their weights differ by an integer number of grams. The weight of coins of each type is known. In each bag, there are coins of one type, but the number of bags with coins of a given type can be arbitrary. How can you determine, with one weighing on a balance with unequal arms, what type of coins are in each bag?

Given a function $f(x)$ defined on the set of all real numbers $\mathbf{R}$ that satisfies: (1) For any $x \in \mathbf{R}, 0<f(x) \leqslant a$ (where $a$ is a fixed constant); (2) For any $x, y \in \mathbf{R}, \sqrt{f(x) f(y)} \geqslant f\left(\frac{x+y}{2}\right)$. Prove: $f(x)$ is a constant function.

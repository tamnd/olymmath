\section*{Problem 6A - 121236A}

Let $f$ be a function defined for all real numbers $x$ with the following properties:

(1) For all $x$, $f(x)=x \cdot f(x+1)$.

(2) $f(1)=1$.

a) Determine all integers $n$ for which $f(n)=0$.

b) Let $m$ and $n$ be arbitrary integers, and let $f(x+m)$ be given. Calculate $f(x+n)$.

c) Provide a specific function $f_{0}$ that satisfies the above properties, and sketch the graph of this function in the interval $-3 \leq x \leq 4$.

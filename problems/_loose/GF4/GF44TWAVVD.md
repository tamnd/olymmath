There are 64 cubic blocks with a side length of 1, each having one red face and the other 5 faces white. Place these 64 cubes on an $8 \times 8$ chessboard (each square on the chessboard is a 1-sided square, with exactly one block on each square), then "rotate" the blocks. The rule for rotation is to rotate 8 blocks in the same row (or the same column) simultaneously in one direction. Can all the red faces of the blocks be turned to the top after a finite number of rotations?

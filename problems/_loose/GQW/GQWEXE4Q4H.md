Two players play the following game. Players alternately write down one natural number greater than one, with the condition that it is not allowed to write a linear combination of previously written numbers with non-negative integer coefficients. The player who cannot write a new number loses the game. Does any of the players have a winning strategy, and if so, which one? (Aleksandar Ilić / "Kvant")

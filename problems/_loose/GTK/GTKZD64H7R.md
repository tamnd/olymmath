The upper density of an infinite graph $G$ is defined as the infimum of all real numbers $c \in \mathbb{R}$, where $\alpha$ is such that $G$ contains only finitely many (isomorphism types of) finite subgraphs with edge density $>\alpha$. Using the Erdös-Stone theorem, prove: this parameter always takes one of the countable possible values $0,1, \frac{1}{2}, \frac{2}{3}, \frac{3}{4}, \ldots$.

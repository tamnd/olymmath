Ten evenly spaced vertical lines in the plane are labeled $\ell_1,\ell_2, \ldots,\ell_{10}$ from left to right. A set $\{a,b,c,d\}$ of four distinct integers $a,b,c,d \in \{1,2,\ldots,10\}$ is *squarish* if some square has one vertex on each of the lines $\ell_a,\ell_b,\ell_c,$ and $\ell_d.$ Find the number of squarish sets.

Whether there exists an integer $n>1$ such that: the set of positive integers can be partitioned into $n$ non-empty subsets, so that from any $n-1$ of these subsets, taking one integer from each, the sum of these $n-1$ integers belongs to the remaining subset.
（36th International Mathematical Olympiad Preliminary Question, 1995)

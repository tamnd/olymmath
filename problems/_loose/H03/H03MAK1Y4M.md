In each field of a $4 \times 4$ square board, write one of the four letters: $A, B, C, D$ and one of the four numbers: 1, 2, 3, 4 such that the following conditions are met:

(a) in each row and in each column, each of these letters and each of these numbers appears exactly once,

(b) on the board, each combination (pair) of one letter and one number is found on exactly one field.

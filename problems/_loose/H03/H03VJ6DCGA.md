The set $T_{0}$ consists of all numbers of the form $\left(2^{k}\right)$ l, where $k=0,1,2, \ldots$. For each value of $p=1,2,2,1987$, the set $T_{p}$ is obtained by adding to the set all numbers that can be represented as the sum of several different numbers from $T_{p-1}$. Prove that at least one natural number does not belong to the set $T_{1987}$.

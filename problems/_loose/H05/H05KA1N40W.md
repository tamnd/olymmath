(2001 Beijing College Entrance Examination) A function $f(x)$ defined on $D$ is said to be convex on $D$ if for any $x_{1}, x_{2} \in D$, it satisfies: $f\left(\frac{x_{1}+x_{2}}{2}\right) \geqslant \frac{1}{2}\left[f\left(x_{1}\right)+f\left(x_{2}\right)\right]$.

Given the quadratic function $f(x)=a x^{2}+x(a \in \mathbf{R}$, and $a \neq 0)$. (1) Prove that when $a<0$, the function $f(x)$ is convex on $\mathbf{R}$; (2) If $x \in[0,1]$, and $|f(x)| \leqslant 1$, find the range of values for $a$.

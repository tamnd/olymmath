Let $I_{n}$ be the set of the first n odd natural numbers. For example: $I_{3}=\{1,3,5\}, I_{6}=\{1,3,5,7,9,11\}$, etc.

For which numbers n can the set $I_{n}$ be decomposed into two parts (disjoint) such that the sums of the numbers in each part are equal?

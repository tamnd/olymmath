If $\operatorname{GCD}(a, b)=1$ then $D_{a}$ and $D_{b}$ are disjoint.

(A disk $D(O, r)$ is a set of points in the plane whose distance to a given point $O$ is at most a given positive real number $r$.) (Josef Greilhuber \& Josef Tkadlec, Austria)

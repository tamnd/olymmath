Let $\xi_{1}, \xi_{2}, \ldots$ be independent random variables distributed according to $\mathscr{N}(0,1)$. For $n \geqslant 1$ we set

$$
X_{n}=\xi_{1}+\ldots+\xi_{n} \text { and } S_{n}=X_{1}+\ldots+X_{n}
$$

Using the method of characteristic functions, show that

$$
\frac{S_{n}}{n^{3 / 2}} \xrightarrow{d} \mathscr{N}(0,1 / 3), n \rightarrow \infty
$$

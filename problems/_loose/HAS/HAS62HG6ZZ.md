Let $M$ be an infinite set of real numbers with the property that for any finite subset $S \subset M$ the condition $\sum_{x \in S}|x| \geq(\operatorname{card} S)^{2}$ is satisfied, where $|x|$ represents the absolute value of the real number $x$, and card $S$ represents the number of elements in the set $S$.

a) Show that there exists a sequence $\left(a_{n}\right)_{n \geq 1}$ with elements from $M$ such that $\lim _{n \rightarrow \infty}\left|a_{n}\right|=\infty$.

b) Show that the set $M$ is countable.

We need to prove that, in any graph $G$ containing arbitrarily many disjoint $I H$, we can find a locally finite subgraph with the same property. The first step is to find a countable such graph $G^{\prime}$, and order its vertices, then use this ordering to find a locally finite subgraph $G^{\prime \prime} \subseteq G^{\prime}$ such that each vertex of $G^{\prime}$ is used by only finitely many $I H$.

The probability $p$ of an event is the fraction $\frac{\boldsymbol{a}}{m}$, where the denominator represents the number $m$ of all equally possible cases, and the numerator $a$ represents the number of those equally possible cases that are favorable to this event. According to this definition, we have for the probability $p=\frac{a}{\boldsymbol{m}}$ the inequality $0 \leqslant p \leqslant 1$. How does the probability change: 1) when the number of favorable cases increases at the expense of the number of unfavorable (or vice versa)? 2) when the number of favorable cases increases, while the number of unfavorable remains unchanged? 3) when the number of favorable cases and the number of unfavorable cases increase by the same number? 4) when the number of favorable cases and the number of unfavorable cases increase proportionally?

Miha has experimented with writing various numbers using only the digit 1 and the addition sign. For example, he found that there are only two natural numbers $n$ (13 and 4) for which the number 13 can be written using $n$ ones and the addition sign, since the number 13 can be written as the sum of thirteen ones or as $11+1+1$, using four ones.

How many different natural numbers $n$ are there for which the number 125 can be written using $n$ ones and the addition sign?

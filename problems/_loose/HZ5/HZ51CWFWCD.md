(3 Let $y=f(x)$ be a function defined on $\mathbf{R}$. If there exists a point $A$, for any point $P$ on the graph of the function $y=f(x)$, the point $Q$ symmetric to $P$ with respect to $A$ is also on the graph of the function $y=f(x)$, then the graph of the function $y=f(x)$ is said to be symmetric about the point $A$, and $A$ is called the center of symmetry of the graph of the function $y=f(x)$.
(1) Prove that the point $A(1,0)$ is the center of symmetry of the function $y=g(x)=(x-1)^{3}$;
(2) Find a center of symmetry of the graph of the function $h(x)=x^{3}+3 x^{2}$;
(3) Let $y=f(x)$ be a function defined on $\mathbf{R}$. Prove that the point $A(a, b)$ is a center of symmetry of the graph of the function $y=f(x)$ if and only if $f(a-x)+f(a+x)=2 b$.

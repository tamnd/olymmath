We have a board on which $n$ holes are arranged in a circle. Some of these holes contain a certain number of marbles. It is allowed to take all the marbles contained in a hole and distribute them one by one into the following holes, moving in a clockwise direction.

Show that it is possible, using the above operation, to reach any position from any other having the same number of marbles.

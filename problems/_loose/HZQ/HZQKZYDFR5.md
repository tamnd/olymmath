a) The numbers 11, 12, 13, 21, 22, 23, 31, 32, 33 are to be entered into the nine fields of a $3 \times 3$ square such that the following conditions are met:

In each row, each of the digits 1, 2, 3 must appear exactly once in the units place and exactly once in the tens place. The same applies to each column.

b) The two-digit numbers that can be formed using the digits 1, 2, 3, 4 are to be entered into the fields of a $4 \times 4$ square. The same conditions as in a) must be met for the digits 1, 2, 3, 4.

Provide a valid entry for each case!

Determine for a) and b) whether there are two entries that cannot be transformed into each other by swapping rows or columns, by swapping columns, or by converting rows into columns (or by performing multiple such operations)! A justification is not required.

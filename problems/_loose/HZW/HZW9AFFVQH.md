If we avoid selecting a certain tree as an induced subgraph, can we force the chromatic number to increase by increasing the average degree? More precisely, for which trees $T$, does there exist a function $f: \mathbb{N} \rightarrow \mathbb{N}$ such that for each $k \in \mathbb{N}$, any graph with average degree at least $f(k)$ either has chromatic number at least $k$ or contains an induced copy of $T$?

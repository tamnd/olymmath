Let the minimum value of the real numbers $a_{1}, a_{2}, \cdots, a_{n}$ be $\min \left\{a_{1}, a_{2}, \cdots, a_{n}\right\}$, for example, $\min \{-1.1, -2.3, 6\} = -2.3$. Try to draw the graph of the function $f(x) = \min \left\{x, 2 - x^{2}\right\}$ with the domain $\mathbf{R}$.

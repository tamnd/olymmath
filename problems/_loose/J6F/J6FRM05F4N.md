Let $f: \mathbf{R}^{*} \rightarrow \mathbf{R}$ be a function for which the set $G=\left\{\left.\left(\begin{array}{cc}x & 0 \\ f(x) & 1\end{array}\right) \right\rvert x \in \mathbf{R}^{*}\right\}$ is a stable subset of the set of 2x2 square matrices with respect to matrix multiplication. Show that $(G, \cdot)$ is an abelian group isomorphic to the multiplicative group of non-zero real numbers.

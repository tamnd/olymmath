Let $Q$ be a set composed of several permutations of $1,2, \cdots, 100$, and it satisfies that for any $1 \leqslant a, b \leqslant 100$, $a \neq b$, there is at most one $\sigma \in Q$ such that in $\sigma$, the number immediately following $a$ is exactly $b$. Find the maximum number of elements in the set $Q$.
(Sun Gongchun)

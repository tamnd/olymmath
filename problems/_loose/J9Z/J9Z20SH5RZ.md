The equation $a x^{2}-b x+c=0$ has two distinct roots $x_{1}, x_{2}$. What is the maximum number of numbers in the set $\left\{a, b, c, x_{1}, x_{2}\right\}$ that can be prime (and, accordingly, natural) numbers? If a prime number appears in the set twice, it should be counted twice. The number 1 is not considered a prime number.

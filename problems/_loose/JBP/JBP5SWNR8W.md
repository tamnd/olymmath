A class contains a certain number of girls and a certain number of boys. We know that each boy is friends with at least one girl.

1. Show that it is possible to choose a group that contains at least half of the students in the class and such that each boy in the group is friends with an odd number of girls in the group.
2. Does this remain true if we replace "at least half" with "at least $51\%$"?

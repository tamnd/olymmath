Find all triples $(x, y, z)$ of pairwise coprime natural numbers satisfying the system

$$
\left\{\begin{array}{l}
(a+b) x+a y=b z ; \\
(a+b) x^{3}+a y^{3}=b z^{3},
\end{array} \text { where } b>a\right. \text { are coprime natural numbers. }
$$

In your answer, write the smallest possible value of $x+y+z$.

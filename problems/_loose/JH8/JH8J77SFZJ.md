Let $P=\left\{1^{2}, 2^{2}, \cdots\right\}$ be the set of all squares of positive integers. If a number $n$ can be expressed as the algebraic sum of several (at least one) distinct elements from the set $P$, then the number $n$ is said to have a $P$ structure. Prove: Every natural number $n$ has a $P$ structure.

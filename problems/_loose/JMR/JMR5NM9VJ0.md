A sequence $t_{1}, t_{2}, t_{3}, \ldots$ is defined by

$$
t_{n}=\left\{\begin{array}{cl}
\frac{1}{7^{n}} & \text { when } n \text { is odd } \\
\frac{2}{7^{n}} & \text { when } n \text { is even }
\end{array}\right.
$$

for each positive integer $n$. Determine the sum of all of the terms in this sequence; that is, calculate $t_{1}+t_{2}+t_{3}+\cdots$.

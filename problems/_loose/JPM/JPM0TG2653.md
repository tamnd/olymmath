A square table containing $n$ rows and $n$ columns ($n$ is an odd number) is filled with numbers $1,2, \ldots n$ such that each row and each column contains all these numbers. Moreover, the table is filled symmetrically with respect to one of its diagonals. Is it true that all numbers from 1 to $n$ appear on this diagonal?

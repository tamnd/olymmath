Given a quadrilateral $A B C D$ set $A B=a, B C=b, C D=c$, $D A=d, A C=e$ and $B D=f$. Prove that:
a) $a^{2}+b^{2}+c^{2}+d^{2} \geq e^{2}+f^{2}$;

b) if the quadrilateral $A B C D$ is cyclic then $|a-c| \geq|e-f|$.

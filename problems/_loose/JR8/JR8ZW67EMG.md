(I) Investigate whether the following statement is generally true:

If $a, b, c, d$ are real numbers for which $b \neq 0, b+c \neq 0$ and $b+d \neq 0$, then

$$
\frac{a}{b}<\frac{a+c}{b+c} \text { always implies } \frac{a}{b}<\frac{a+d}{b+d}
$$

(II) Investigate whether the following statement is generally true:

If $a, b, c, d$ are positive real numbers, then

$$
\frac{a}{b}<\frac{a+c}{b+c} \text { always implies } \frac{a}{b}<\frac{a+d}{b+d}
$$

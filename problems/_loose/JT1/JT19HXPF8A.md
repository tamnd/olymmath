A positive rational number is written on the board. For any already written numbers $a$ and $b$ (including identical ones), it is allowed to write the numbers $a + 2b$, $ab^2$, and $a / b^2$ on the board. Is it always possible (possibly in several steps):

a) to write the number 1 if initially one odd natural number is written? (2 points)

b) to write the number 1 if initially one even natural number is written?

c) to write the number 1 if initially one number is written?

2) to write the number 2 if initially one number is written?

d) Does there exist such an $x$ that if $x$ is written on the board, then it is possible to write any other positive rational number? (4 points)

We place a coin in one of three identical boxes and put these three boxes into two accounts so that each account gets a box. What is the probability that if someone randomly selects an account and takes a box from it, they will find the coin,

a) if the box containing the coin is alone in an account?

b) if the box containing the coin is with another box in an account?

c) if the 3 boxes are placed randomly into the two accounts, without knowing which box contains the coin?

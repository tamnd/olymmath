Seja $a_{n}$ o número de maneiras de preencher um tabuleiro $n \times n$ com os algarismos 0 e 1, de modo que a soma em cada linha e em cada coluna seja a mesma. Por exemplo, os tabuleiros $2 \times 2$ que satisfazem essa regra são:

| 0 | 0 |
| :--- | :--- |
| 0 | 0 |
| 1 | 0 |
| :--- | :--- |
| 0 | 1 |
| 0 | 1 |
| :--- | :--- |
| 1 | 0 |
| 1 | 1 |
| :--- | :--- |
| 1 | 1 |

Logo, $a_{2}=4$. Calcule os valores de $a_{3}$ e $a_{4}$.

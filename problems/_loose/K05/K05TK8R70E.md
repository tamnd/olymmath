$n^{2}$ integers from 1 to $n^{2}$ are written in a square table of size $n \times n$: in this case, the number 1 is placed at any position in the table; 2 belongs to the row whose ordinal number is equal to the column number containing 1; the number 3 belongs to the row whose number matches the column number containing the number 2, and so on. By how much does the sum of the numbers in the row containing the number 1 differ from the sum of the numbers in the column containing the number $n^{2}$?[^3]

Let $D$ be a line. Show that there exist real numbers $a, b$ and $c$ not all zero such that $D$ is the set of points $\langle u, v, w\rangle$ such that $a u+b v+c w=0$.

Similarly, if we denote $\Delta_{a, b, c}$ as the line $D$, we can show that $\Delta_{\alpha_{1}, \beta_{1}, \gamma_{1}}=\Delta_{\alpha_{2}, \beta_{2}, \gamma_{2}}$ if and only if the triplets $\left(\alpha_{1}, \beta_{1}, \gamma_{1}\right)$ and $\left(\alpha_{2}, \beta_{2}, \gamma_{2}\right)$ are multiples of each other.

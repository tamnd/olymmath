The set of natural numbers is represented as the union of some set of pairwise non-intersecting infinite arithmetic progressions of integers with positive differences $d_{1}, d_{2}, d_{3}, \ldots$. Can it happen that in this case the sum $1 / d_{1}+1 / d_{2}+\ldots+1 / d_{k}$ does not exceed 0.9? Consider the cases:

a) the total number of progressions is finite;

b) the number of progressions is infinite (in this case, the condition should be understood in the sense that the sum of any finite number of terms from the infinite sum does not exceed 0.9).

Let $A B C D$ be a quadrilateral and let $M, N, P$ and $\mathrm{Q}$ be the midpoints of the segments $[A B],[B C],[C D]$ and $[D A]$. Show that if $A B C D$ is a rectangle then the quadrilateral MNPQ is a rhombus, and that if $A B C D$ is a rhombus then the quadrilateral MNPQ is a rectangle.

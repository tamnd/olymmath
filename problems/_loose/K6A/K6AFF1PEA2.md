If $a_{1}^{2}+a_{2}^{2}+\cdots+a_{n}^{2}=p, b_{1}^{2}+b_{2}^{2}+\cdots+b_{n}^{2}=q$, then $\left(a_{1} b_{1}+a_{2} b_{2}+\cdots+a_{n} b_{n}\right)_{\text {max }}=$ $\sqrt{p q}$ (when and only when $\sqrt{\frac{q}{p}} a_{i}=b_{i}(i=1,2, \cdots, n)$, the maximum value is achieved).

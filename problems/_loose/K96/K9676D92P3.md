Consider a $2n$-digit number, where the first $n$ digits and the last $n$ digits are each treated as an $n$-digit number. If the square of the sum of these two $n$-digit numbers is exactly equal to the $2n$-digit number, then this $2n$-digit number is called a Kabulek (Kabulek) strange number. For example, $(30+25)^{2}=3025$, so 3025 is a Kabulek strange number. Please find which four-digit numbers are Kabulek strange numbers?

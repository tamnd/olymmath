Solve the following system of equations for the unknowns $a, f, g, i, k, l, m, n, o, p, r, s z$ and $\ddot{u}$:
(1) $m+\ddot{u} =\mu$
(2) $n+\ddot{u} =\nu$
(3) $p+i =\pi$
(4) $f+i =\varphi$
(5) $r+o =\varrho$
(6) $k+s z+i=\xi$
(8) $a+l+f+a$
(7) $p+s z+i=\psi$
$=\alpha$
(9) $g+a+m+m+a$
$=\gamma$
(10) $k+a+p+p+a =\kappa$
(11) $s z+i+g+m+a$
$=\sigma$
(12) $o+m+i+k+r+o+n=o$
(13) $\ddot{u}+p+s z+i+l+o+n=v$

Can each unknown have an integer value if $\alpha, \gamma, \kappa, \mu, \nu, o, \xi, \pi, \varrho, \sigma, v, \varphi, \psi$ (in this order) are consecutive integers? And what if these are consecutive odd integers?

Examine the system of equations that results from adding the following equations to the above:

$$
\text { (14) } e+p+s z+i+l+o+n=\varepsilon \text { and } \text { (15) } o+m+e+g+a+=\omega
$$

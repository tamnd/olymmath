Let $x_{1}$ be an arbitrary real number, and let $x$ be such a real number that $\left|x-x_{1}\right| \leq \frac{1}{100}$.

a) Prove that the difference in the values of the function $\sin x$ at points $x$ and $x_{1}$ is not greater than $\frac{1}{100}$.

b) Can an interval $\Delta=\left(x_{1}-\delta, x_{1}+\delta\right)$ be determined for the function $\sin x^{2}$ such that

$$
\left|\sin x^{2}-\sin x_{1}^{2}\right| \leq \frac{1}{100}, \text { for every } x \in \Delta
$$

where $\delta$ is a finite positive number that does not depend on $x_{1}$?

Show that the two inequalities

$$
x y z(x+y+z)>0 \text { and } x y+y z+x z>0
$$

with $x ; y ; z \neq 0$ hold if and only if $\operatorname{sgn} x=\operatorname{sgn} y=\operatorname{sgn} z$. Here, $\operatorname{sgn} a=0$ if $a=0$, $\operatorname{sgn} a=1$ if $a>0$, and $\operatorname{sgn} a=-1$ if $a<0$.

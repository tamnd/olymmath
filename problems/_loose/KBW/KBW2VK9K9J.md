Let $f$ be a quadratic function with the rule $f(x)=(m-1) x^{2}+m x+m$, where $m \neq 1$.

(a) For $m=3$, calculate the minimum value of the function $f$.

(b) Find all real numbers $m$ such that the function $f$ is strictly negative for all $x$.

Time for solving: 45 minutes.

There are 100 identical boxes, all closed, arranged in a line. In one of the boxes, there is a diamond. Each box has the following message written on its lid: "the diamond is in the box to the left or to the right." We know that exactly one of these messages is true and all the others are false. By opening the lid of only one of them, is it possible to find out where the diamond is?

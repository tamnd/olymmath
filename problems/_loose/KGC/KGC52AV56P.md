In a convex quadrilateral $A B C D$, points $G_{1}, G_{2}, G_{3}, G_{4}$ are the centroids of triangles $B C D, A C D, A B D, A B C$, respectively, while points $A_{1}, B_{1}, C_{1}, D_{1}$ are the points centrally symmetric to points $A, B, C, D$ with respect to $G_{1}, G_{2}, G_{3}, G_{4}$. Prove that $A B C D$ is a parallelogram if and only if $A_{1} B_{1} C_{1} D_{1}$ is a parallelogram.

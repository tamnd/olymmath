Let $(x ; y)$ be pairs of real numbers. Represent the mapping

$$
\begin{array}{r}
\{(m ; y): y=x+4 \text { for } 0 \leq x<2 \\
0 \leq y \leq 6 \text { for } x=2
\end{array}
$$

$$
\begin{array}{r}
(x-5)^{2}+(y-4)^{2}=4 ; y=4-\sqrt{7-x^{2}+6 x} \text { for } 3 \leq x \leq 7 \\
y=6 \text { and } y=2 x-16 \text { for } 8 \leq x \leq 11 \\
4 \leq y \leq 6 \text { for } x=12 \\
\left.y=6 \text { and }(x-14)^{2}+(y-2.5)^{2}=6.25 \text { for } 12 \leq x \leq 16.5\right\}
\end{array}
$$

graphically in a right-angled Cartesian coordinate system!

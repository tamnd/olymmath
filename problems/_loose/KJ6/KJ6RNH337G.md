Given the function $f(x)=2 x+a \ln x$.
(1) If $a<0$, prove: for any two positive numbers $x_{1} 、 x_{2}$, there is always
$$
\frac{f\left(x_{1}\right)+f\left(x_{2}\right)}{2} \geqslant f\left(\frac{x_{1}+x_{2}}{2}\right)
$$

holds;
(2) If for any $x \in[1, \mathrm{e}]$, the inequality
$$
f(x) \leqslant(a+3) x-\frac{1}{2} x^{2}
$$

always holds, find the range of values for $a$.

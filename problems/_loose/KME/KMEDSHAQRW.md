Let $A, B, C, D$ be four non-coplanar points such that the angles $A B C, A B D, A C B, A C D, A D C, A D B$ are acute.

Show that if $\angle A B C \equiv \angle A B D$ and $\angle A C B \equiv \angle A C D$, then $\angle A D C \equiv \angle A D B$.

On a plane, there are $n$ points, no three of which are collinear. Each pair of points is connected by a line segment, and each line segment is colored either red or blue. A triangle with all three sides of the same color is called a "monochromatic triangle." Let the number of monochromatic triangles be $S$.
(1) If $n=6$, for all possible colorings, find the minimum value of $S$;
(2) If $n=2 k$ (integer $k \geqslant 4$), for all possible colorings, find the minimum value of $S$.

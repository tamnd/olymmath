Given 13 silver coins, exactly one of which is counterfeit and has a different weight.
（1）How can you use a balance scale without weights to find the counterfeit coin in 3 weighings?
（2）Prove that the above method does not necessarily determine whether the counterfeit coin is lighter or heavier. If an additional known genuine coin is added, then the counterfeit coin can be found and its weight determined in 3 weighings.
（3）If there are 14 silver coins, exactly one of which is counterfeit, it is impossible to find the counterfeit coin using the balance scale in 3 weighings.

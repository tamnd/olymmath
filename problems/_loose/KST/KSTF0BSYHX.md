Find all values of the parameter $a$ such that the system

$$
\left\{\begin{array}{l}
\arccos \left(\frac{4+y}{4}\right)=\arccos (x-a) \\
x^{2}+y^{2}-4 x+8 y=b
\end{array}\right.
$$

has no more than one solution for any value of the parameter $b$.

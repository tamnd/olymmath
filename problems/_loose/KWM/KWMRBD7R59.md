Which of the following formulas defines the function $g$ such that, for all values of $x$, $g(f(x))=x$ ?
A $\frac{1}{3} x-4$
B $\frac{1}{3} x+\frac{4}{3}$
C $4 x-3$
D $\frac{1}{3} x-\frac{4}{3}$
E $3 x-4$

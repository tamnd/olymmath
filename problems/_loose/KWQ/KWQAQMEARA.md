High $\mathbf{5 0 1}$ Given $\left\{a_{n}\right\}$ is a sequence with 1007 terms, and its general term formula is
$$
a_{n}=10^{n}+10^{2016-n}(1 \leqslant n \leqslant 1007) \text {. }
$$

In the sequence $\left\{a_{n}\right\}$, find the solutions to the following congruence equations (given that 2017 is a prime number, and 10 is a primitive root modulo 2017):
$$
\begin{array}{l}
\text { (1) } x \equiv 1(\bmod 2017) ; \\
\text { (2) } x^{2} \equiv 2(\bmod 2017) ; \\
\text { (3) } x^{3}-3 x \equiv 1(\bmod 2017) ; \\
\text { (4) } x^{3}+x^{2}-2 x \equiv 1(\bmod 2017) \text {. }
\end{array}
$$

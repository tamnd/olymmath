Let $M=\{1,2, \ldots, n\}$, where $n \geq 2$, and $\mathcal{P}(M)=\{P \mid P \subseteq M\}$ be the set of all subsets of $M$. Determine the number of functions $f: \mathcal{P}(M) \rightarrow \mathcal{P}(M)$ that have the property:

$$
|f(A) \cap f(B)|=|A \cap B| \text {, for any } A, B \in \mathcal{P}(M)
$$

(We denote by $|X|$ the number of elements of the set $X$.)

Lysov Yu.P. On a circle, there is a set $F$ of points, consisting of 100 arcs. For any rotation $R$ of the circle, the set $R(F)$ has at least one common point with the set $F$. (In other words, for any angle $\alpha$ from $0^{\circ}$ to $180^{\circ}$, there are two points in the set $F$ that are separated by an angle $\alpha$.) What is the smallest possible sum of the lengths of the 100 arcs that form the set $F$? What would the answer be if there were $n$ arcs instead of 100?

It is known about an infinite set of rectangles that for any number $S$, there are rectangles with a total area greater than $S$.

a) Is it necessarily possible to cover the entire plane with this set, if overlaps are allowed?

b) The same question, if it is additionally known that all rectangles in the set are squares.

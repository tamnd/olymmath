Misunderstanding. An American reader asked me to find a number composed of any number of digits, for which division by 2 can be performed by moving the last digit to the front. Apparently, this problem arose for him after he became acquainted with a previously misstated problem. If it were required to move the first digit to the end, the answer would be the number 315789473684210526, and from this, it would be easy to find a solution starting with any digit. But if it is required to move the digit from the end to the front, there is no solution for the divisor 2. However, there is a solution for the divisor 3. Could you find it?

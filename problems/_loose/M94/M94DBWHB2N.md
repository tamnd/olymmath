Determine for each natural number $n$ with $n>1$ all those functions $f$ that satisfy the following conditions (1), (2), (3) with this number $n$:

(1) The function $f$ is defined for all real numbers $x$.

(2) The function $f$ is continuous at the point $x=0$.

(3) For every real number $x$, $n \cdot f(n x)=f(x)+n x$.

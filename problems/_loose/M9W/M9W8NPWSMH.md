Given the set $A=\left\{a_{1}, a_{2}, \cdots, a_{n}\right\}$, $1 \leqslant a_{1}<a_{2}<\cdots<a_{n}(n \geqslant 5)$, for any $1 \leqslant i \leqslant j \leqslant n$, it is always true that $\frac{a_{i}}{a_{j}}$ or $a_{i} a_{j}$ is in the set $A$. Prove: $a_{1}, a_{2}, \cdots, a_{n}$ form a geometric sequence in order.

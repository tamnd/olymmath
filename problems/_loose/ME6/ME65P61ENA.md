The absolute value $|a|$ of any number $a$ is defined by

$$
|a|=\left\{\begin{array}{cl}
a & \text { if } a>0 \\
0 & \text { if } a=0 \\
-a & \text { if } a<0
\end{array}\right.
$$

For example, $|6|=6,|-4|=4$ and $|0|=0$. What is the value of $N=|5|+|3-8|-|-4|$?
(a) 4
(b) -4
(c) 14
(d) -14
(e) 6

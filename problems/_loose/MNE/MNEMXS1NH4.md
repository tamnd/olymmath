A cooperative of small farmers has created its own 6-digit numbering system so that consumers can identify the origin of the products:

I) The first 2 digits indicate the sub-region, which are 27, numbered from 01 to 27.

II) The next 2 digits refer to the producer, with each sub-region having 40, numbered from 31 to 70 (note that there is a producer 35, for example, in sub-region 01, 02, 03... etc., i.e., there are 27 producers number 35).

III) The last 2 digits refer to the type of product, which are 28, numbered from 71 to 98.

For example, the number 074197 corresponds to a product from sub-region 07, producer 41 of this sub-region, and type 97.

a) Carlos wrote down the number in the wrong sequence, swapping the 3 parts of the code, writing 900950. Is it still possible to identify the sub-region, producer, and type of the product?

b) In total, how many different codes can be generated, so that they meet the cooperative's conditions?

c) Júnior is a superstitious consumer. He hates the number 15 and does not buy any product that contains it. How many product codes are in this situation?

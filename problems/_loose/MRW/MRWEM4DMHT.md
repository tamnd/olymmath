An increasing integer sequence, if its 1st term is odd, the 2nd term is even, the 3rd term is odd, the 4th term is even, and so on, is called an alternating sequence. The empty set is also considered an alternating sequence. The number of all alternating sequences with each term taken from the set $\{1,2, \cdots, n\}$ is denoted as $A(n)$. Clearly, $A(1)=2, A(2)=3$, find $A(20)$ and explain the reason.

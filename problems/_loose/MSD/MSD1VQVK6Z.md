Let $S$ be a set included in $\{1,2,3, \ldots, 199,200\}$. We say that $S$ is pretty if, for all elements $a$ and $b$ of $S$, the number $a-b$ is not a prime number. What is the maximum number of elements in a pretty set included in $\{1,2,3, \ldots, 199,200\}$?

Note: We say that a set $A$ is included in a set $B$ if every element of $A$ is also an element of $B$.

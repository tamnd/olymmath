On four tiles is written the number 1; on two tiles is written the number 2; on seven tiles is written the number 3; on eight tiles is written the number 4. Using 20 of these tiles, Dimitar formed a rectangle with dimensions 4 by 5. For the formed rectangle, the sum of the numbers in each row is the same, and the sum of the numbers in each column is the same. Which number is on the unused tile?

Let $k\ge2$ be an integer. The function $f:\mathbb N\to\mathbb N$ is defined by $$ f(n)=n+\left\lfloor\sqrt[k]{n+\sqrt[k]n}\right\rfloor. $$ Determine the set of values taken by the function $f$ .

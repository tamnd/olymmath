In a country, some pairs of cities are connected by two-way non-stop flights. Moreover, from any city, it is possible to fly to any other city (possibly with layovers). It is known that if any closed route consisting of an odd number of flights is chosen and all these flights are closed, then it will no longer be possible to get from any city to any other city. Prove that all cities can be distributed among 4 republics so that any flight connects cities from different republics. (Some republics may not contain any cities.)

(V. Dol'nikov)

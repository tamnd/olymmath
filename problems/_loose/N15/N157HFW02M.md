53 Given the set $S_{n}=\left\{a_{1}, a_{2}, a_{3}, \cdots, a_{n}\right\}$ and $S_{m}=\{0,1,2,3, \cdots, m-1\}, P\left(S_{n}\right)$ represents the set of all subsets (including the empty set $\emptyset$) of $S_{n}$, and the mapping $f: P\left(S_{n}\right) \longrightarrow S_{m}$ has the following property: For any two elements $X_{1}$ and $X_{2}$ in $P\left(S_{n}\right)$, we have
$$
f\left(X_{1} \cup X_{2}\right)+f\left(X_{1} \cap X_{2}\right)=f\left(X_{1}\right)+f\left(X_{2}\right) .
$$

Find: (1) When $f(\varnothing)=0$, the number of all such mappings $f$.
(2) When $f(\emptyset)=1$, the number of all such mappings $f$.

On the set of non-zero real numbers $\mathbb{R}^{*}$, the composition law "*" is defined by $a * b=\left\{\begin{array}{l}\frac{a}{b}, \text { if } a < b \\ \frac{b}{a}, \text { if } a > b\end{array} \forall a, b \in \mathbb{R}^{*}\right.$

a) Prove that $\left(\mathbb{R}^{*}, *\right)$ is a non-commutative group.

b) Solve the equation $a * b * a=b,\left(a, b \in \mathbb{R}^{*}\right)$.

We need to fill a $3 \times 3$ table with nine given numbers such that in each row and column, the largest number is the sum of the other two. Determine whether it is possible to complete this task with the numbers

a) 1, 2, 3, 4, 5, 6, 7, 8, 9;

b) 2, 3, 4, 5, 6, 7, 8, 9, 10.

If yes, find out how many ways the task can be completed such that the largest number is in the center of the table.

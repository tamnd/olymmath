Given the proportion:

$$
\frac{\text { area } \boldsymbol{S}}{\text { area } \boldsymbol{S}^{\prime \prime}}=\frac{\text { segment } \boldsymbol{a}}{\text { segment } \boldsymbol{a}^{\prime}}
$$

$$
\frac{\text { area } S}{\text { segment } a}=\frac{\text { area } S^{\prime}}{\text { segment } a^{\prime}}
$$

and area $\boldsymbol{S} \times$ segment $\boldsymbol{a}^{\prime}=$ area $\boldsymbol{S}^{\prime} \times$ segment $\boldsymbol{a}$ (2)?

The giants were prepared 813 burgers, among which are cheeseburgers, hamburgers, fishburgers, and chickenburgers. If three of them start eating cheeseburgers, then in that time two giants will eat all the hamburgers. If five take on eating hamburgers, then in that time six giants will eat all the fishburgers. If seven start eating fishburgers, then in that time one giant can eat all the chickenburgers. How many burgers of each type were prepared for the giants? (The time it takes for one giant to eat one burger does not depend on the type of burger, and all giants eat at the same speed.)

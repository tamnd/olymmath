Twenty numbers are arranged in a circle. It is allowed to replace a triplet of consecutive numbers $x, y, z$ with the triplet $x+y, -y, z+y$ (in that exact order). Is it possible to use these operations to transform the set $\{1,2,3, \ldots, 9,10, -1,-2,-3, \ldots,-9,-10\}$ into the set $\{10,9,8, \ldots, 2,1, -10,-9, -8, \ldots,-2,-1\}$ (numbers are listed in a clockwise direction)?

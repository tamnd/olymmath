If the real number $x_{0}$ satisfies $f\left(x_{0}\right)=x_{0}$, then $x=x_{0}$ is called a fixed point of $f(x)$.
Given the function $f(x)=x^{3}+a x^{2}+b x+3$, where $a, b$ are constants.
(I) If $a=0$, find the interval where the function $f(x)$ is monotonically increasing;
(II) If $a=0$, there exists a real number $x_{0}$ such that $x=x_{0}$ is both a fixed point and a critical point of $f(x)$. Find the value of the real number $b$;
(III) Prove that there does not exist a real number pair $(a, b)$ such that $f(x)$ has two distinct critical points that are both fixed points.

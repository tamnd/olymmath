Given a natural number $a_{0}$, a sequence $\left\{a_{n}\right\}$ is constructed as follows: $a_{n+1}=a_{n}^{2}-5$ if $a_{n}$ is odd, and $a_{n / 2}$ if $a_{n}$ is even. Prove that for any odd $a_{0}>5$, the sequence $\left\{a_{n}\right\}$ will contain arbitrarily large numbers.

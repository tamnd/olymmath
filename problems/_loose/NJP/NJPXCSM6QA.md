For a number $x$, the following four pairs $\left(A_{1}, A_{2}\right),\left(B_{1}, B_{2}\right),\left(C_{1}, C_{2}\right),\left(D_{1}, D_{2}\right)$ of statements are made, of which exactly one is true and exactly one is false.

Investigate whether there is a number $x$ that satisfies this requirement! Determine, if this is the case, every such number $x$!

A1) There is no number other than $x$ that satisfies the requirement of this task.

A2) $x$ is a natural number, in whose (decimal) representation a digit appears twice.

B1) $x-5$ is an integer divisible by 6.

B2) $x+1$ is an integer divisible by 12.

C1) $x$ is a natural number whose (decimal) representation begins with the digit 3.

C2) $x$ is the number 389.

D1) $x$ is a three-digit prime number with $300<x<399$, i.e., one of the numbers $307,311,313,317,331,337,347,349,353,359,367,373,379,383,389,397$.

D2) $x$ is a natural number consisting of three identical digits.

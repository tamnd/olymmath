Let the function $f: \mathbf{Z}_{+} \rightarrow \mathbf{Z}_{+}$ satisfy: if $n \in \mathbf{Z}_{+}$, then
$$
n^{3}-n^{2} \leqslant f(n) f^{2}(f(n)) \leqslant n^{3}+n^{2} \text {. }
$$

Find the function $f$.

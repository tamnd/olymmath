Let $f(x)=\sup _{\alpha}\left(a_{\alpha}^{\top} x+b_{\alpha}\right)$ be a finite function in a convex domain $x \in C \subset \mathbb{R}^{d}$ for some $a_{\alpha} \in \mathbb{R}^{d}, b_{\alpha} \in \mathbb{R}$, where $\alpha$ runs through an arbitrary set of indices.

(a) Prove that for any $x, y \in C$, for all $\lambda, 0<\lambda<1$, the inequality

$$
f(\lambda x+(1-\lambda) y) \leqslant \lambda f(x)+(1-\lambda) f(y) .
$$

holds. In other words, the function $f$ is convex.
(b) Establish the converse to (b), that any convex function $f$ on an open convex domain $C$ can be represented as $\sup _{\alpha}\left(a_{\alpha}^{\top} x+b_{\alpha}\right)$.

(c) Show that there always exists a countable subsystem $\left\{\left(a_{n}, b_{n}\right)\right\}$ in $\left\{\left(a_{\alpha}, b_{\alpha}\right)\right\}$ such that

$$
f(x)=\sup _{n}\left(a_{n}^{\top} x+b_{n}\right)
$$

In particular, $f$ is a Borel function.

(d) Let the random vector $X$ lie in the closure of $C$ almost surely. Verify that if $E X$ exists, then $E X$ also lies in the closure of the domain $C$ and the multidimensional Jensen's inequality holds:

$$
f(\mathrm{E} X) \leqslant \mathrm{E} f(X)
$$

Remark. Using part (d), for example, one can provide an alternative proof of Minkowski's inequality by noting that the function $f(x, y)=\left(|x|^{p}+|y|^{p}\right)^{1 / p}$ is convex in the domain $C=\mathbb{R}^{2}$ when $p \geqslant 1$.

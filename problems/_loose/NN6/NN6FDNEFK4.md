$f$ is a one-to-one mapping on $R \rightarrow R$, the function $y=$ $f(x)$ is strictly increasing, the solution set of the equation $x=f(x)$ is $P$, the solution set of the equation $x$ $=f(f(x))$ is $Q$, then
(A) $P \subset Q$.
(B) $P=Q$.
(C) $Q \subset P$.
(D) $P \nsubseteq Q$, and $Q \nsubseteq P$.
(1st "Hope Cup" Mathematics Competition, 1990)

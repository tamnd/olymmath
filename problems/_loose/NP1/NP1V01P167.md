Let $X$ be a random variable with a symmetric distribution $(X \stackrel{d}{=}-X)$ and the function $\varphi=\varphi(x), x \in \mathbb{R}$, such that $\mathbb{E}[\varphi(X)\|X\|]$ is defined. Show that

$$
\mathrm{E}[\varphi(X)|| X \mid]=\frac{1}{2}[\varphi(|X|)+\varphi(-|X|)] \text { a.s. }
$$

Using the given equality, compute $\mathrm{P}(X \leqslant x|| X \mid)$.

18 (1) Let $D$ be any point inside $\triangle ABC$, prove that $-\frac{BC}{\min \{AD, BD, CD\}}$
$$
\geqslant\left\{\begin{array}{ll}
2 \sin A, & \text { when } \angle A<90^{\circ} \text { } \\
2, & \text { when } \angle A \geqslant 90^{\circ} \text {; }
\end{array}\right.
$$
(2) Let $E$ be any point inside the convex quadrilateral $ABCD$, and let the ratio of the maximum distance to the minimum distance between any two of the five points $A, B, C, D, E$ be denoted as $k$. Prove that: $k \geqslant 2 \sin 70^{\circ}$. Also, determine whether the equality can hold.

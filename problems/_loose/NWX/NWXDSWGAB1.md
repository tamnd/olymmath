Natural number (where each $a_{i}$ represents an Arabic numeral): First write $a_{1}$, then write $a_{2}, a_{3}, \cdots$, $1,2, \cdots, 1999$ according to the rule. If a 2000-digit natural number written according to the above rule has the digits $a_{i}$, where the digits 1, 9, 8, 7 all appear. Prove that the 2000-digit natural number written must be a composite number.

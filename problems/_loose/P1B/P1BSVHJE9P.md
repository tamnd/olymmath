In Academy of Sciences, there are $999$ academicians. For each scientific topic there are exactly $3$ academicians interested in this topic. For each pair of academicians, there exists exactly one topic in which both these academicians are interested. Prove that there exists a set of $250$ topics such that each academician is interested in not more than one topic from this set. (A. Magazinov)

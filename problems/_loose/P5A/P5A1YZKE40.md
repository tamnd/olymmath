Let $D$ be the set of diagonals of a regular 100-gon. Does there exist a subset $E$ of the set $D$ with the following properties:
1) No two diagonals in $E$ have a common interior point.
2) From each vertex of the 100-gon, an even number of diagonals from the set $E$ emanate.
3) The diagonals from $E$ divide the 100-gon into triangles.

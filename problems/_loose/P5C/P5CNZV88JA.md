If in set $A$, there exist $m$ elements $a_{1}, a_{2}, \cdots, a_{m}$ (which can be repeated), satisfying the equation $a_{1}+a_{2}+\cdots+a_{m-1}=a_{m}$, we say that set $A$ is $m$-sum-related. Given that the set $\left\{1,2, \cdots, n_{m}\right\}$ is arbitrarily divided into the union of two disjoint subsets, and at least one of these subsets is $m$-sum-related $(m \geqslant 3)$, find the minimum value of the natural number $n_{m}$.

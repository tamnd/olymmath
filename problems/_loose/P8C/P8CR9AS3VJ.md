Using Zorn's Lemma, equivalent to the Axiom of Choice:

"if on a set $X$ there is a partial order $\prec$ such that every chain, i.e., a set of pairwise comparable elements, has a maximal element, then there exists an element $x_{\max} \in X$ such that $x \prec x_{\max}$ for all $x \in X$", show that every finitely additive probability measure $\mathrm{P}$ defined on an algebra $\mathscr{A}$ of subsets of $\Omega$ can be extended to a finitely additive probability on all subsets of $\Omega$.

Let's determine all the square numbers whose digits, in some order, are $0,0,0,1,1,1,2, 2, 2$. We allow a leading digit of 0.

Are the found representations valid in any base larger than 2? Is it true that by reversing the digits of each found square number, we again get a valid number?

(11.0 Proof: There does not exist a finite set of more than $2 N (N>3)$ pairwise non-parallel vectors in the plane with the following properties:
1) For any $V$ vectors in this set, one can find another $N-1$ vectors from this set, such that the sum of these $2 V-1$ vectors equals 0;
2) For any $N$ vectors in this set, one can find another $N$ vectors from this set, such that the sum of these $2 N$ vectors equals 0.

A function is said to be of symmetric behavior if there exists a number $t$ such that the function takes the same value at $x$ and $2t - x$ for any $x$. Prove that the function

$$
a x^{4} + b x^{3} + c x^{2} + d x + e
$$

is of symmetric behavior if and only if

$$
b^{3} - a b c + 8 a^{2} d = 0 \text{ and } a \neq 0
$$

For a convex polygon with an odd number of sides, each vertex is painted a color such that any two adjacent vertices have different colors. Prove that for any such coloring, the polygon can be divided into several triangles using non-intersecting diagonals, such that each diagonal used in the partition has endpoints of different colors.

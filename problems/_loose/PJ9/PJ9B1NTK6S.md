For a positive integer $n$, let $\mathbf{Z} / n^{2} \mathbf{Z}$ be the set of all residue classes modulo $n^{2}$. Given a set $A \subset \mathbf{Z} / n^{2} \mathbf{Z}, |A|=n$. Prove: there exists a set $B, |B|=n$, such that $|A+B| \geqslant \frac{n^{2}}{2}$, where $A+B=\{a+b \mid a \in A, b \in B\}$, and all operations are performed modulo $n^{2}$.

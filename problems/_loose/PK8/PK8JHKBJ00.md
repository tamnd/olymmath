An integer $n$ is called a combi-number if every pair of different digits from all possible digits $0 \mathrm{t} / \mathrm{m} 9$ appear next to each other at least once in the number. Thus, in a combi-number, the digits 3 and 5 appear next to each other somewhere. It does not matter whether they appear in the order 35 or 53. We agree that a combi-number does not start with the digit 0.

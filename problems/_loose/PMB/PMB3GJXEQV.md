Consider the set $A=\left\{x \in \mathbb{N} \mid x=n^{2}+5, n \in \mathbb{N}, n \leq 2014\right\}$.

a) Find the four smallest elements of the set $A$.

b) Show that $261 \in A$ and that $2014 \notin A$.

c) Let the set $B=\{y \in \mathbb{N} \mid y=n(n+1)+5, n \in \mathbb{N}, n \leq 2014\}$.

Calculate the difference $S(B)-S(A)$, where $S(A)$ is the sum of the elements of set $A$, and $S(B)$ is the sum of the elements of set $B$.

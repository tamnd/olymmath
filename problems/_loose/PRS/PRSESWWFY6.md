If $c$ is a real number, the system of equations

$$
\begin{aligned}
x+y & =1 \\
x^{2}+y^{2} & =c
\end{aligned}
$$

is formed.

a) Determine all pairs $(x ; y)$ that satisfy the system of equations (1), (2) for $c=2$.

Furthermore, determine all real numbers $c$ for which the system of equations (1), (2)

b) has no solution $(x ; y)$ from real numbers $x, y$,

c) has exactly one solution $(x ; y)$,

d) has two different solutions $\left(x_{1} ; y_{1}\right),\left(x_{2} ; y_{2}\right)$ from real numbers.

Let $P(x)$ be a polynomial with integer coefficients

$$
P(x)=a_{n} x^{n}+a_{n-1} x^{n-1}+\ldots+a_{2} x^{2}+a_{1} x+a_{0}
$$

If

$$
P(a)=1991, P(b)=1992 \text { and } P(c)=1993 \text { and } a, b, c \in \mathbb{Z} \text {, }
$$

then $a, b, c$ are consecutive numbers.

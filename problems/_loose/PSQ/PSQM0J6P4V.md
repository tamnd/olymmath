If a positive function $f(x)$ defined on the set $D$ satisfies the functional inequality for any $x, y \in D$:
$$
f(x) f(y) \leqslant\left[f\left(\frac{x+y}{2}\right)\right]^{2}
$$
(equality holds if and only if $x=y$), then for any $x, \in D, i=1,2, \cdots, n$, we have
$$
f\left(x_{1}\right) f\left(x_{2}\right) \cdots f\left(x_{n}\right) \leqslant\left[f\left(\frac{x_{1}+x_{2}+\cdots+x_{n}}{n}\right)\right]^{n}
$$
(equality holds if and only if $x_{1}=x_{2}=\cdots=x_{n}$).

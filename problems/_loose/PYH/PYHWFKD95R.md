97.+ An open Euler tour in an infinite connected graph $G$ is a 2-way infinite walk $\ldots e_{-1} v_{0} e_{0} \ldots$, which contains each edge of $G$ exactly once. Prove: $G$ contains an open Euler tour if and only if $G$ is countable, each vertex has even or infinite degree, and each finite cut $F=E\left(V_{1}, V_{2}\right)$ with $V_{1}$ and $V_{2}$ both infinite sets is odd.

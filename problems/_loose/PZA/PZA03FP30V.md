On a plane, there are 7 point projectors. Each projector illuminates an angle of $90^{\circ}$. If a quadrant illuminated by any projector contains another projector, a shadow - a dark infinite ray - will fall from the latter. Prove that these 7 projectors can be arranged so that a shadow 7 km long falls from each of them.

Let $a, b, c$ be real numbers. Then, for any real number $x$, the inequality
$$
a \sin x + b \cos x + x > 0
$$

always holds if and only if
(A) $a, b$ are both 0, and $c > 0$.
(B) $\sqrt{a^{2}+b^{2}} = c$.
(C) $\sqrt{a^{2}+b^{2}} < c$.
(China High School Mathematics League, 1994)

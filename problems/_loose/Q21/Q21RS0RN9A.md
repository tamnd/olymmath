(15th "Hope Cup" Mathematics Invitational for High School Freshmen) A periodic function $f(x)$ with the smallest positive period $T=2$ satisfies the equation $f(2-x)=f(2+x)$ for any real number $x$, and $[a, b]$ is a monotonic interval of $f(x)$.
(1) Prove: $b-a \leqslant 1$;
(2) Given that $[0,1]$ is a monotonic interval of the function $f(x)$, and for any $xf(2)$, find the solution set of the inequality $f(-10.5)>f\left(x^{2}+6 x\right)$.

Let $ a,b,c$ positive reals such that $ ab + bc + ca = 3$, show that:
$ a^2 + b^2 + c^2 + 3 \ge \frac {a(3 + bc)^2}{(c + b)(b^2 + 3)} + \frac {b(3 + ca)^2}{(a + c)(c^2 + 3)} + \frac {c(3 + ab)^2}{(b + a)(a^2 + 3)}$

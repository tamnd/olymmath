For the function $f(x)$, if there exists $x_{0} \in \mathbf{R}$, such that $f\left(x_{0}\right)=x_{0}$ holds, then $x_{0}$ is called a fixed point of $f(x)$. Given the function $f(x)=a x^{2}+(b+1) x+(b-1)(a \neq 0)$.
(1) When $a=1, b=-2$, find the fixed points of the function $f(x)$;
(2) If for any real number $b$, the function $f(x)$ always has two distinct fixed points, find the range of values for $a$;
(3) Under the condition in (2), if the points $A$ and $B$ on the graph of $y=f(x)$ have the x-coordinates as the fixed points of the function $f(x)$, and $A$ and $B$ are symmetric about the line $y=k x+\frac{1}{2 a^{2}+1}$, find the minimum value of $b$.

$a, b$ are real numbers, among the following five propositions, which one is correct?
(A) If $a>b$, then $a^{2}>b^{2}$.
(B) If $|a|>b$, then $a^{2}>b^{2}$.
(C) If $a>|b|$, then $a^{2}>b^{2}$.
(D) If $a^{2}>b^{2}$, then $a>b$.
(E) If $a \neq|b|$, then $a^{2} \neq b^{2}$.
(China Beijing Junior High School Mathematics Competition, 1983)

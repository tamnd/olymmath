By the modification of a natural number, we mean the following operation: if the number is even, we divide it by two; if it is odd, we add the number 1 to it.

a) Prove that from any natural number, we will get the number 1 after several modifications.

b) For which $z$ numbers $1,2, \ldots, 10^{6}$ will we need the greatest number of modifications to obtain the number 1?

(Ján Mazák)

Show that the support supp $F$ of a continuous distribution function $F$ is a perfect set (i.e., closed and having no isolated points), coinciding with the set $G_{F}$ of growth points of $F$.

Provide an example of a discrete distribution function $F$ whose support supp $F=\mathbb{R}$, i.e., coincides with the entire real line $\mathbb{R}$.

Remark. Recall that supp $F$ for a distribution function $F$ on $\mathbb{R}$ is defined as the smallest closed set $G$ such that $\mu(\mathbb{R} \backslash G)=0$, where $\mu$ is the measure corresponding to the distribution function $F$; see also $\S 2$ of the appendix.

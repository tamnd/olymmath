Show that a continuous function $f: \mathbb{R} \rightarrow \mathbb{R}$ is increasing if and only if

$$
(c-b) \int_{a}^{b} f(x) \mathrm{d} x \leq(b-a) \int_{b}^{c} f(x) \mathrm{d} x
$$

for any real numbers $a<b<c$.

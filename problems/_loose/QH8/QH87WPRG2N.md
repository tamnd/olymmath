A convex $n$-sided polygon and $n-3$ non-intersecting diagonals inside the polygon form a graph called a triangulation graph. Prove that a triangulation graph can be a graph that can be drawn in one stroke (i.e., starting from one vertex, passing through each segment of the graph exactly once, and finally returning to the starting point) if and only if $3 \mid n$.

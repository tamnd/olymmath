Suppose $n k$ stones are divided into $n$ piles, and the following operation is allowed: move some stones from one pile to another, but the number of stones moved should be equal to the number of stones originally in the pile to which they are moved. For which natural numbers $k$ is it true that for all $n$, it is possible to make the number of stones in each pile equal through a finite number of operations?

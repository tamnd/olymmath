(53rd Romanian Mathematical Olympiad (1st Round) (1) Let $a$ be a real number greater than 1, and $f, g, h: \mathbf{R} \rightarrow \mathbf{R}$ be real functions such that $f(x) + g(x) + h(x) \geqslant 0$ for all $x \in \mathbf{R}$. Prove that $a^{f(x)} + a^{g(x)} + a^{h(x)} = 3$ has a solution if and only if the functions $f, g, h$ have a common root.
(2) Solve the equation $5^{1+\cos x} + 2^{-1} + 4^{1-|x|} = 3$.

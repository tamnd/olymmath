Let $x, y$ be non-zero real numbers, and satisfy
$$
\frac{x \sin \frac{\pi}{5} + y \cos \frac{\pi}{5}}{x \cos \frac{\pi}{5} - y \sin \frac{\pi}{5}} = \tan \frac{9 \pi}{20}.
$$
(1) Find the value of $\frac{y}{x}$;
(2) In $\triangle ABC$, if $\tan C = \frac{y}{x}$, find the maximum value of $\sin 2A + 2 \cos B$.

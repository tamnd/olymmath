The set of three-digit natural numbers formed from digits $1,2, 3, 4, 5, 6$ is called *nice* if it satisfies the following condition: for any two different digits from $1, 2, 3, 4, 5, 6$ there exists a number from the set which contains both of them.
For any nice set we calculate the sum of all its elements. Determine the smallest possible value of these sums.

(E. Barabanov)

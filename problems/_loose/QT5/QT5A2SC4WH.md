${ }^{+}$ Let $G$ be a connected countable graph that is not locally finite. Prove: $|G|$ is not compact, but $\Omega(G)$ is compact if and only if for any finite set $S \subseteq V(G)$, only finitely many components of $G-S$ contain a ray.

Let $\mathscr{A}=\left\{A_{1}, A_{2}, \ldots, A_{k}\right\}$ be a collection of subsets of a set $S$ which has $n$ ($n \geqslant 2$) elements. If for any two elements $x, y \in S$ there exists a subset $A_{i} \in \mathscr{A}$ such that $A_{i}$ contains exactly one of the elements $x, y$, prove that $n \leqslant 2^{k}$.

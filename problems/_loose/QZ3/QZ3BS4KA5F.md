a) Prove that $(p-1)!+1$ is divisible by $p$ if and only if the number $p$ is prime (Wilson's theorem).

b) Prove that

$$
((p-1)!)^{2} \equiv \begin{cases}0(\bmod p), & \text { if } p \text { is composite } \\ 1(\bmod p), & \text { if } p \text { is prime }\end{cases}
$$

Four (arbitrary) numbers $a, b, c, d$ are written down in a row. Below these numbers, a new set of four numbers $a_{1}=a b, b_{1}=b c, c_{1}=c d$, $d_{1}=d a$ is written; below them, the numbers $a_{2}=a_{1} b_{1}, b_{2}=b_{1} c_{1}$, $c_{2}=c_{1} d_{1}, d_{2}=d_{1} a_{1}$, and so on. Prove that either all the resulting sets of four numbers are different, or all of them, starting from some point, coincide with each other.

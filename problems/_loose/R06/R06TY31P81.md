We will prove that if $0 < x < \frac{\pi}{2}$, then $\sin x < x < \tan x$.

We will also prove that if $0 < x < \frac{\pi}{2}$, then $\cos x < \frac{\sin x}{x} < 1$.

And we will prove that if $0 < x < \frac{\pi}{2}$, then $\cos x < 1 < \frac{1}{\cos x}$.

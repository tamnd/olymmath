(a) Show that any Borel set $A$ in $\mathbb{R}$ can be represented as

$$
A=\{x \in \mathbb{R}:(x, y) \in D \text { for some } y \in \mathrm{P}\}
$$

for some closed set $D \subseteq \mathbb{R}^{2}$, where $\mathrm{P}$ is the set of irrational numbers in $[0,1]$.

(b) Show that there exists a closed set $U \subseteq \mathbb{R}^{3}$ with the property that any closed set $F$ in $\mathbb{R}^{2}$ can be represented as

$$
F=\left\{(x, y) \in \mathbb{R}^{2}:(x, y, z) \in U\right\}
$$

for some $z \in \mathbb{R}$.

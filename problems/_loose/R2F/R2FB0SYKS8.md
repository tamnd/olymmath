For any positive integer $n$, if
$$
f(n)=\left\{\begin{array}{l}
\log _{8} n, \text { if } \log _{8} n \text { is a rational number; } \\
0, \text { if } \log _{8} n \text { is not a rational number. }
\end{array}\right.
$$

then $\sum_{n=1}^{1997} f(n)=$
(A) $\log _{8} 2047$.
(B) 6 .
(C) $\frac{55}{3}$.
(D) $\frac{58}{3}$.
(E) 585 .
(48th American High School Mathematics Examination, 1997)

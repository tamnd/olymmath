Let $=\left\{A_{1}, A_{2}, \cdots, A_{t}\right\}$ be a reasonably spaced family of an $n$-element set $X$, then
$$
t \leqslant\left\{\begin{array}{l}
2 n, \text { if } n \equiv 0(\bmod 4) ; \\
n+1, \text { if } n \text { is odd; } \\
n+2, \text { if } n \equiv 2(\bmod 4) .
\end{array}\right.
$$

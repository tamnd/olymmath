A cut of a finite set of points in the plane is a partition of this set into disjoint subsets $A$ and $B$, for which there exists a line that does not pass through any point of the observed set, such that all points of set $A$ are on one side, and all points of set $B$ are on the other side of this line. Determine the maximum possible number of cuts of a set of $n$ points in the plane.

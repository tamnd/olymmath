Let's form a sequence of numbers $a_{1}, a_{2}, \ldots$ such that the first number $\left(a_{1}\right)$ is given arbitrarily, and then each subsequent number - if these are $a_{k}$ and $a_{k+1}$ - is calculated according to the formula

$$
a_{k+1}=\frac{c a_{k}+d}{e a_{k}+f}
$$

where $c, d, e, f$ are given numbers. Show that if $c=e=f=-d=1$, then the terms of the sequence are periodically repeating from some point onwards. - Can we choose any number for $a_{1}$ in this case? - Provide a set of values for $c, d, e, f$ such that using them, the number of different terms in the sequence is one less than in the above case.

26.1.5 ** $n$ children stand in a circle, each holding some number of balls. The following is called an operation: if everyone has an even number of balls, each person gives half of their balls to the child next to them, and if there is a child with an odd number of balls after this, an additional ball is given to that child. Prove: if initially each child has an even number of balls, then after several operations, each child will have the same number of balls.

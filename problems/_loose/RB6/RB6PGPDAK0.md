Given an equilateral triangle with side length $s$, $P$ is a point in the plane of the triangle, and the sum of the squares of the distances from $P$ to the three vertices of the triangle is a constant $a$. The locus of all points $P$ that satisfy this condition is
(A) If $a>s^{2}$, it is a circle.
(B) If $a=2 s^{2}$, it contains only three points; if $a>2 s^{2}$, it is a circle.
(C) It is a circle with a positive radius only when $s^{2}<a<2 s^{2}$.
(D) For any value of $a$, it contains only a finite number of points.
(E) None of these.
(27th American High School Mathematics Examination, 1976)

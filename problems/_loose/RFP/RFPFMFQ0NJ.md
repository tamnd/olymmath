(12th "Hope Cup" Senior High School Competition Problem) Given that the function $y=f(x)$ is defined on $\mathbf{R}$ with the smallest positive period $T=5$, it is a linear function on $[0,1]$. The graph is symmetric about the origin on $[-1,1]$, and it is a quadratic function on $[1,4]$, achieving its minimum value of -5 at $x=2$. Try to find the analytical expression for $y=f(x)$.

Given a finite set of cards. On each of them, either the number 1 or the number -1 is written (exactly one number on each card), and there are 100 more cards with -1 than cards with 1. If for each pair of different cards, the product of the numbers on them is found, and all these products are summed, the result is 1000. How many cards have the number 1?

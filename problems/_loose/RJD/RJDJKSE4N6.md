A circular stage for a circus performance is illuminated by $n$ searchlights, each of which illuminates a convex shape on the stage. It is known that when any one of the searchlights is turned off, the stage is still fully illuminated; but if any two searchlights are turned off, the stage cannot be fully illuminated. Find all possible values of $n$.

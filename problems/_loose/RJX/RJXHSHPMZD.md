\section*{Problem 3A - 141043A}

Let $A B C D S$ be a straight quadrilateral pyramid with a fixed square base $A B C D$.

We consider all closed line segments $P Q R T P$, where $P$ is a fixed interior point of the edge $A S$, $Q$ is an interior point of $B S$, $R$ of $C S$, and $T$ of $D S$.

Determine the set of all angles $\rho\left(0^{\circ}<\rho<90^{\circ}\right)$ for which the following holds:

If the angle $\angle A S B$ has the size $\rho$, then among the line segments $P Q R T P$ considered on the pyramid $A B C D S$, there exists a shortest one.

In a mathematics circle, non-constant functions are discussed that are defined for all real numbers and whose function values are also real numbers.

If $f$ and $g$ are two such functions, the function $F$ can be defined for all real $x$ by $F(x)=f(g(x))$.

The discussion focuses on whether such functions $f, g, F$ are periodic.

(A function $\rho$ is called periodic if there exists a real number $p>0$ such that for all $x$ the equation $\rho(x+p)=\rho(x)$ holds.)

Jens claims: If $g$ is a periodic function (and $f$ is periodic or not), then the function $F$ defined as above is always periodic.

Dirk claims: If $f$ is a periodic function (and $g$ is periodic or not), then the function $F$ is always periodic.

Christa claims: If both functions $f$ and $g$ are not periodic, then $F$ is also always not periodic.

Examine for each of these three students whether they have made a true or a false statement!

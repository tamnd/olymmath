Let $m$ be a real number and $f(x)=(m-2) x^{2}-2 m x+3 m$.

a) Calculate the value of the parameter $m$ so that the graph of the function $f$ passes through the point $T(-2,3)$. For the calculated value of the parameter $m$, write the rule of the function $f$.

b) Calculate for which value of the parameter $m$ the graph of the function $f$ is not a parabola. What is the graph of the function $f$ in this case? For the calculated value of the parameter $m$, write the rule of the function $f$ and its inverse function $f^{-1}$.

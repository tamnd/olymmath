Given finite set $S$ of natural numbers. First player selects number $s$ from $S$, second player says number $x$ not necessary in $S$ and first player says $\sigma_{0}(xs)$. Prove that second player can say only one number $x$ and understand, which number first has selected. (Both players know all elements of $S$)

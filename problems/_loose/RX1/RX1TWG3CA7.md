Let $\mathrm{S}$ be a set of $\mathrm{n}$ positive integers. Let $\mathrm{P}$ be the set of all integers which are the sum of one or more distinct elements of $\mathrm{S}$. Show that we can find $\mathrm{n}$ subsets of $\mathrm{P}$ whose union is $\mathrm{P}$ such that if $\mathrm{a}, \mathrm{b}$ belong to the same subset, then $\mathrm{a} \leq 2 \mathrm{~b}$.

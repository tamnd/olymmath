$36{ }^{+}$ Proof: A graph has a large treewidth if and only if it contains a large externally $k$-connected vertex set (where $k$ is a large value). For example, prove: A graph with treewidth $<k$ does not contain an externally $k$-connected set with $3 k$ vertices, and a graph that does not contain an externally $(k+1)$-connected set with $3 k$ vertices has treewidth $<4 k$.

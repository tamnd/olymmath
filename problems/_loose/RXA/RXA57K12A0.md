A young hacker wants to change the grades in the electronic journal. But when changing some grades, others change as well, specifically: a) if he increases the number of fives by 2, then the number of twos decreases by 1; b) if he increases the number of fives by 1, then the number of twos increases by 2; c) if he decreases the number of fives by 2, then the number of twos increases by 1; d) if he decreases the number of fives by 1, then the number of twos decreases by 2. Can he, by performing such operations, turn his 3 fives and 30 twos into 30 fives and 3 twos?

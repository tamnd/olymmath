Let $ X $ be a set with $ n $ elements. The power set of $ X $, denoted by $ P(X) $, is the set of all subsets of $ X $. find the number of functions $f: P(X) \to \{0, 1\} $ such that for any $A,B\in P(X)$ we have $$ f(A)f(B) = f(A\cap B)f(A\cup B). $$

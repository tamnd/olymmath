Let's take a three-digit number, for example, 346. By writing the digits in reverse order, we get 643. Subtracting the smaller number from the larger one $(643-346)$, we get 297. Writing the digits of this number in reverse order again: 792. The sum of these two numbers $297+792=1089$. Is it true that we always get 1089 as the result, no matter which three-digit number we choose?

$$
x_{1}+x_{2}+\cdots+x_{n}=633 \text { and } \frac{1}{x_{1}^{2}}+\frac{1}{x_{1}^{2}}+\cdots+\frac{1}{x_{n}^{2}}=\frac{2017}{36} \text {, }
$$
find the value of $n$.

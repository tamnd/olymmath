Given $\triangle A B C$ in the plane, for a point $P$ in the plane, establish the following transformation $f: A P$'s midpoint is $Q, B Q$'s midpoint is $R, C R$'s midpoint is $P^{\prime}, f(P)=P^{\prime}$. Prove: $f$ has only one fixed point (the point where $P$ coincides with $P^{\prime}$).

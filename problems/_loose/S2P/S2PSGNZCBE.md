(1) Let $A, B, C$ be three distinct points on a line $l$ in sequence. Prove that there exists a point $P$ outside $l$ such that $\angle A P B = \angle B P C ;$
(2) For any four points $A, B, C, D$ on a line $l$ in sequence, does there always exist a point $P$ outside $l$ such that $\angle A P B = \angle B P C = \angle C P D$? If point $P$ always exists, provide a proof; if point $P$ does not always exist, give a counterexample.

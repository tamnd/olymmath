A container for liquid has the shape of a right circular cone with a height of $12 \mathrm{~cm}$ and a base radius of $5 \mathrm{~cm}$. If we pour liquid into the container and hold it (closed) so that its vertex is pointing downwards and the base is in a horizontal position, the depth of the poured liquid is $9 \mathrm{~cm}$. How many $\mathrm{cm}^{3}$ of liquid need to be added to the container so that the depth of the liquid is $9 \mathrm{~cm}$ and in the case where the container is inverted with the vertex pointing upwards (and the base in a horizontal position)?

For the positive integer $\mathrm{n}$, define the set $A_{n}=\left\{a\left|a \in Z^{+}, a \leq n, n\right|\left(a^{n}+1\right)\right\}$.
(1) Find all positive integers $n$ such that $A_{n}$ is not an empty set;
(2) Find all positive integers $n$ such that $A_{n}$ is not an empty set, and $\left|A_{n}\right|$ is even.

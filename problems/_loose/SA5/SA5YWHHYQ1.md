Anja, Brigitte, Cathrin, Daja, and Eva played several four-player games among themselves. In each game, there was one winner and three losers. Each of the girls played the same number of times. After all the games were completed, it was observed:

(1) Cathrin won exactly half, Daja exactly one third, and Eva exactly one quarter of the games they participated in.

(2) The number of wins of the girl who achieved the third-best result was a prime number.

(3) None of the girls lost all the games.

Determine the exact number of games that were played and state how many games each girl won in total!

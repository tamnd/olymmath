Show that for any $n$, there exists a multiple of $n$ with at most $n$ digits, all equal to 0 or 1.

The drawers will be the number of interns known. It can vary from 0 to 45, which makes 46 drawers for 46 interns, which is one drawer too many. But we notice that if an intern knows the 45 other interns, then all the interns know him, so the number of interns known cannot take the value 0 if it takes the value 45. It therefore takes at most 45 values, and the pigeonhole principle applies.

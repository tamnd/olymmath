Triangular Network (I). As is known, the entire plane can be covered with a network of equilateral triangles.

Can one place a plus or minus sign at each node of this network so that for each triangle forming the network, the following rule applies: if two vertices of the triangle have the same sign, then the third vertex will be a plus, and if otherwise - then the third vertex will be a minus.

Of course, one can place pluses everywhere, but this trivial solution we exclude.

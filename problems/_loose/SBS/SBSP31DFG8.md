A set of points in the plane is called *sane* if no three points are collinear and the angle between any three distinct points is a rational number of degrees.

(a) Does there exist a countably infinite sane set $\mathcal{P}$?

(b) Does there exist an uncountably infinite sane set $\mathcal{Q}$?

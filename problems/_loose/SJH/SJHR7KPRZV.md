A set $H$ contains $2n$ points in the plane, no three of which are collinear. If $P$ and $Q$ are two distinct points in $H$, and $H$ has exactly the same number of points on each side of the line $PQ$, then the segment $PQ$ is called a bisecting segment. Prove that if the number of bisecting segments is $n$, then any two of them intersect.

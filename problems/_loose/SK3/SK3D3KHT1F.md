(Shortlist 2010) For any pair of integers ( $a, b$ ) we define $f(k)=a k^{3}+b k$. We say that a pair ( $a, b$ ) is $n$-good if for any pair ( $m, k$ ) of integers we have

$$
\sin \mid f(k)-f(m) \text { then } n \mid(k-m)
$$

If a pair is $n$-good for infinitely many values of $n$, then we say it is very good. Find a pair (a,b) that is 51-good but not very good. Show that if a pair is 2013-good then it is very good.

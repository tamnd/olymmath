If $c$ is a positive real number, then $f$ denotes the function defined for all real $x \neq 0$ by $f(x)=\sin \frac{c}{x}$.

Given is now an arbitrary natural number $m>1$.

a) Determine (in dependence on $m$) all positive real numbers $c$ for which the function $f$ has exactly $m$ zeros in the interval $10 \leq x \leq 20$, including the numbers 10 and 20 themselves.

b) For each $c$ found in a), prove that $f$ has only finitely many zeros in the interval $20 \leq x < \infty$.

Furthermore, determine (in dependence on $m$ and for each $c$ found for the respective $m$) the largest zero of $f$.

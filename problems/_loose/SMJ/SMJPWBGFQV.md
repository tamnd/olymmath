In each field of a table there is a real number. We call such $n \times n$ table silly if each entry equals the product of all the number in the neighbouring fields.

a) Find all $2 \times 2$ silly tables.

b) Find all $3 \times 3$ silly tables.

(Two fields of a table are neighbouring if they share a common side.)

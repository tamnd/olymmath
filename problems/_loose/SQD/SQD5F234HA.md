A discrete two-dimensional random variable $(X, Y)$ is given:

| $Y$ | $X$ | | |
| :---: | :---: | :---: | :---: |
| | $x_{1}=2$ | $x_{2}=5$ | $x_{2}=8$ |
| | | | |
| $y_{1}=0.4$ | 0.15 | 0.30 | 0.35 |
| $y_{2}=0.8$ | 0.05 | 0.12 | 0.03 |

Find: a) the unconditional distribution laws of the components; b) the conditional distribution law of the component $X$ given that the component $Y$ has taken the value $y_{1}=0.4$; c) the conditional distribution law of $Y$ given that $X=x_{2}=5$.

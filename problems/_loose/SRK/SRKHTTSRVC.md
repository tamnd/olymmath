Consider the function $f: \mathbb{R} \rightarrow \mathbb{R}$ which is periodic, non-constant, and admits primitives.

a) Prove that any primitive of the function $f$ can be written as the sum of a periodic function and a function of the type $G: \mathbb{R} \rightarrow \mathbb{R}, G(x)=a x$, where $a \in \mathbb{R}$.

b) If $F: \mathbb{R} \rightarrow \mathbb{R}$ is a primitive of the function $f$, calculate $L=\lim _{x \rightarrow \infty} \frac{F(x)}{x}$.

c) Show that the limit $\lim _{x \rightarrow \infty}(F(x)-L x)$ does not exist.

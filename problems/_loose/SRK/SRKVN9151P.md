In space, a point $O$ and $n$ pairwise non-parallel lines are given. The point $O$ is orthogonally projected onto all the given lines. Each of the resulting points is again projected onto all the given lines, and so on. Does there exist a sphere that contains all the points that can be obtained in this way?

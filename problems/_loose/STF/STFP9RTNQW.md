$$
f(x)=x^{4}-(x+1)^{4}-(x+2)^{4}+(x+3)^{4}
$$

where the domain of $f$ is

a) the set of all integers,

b) the set of all real numbers.

Investigate, for both case a) and case b), whether the function $f$ attains a minimum value, and determine, if applicable, this minimum value in each case.

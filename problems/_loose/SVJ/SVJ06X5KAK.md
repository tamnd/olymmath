Among these $Q_{n, m}$, find a sequence of nested edge sets (taking one edge set for each $m$). As continuous mappings on $[0,1]$, parameterize the paths in this sequence so that they converge to a meaningful limit. To obtain the required $x-y$ arc in $|G|$, use the theorem "the image of every topological $x-y$ path in a Hausdorff space contains an $x-y$ arc."

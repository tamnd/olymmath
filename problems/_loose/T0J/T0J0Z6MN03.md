We call a positive integer a *reverse difference* if it can be written as a positive integer whose last digit is not a $0$, minus the number consisting of the same digits in reverse order. For example, $2178$ is a reverse difference because $4202 - 2024 = 2178$.

Which of the following numbers is *not* a reverse difference?

A) $1359$
B) $2538$
C) $3906$
D) $4447$
E) $5355$

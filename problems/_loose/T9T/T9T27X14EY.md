On the set of natural numbers greater than 9, we define the function $f$ as follows: if $\overline{c_{1} c_{2} \ldots c_{s}}(s \geqslant 2)$ is the decimal representation of the number $n$, then $f(n)$ is the natural number obtained by replacing all occurrences of the digit $c_{1}$ in the number $n$ with the digit $c_{2}$, and all occurrences of the digit $c_{2}$ in the number $n$ with the digit $c_{1}$; if a leading zero appears in the resulting number after this operation, it is removed. (For example, $f(2375342)=3275243$ and $f(502305)=52350$.) Find all natural numbers that can appear as the value of the expression $\frac{n}{f(n)}$.

Given the following statements:
1) Joe is a trickster;
2) Joe is unlucky;
3) Joe is lucky, but he is not a trickster;
4) if Joe is a trickster, then he is unlucky;
5) Joe is a trickster if and only if he is lucky;
6) either Joe is a trickster or he is lucky, but not both at the same time.

What is the maximum number of these six statements that can be true simultaneously?

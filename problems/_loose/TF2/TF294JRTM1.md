Let $a, b$ be two natural numbers, and there are $a b$ candies. Pack these candies into several packs so that these candies can be divided into $a$ portions, each with $b$ candies, or these candies can be divided into $b$ portions, each with $a$ candies. Find the minimum number of all possible pack numbers.

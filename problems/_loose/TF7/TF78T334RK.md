Let's subtract twice the last digit of an integer from the number obtained by omitting the last digit (if the integer is a single digit, subtract from 0). Prove that if the result is divisible by 7, then the original number is always divisible by 7, and if the result is not divisible by 7, then the original number cannot be divisible by 7.

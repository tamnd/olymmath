Let $A, B$ and $C$ be three points on a given circle $k$. Consider the point $F$ that bisects the broken line segment $A C B$ (that is, if $C A < C B$, then $F$ is the point on the segment $C B$ such that $A C + C F = F B$, and if $A C \geq C B$, then $F$ is the point on the segment $A C$ such that $A F = F C + C B$).

What is the geometric locus of these $F$ points if $A$ and $B$ are fixed, and $C$ runs through $k$?

Each of the robbers in an n-member gang ( $n \geqq 3$ ) looted a certain number of coins. The total number of looted coins was 100n. The robbers decided to distribute the loot in the following way: in each step, one of the robbers gives one coin to two other robbers. Find all natural numbers $n \geqq 3$, for which after a finite number of steps, each robber can have 100 coins regardless of how many coins each individual robber looted.

(Ján Mazák)

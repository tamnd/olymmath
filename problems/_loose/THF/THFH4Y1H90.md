The number 4 is written on the board. In one move, Anya is allowed to choose any proper divisor of the number written on the board, add it to this number, and write the sum instead of the old number. This operation is allowed to be performed an unlimited number of times. Prove that Anya can obtain any composite number on the board. A divisor of a number $ n $ is called proper if it is not equal to 1 and $ n $.

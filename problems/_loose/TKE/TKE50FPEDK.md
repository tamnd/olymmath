The sequence $\left\{x_{n}\right\}$ is defined as follows: $x_{1}=1$, for $k>0$, $x_{2 k}=\left\{\begin{array}{l}2 x_{k}, \text { if } k \text { is even, } \\ 2 x_{k}+1, \text { if } k \text { is odd; }\end{array} x_{2 k+1}=\left\{\begin{array}{l}2 x_{k}, \text { if } k \text { is odd, } \\ 2 x_{k}+1, \text { if } k \text { is even. }\end{array}\right.\right.$ Prove that the sequence $\left\{x_{n}\right\}$ can take every positive integer exactly once.

Let $\mathrm{S}$ be a set with 2002 elements and $\mathrm{P}$ the set of all its subsets. Prove that for any $\mathrm{n}$ (in the range from zero to $|\mathrm{P}|)$ we can color $\mathrm{n}$ elements of $\mathrm{P}$ white, and the rest black, so that the union of any two elements of $\mathrm{P}$ with the same color has the same color.

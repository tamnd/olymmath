96.+ Let $G$ be a locally finite graph, and $X$ a connected standard subspace of $|G|$. We call a continuous map $\sigma: S^{1} \rightarrow X$ a topological Euler tour of $X$ if it crosses each edge of $E(X)$ exactly once. (Formally, any interior point of an edge in $E(X)$ is the image of exactly one point in $S^{1}$.) Using compactness, prove: $X$ contains a topological Euler tour if and only if $E(X) \in \mathcal{C}(G)$.

\section*{Problem 3B - 231043B}

a) Give a function $f$ defined for all real numbers that has the property for all real numbers $x$:

$$
f(x+1)=f(x)+(-1)^{[f(x)]}
$$

Here, if $z$ is a real number, $[z]$ denotes the integer $[z]=g$ such that $g \leq z \leq g+1$.

Prove that the function $f$ you have given has the property (1)!

Sketch the graph of this function $f$ for all $x$ in the interval $-3 \leq x \leq 3$!

b) Prove that any function $f$ with the property (1) must be periodic with period 2, i.e., it must satisfy the equation $f(x+2)=f(x)$ for all real $x$!

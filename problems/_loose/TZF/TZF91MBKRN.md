In some cells of an $n \times n$ chessboard, there are stars; it is known that if any set of rows of the board is crossed out (of course, not all!), then there will be a column in which there is exactly one uncrossed star. (In particular, if no rows are crossed out at all, then there will also be a column in which there is exactly one star.) Prove that if any set of columns (but not all) is crossed out, then there will be a row in which there is exactly one uncrossed star.

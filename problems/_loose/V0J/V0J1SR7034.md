Show that the number of non-decreasing paths (on the integer lattice $\left.\mathbb{Z}_{+}^{r}=\left\{\left(i_{1}, \ldots, i_{r}\right) ; i_{1}, \ldots, i_{r}=0,1,2, \ldots\right\}\right)$, starting from the point $(0, \ldots, 0)$ and ending at the point $\left(n_{1}, \ldots, n_{r}\right)$ with $\sum_{i=1}^{r} n_{i}=N$, is $C_{N}\left(n_{1}, \ldots, n_{r}\right)$. (A path is considered non-decreasing if at each step only one coordinate changes, increasing by one.)

Show that the Cantor set $\mathscr{C}$ is compact, perfect (i.e., closed and dense in itself, or in other words, without isolated points), and nowhere dense.

Remark. This is nothing more than a topological characterization of the Cantor set on the line. Specifically, any compact, perfect, nowhere dense set in $\mathbb{R}$ is homeomorphic to the Cantor set. This follows from the results of Brouwer [43], where the structure of compact sets in $\mathbb{R}^{n}$ is investigated. It is interesting to note other important subsets of $\mathbb{R}$ that admit a similar characterization:

1) the set of rational numbers $\mathbb{Q}$ is the unique (up to homeomorphism) countable set in $\mathbb{R}$ without isolated points (Sierpiński, [102]);
2) the set of irrational numbers $\mathbb{P}$ is the unique set in $\mathbb{R}$ that contains no open interval and is a complete metric space under some metric, and such that it contains no open sets with compact closure (Alexandrov, Urysohn, [28]).

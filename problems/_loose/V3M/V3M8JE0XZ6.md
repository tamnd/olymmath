Let $k$ be a strictly positive integer. For any real number $x$, the real number $|x|$ is the absolute value of $x$, which is $x$ if $x$ is positive, $-x$ if $x$ is negative. Find the number of triplets $(x, y, z)$ where $x, y, z$ are integers such that $x+y+z=0$ and $|x|+|y|+|z|=2k$.

Scattering function (2 p. 7-11). Given a numerical set $x_{1}, \ldots, x_{n}$. Consider the function $d(t)=\frac{\min _{i=1, \ldots, n}\left|x_{i}-t\right|+\max _{i=1, \ldots, n}\left|x_{i}-t\right|}{2}$.

a) Is it true that the function $d(t)$ takes its minimum value at a unique point, regardless of the set of numbers $x_{1}, \ldots, x_{n}$?

b) Compare the values of $d(c)$ and $d(m)$, where $c=\frac{\min _{i=1, \ldots, n} x_{i}+\max _{i=1, \ldots, n} x_{i}}{2}$, and $m$ is its median.

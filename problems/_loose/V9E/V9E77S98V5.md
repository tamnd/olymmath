In a box, there are balls of blue, green, and red color. If we want to draw a certain number of balls and be sure that among them there is at least one ball of each color, it is necessary to draw 11 balls. If we want to be sure that among the drawn balls there is a green ball, it is necessary to draw 10 balls. If we want to be sure that among the drawn balls there is a red ball, it is necessary to draw 8 balls. How many balls of each color are in the box?

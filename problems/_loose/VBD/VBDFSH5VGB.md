Alex bought several boxes of candies and recorded the number of candies in each box. Serge took one candy from each box and put it in the first plate, then in the second plate he put one candy from each non-empty box, and so on. Once he emptied all the boxes, Serge recorded the number of candies in each plate. Prove that the number of different numbers recorded by Alex is equal to the number of different numbers recorded by Serge.

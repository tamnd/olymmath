Given the function
$$
f(x)=\ln (a x+b)+x^{2} (a \neq 0).
$$
(1) If the tangent line to the curve $y=f(x)$ at the point $(1, f(1))$ is $y=x$, find the values of $a$ and $b$;
(2) If $f(x) \leqslant x^{2}+x$ always holds, find the maximum value of $a b$.

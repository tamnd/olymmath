On the coordinate plane, a convex pentagon $A B C D E$ is given, with all vertices having integer coordinates. Prove that there is always a point with integer coordinates inside the pentagon, even if there is only one such point. Is a similar statement true for non-convex pentagons?
(9th All-Russian Mathematical Olympiad, 1983)

For the function $f(x)=a x^{2}+b x+c$, we know that for any $|u| \leq \frac{10}{11}$, there exists a $v$ such that $|u-v| \leq \frac{1}{11}$ and $|f(v)| \leq 1$. Prove that in this case, for any point $x$ in the interval $-1 \leq x \leq 1$, $|f(x)| \leq 2$.

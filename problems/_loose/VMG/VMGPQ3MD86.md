Let $A B C$ be an equilateral triangle. Let $E$ be the set of all points from segments $A B, B C$, and $C A$ (including $A, B$, and $C$ ). Is it true that for any partition of the set $E$ into two disjoint subsets, there exists a right-angled triangle all of whose vertices belong to the same subset in the partition?

Given a natural number $N$. The following operation is performed with it: each digit of this number is written on a separate card (it is allowed to add or discard any number of cards with the digit 0), and then these cards are divided into two piles. In each of them, the cards are arranged in any order, and the two resulting numbers are added. The same operation is performed with the resulting number $N_{1}$, and so on. Prove that in fifteen steps, a single-digit number can be obtained from $N$.

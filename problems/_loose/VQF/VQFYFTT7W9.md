Given a positive integer $m$, prove: there exists a positive integer $k$, such that the set of positive integers $\mathbf{N}^{*}$ can be partitioned into $k$ mutually disjoint subsets $A_{1}, A_{2}, \cdots, A_{k}$, where each subset $A_{i}$ does not contain 4 numbers $a, b, c, d$ (which can be the same), satisfying $a b - c d = m$.

Let $f=f(x)$ be a Borel function defined on $\mathbb{R}_{+}$ such that

$$
\int_{\mathbb{R}_{+}} e^{-\lambda x} f(x) d x=0 \text { for all } \lambda \in \mathbb{N} \text {. }
$$

Show that $f=0$ a.e. with respect to Lebesgue measure.

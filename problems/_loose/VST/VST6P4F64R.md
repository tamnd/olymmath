Given the function
$$
f(x)=x-\frac{1}{x}-\ln x \text{. }
$$
(1) If $f(x)=x-\frac{1}{x}-\ln x$ has equal derivatives at $x=x_{1}, x_{2}$ $\left(x_{1} \neq x_{2}\right)$, prove:
$$
f\left(x_{1}\right)+f\left(x_{2}\right)>3-2 \ln 2 \text{; }
$$
(2) If for any $k \in(-\infty, 1)$, the line $y=k x+b$ intersects the curve $y=f(x)$ at exactly one point, find the range of real values for $b$.

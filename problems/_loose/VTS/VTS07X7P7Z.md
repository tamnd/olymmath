(Problem from the 30th Russian Mathematical Olympiad) Prove: there does not exist a finite set $G$ of more than $2 n (n>3)$ pairwise non-parallel vectors in the plane with the following properties:
(1) For any $n$ vectors in this set, it is possible to find $n-1$ more vectors in the set such that the sum of these $2 n-1$ vectors is 0;
(2) For any $n$ vectors in this set, it is possible to find $n$ more vectors in the set such that the sum of these $2 n$ vectors is 0.

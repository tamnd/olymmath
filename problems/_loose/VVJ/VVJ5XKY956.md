In a discussion, three different tasks are considered:

a) The number 231 is to be represented as a product. Each factor should be a prime number.

b) The number 231 is to be represented as a product of exactly three factors. Each factor should be a natural number. Any two of the factors should be different from each other.

c) The same task as b) is to be performed with 462 instead of 231.

For a), b), and c), provide all different representations! Representations that differ only by the order of the factors are not considered different. Justify that you have provided all the required representations!

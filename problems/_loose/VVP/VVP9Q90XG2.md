Write the integers from 0 to 1985 in a row in increasing order, then write the sum of each pair of adjacent numbers in a new second row, and then write the sum of each pair of adjacent numbers in the third row, and so on, until only one number remains and no new row is generated. Prove that this number is divisible by 1985.
（11th All-Russian Mathematical Olympiad, 1985）

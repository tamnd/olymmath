There are $n$ mathematicians attending a conference, and each mathematician has exactly 3 friends (friendship is mutual). Now, if we arrange some of the mathematicians to sit around a round table to discuss problems, it turns out that if everyone is seated next to their friends, then the number of people at the table is no less than 7. Find the minimum possible value of $n$.

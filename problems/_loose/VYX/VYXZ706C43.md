We have 13 balls weighing 1 to $13 \mathrm{~kg}$, but with similar appearances. At the factory, a small label indicating its weight (thus, the labels also range from 1 to 13) was stuck on each ball. We want to verify that all the labels have been stuck correctly, without any permutations relative to the actual weights of the balls. For this, we have a two-pan balance. It does not allow us to determine the weight of any particular ball (or set of balls). It only allows us to check if the set of balls placed on the left pan weighs less, the same, or more than the set of balls placed on the right pan. Show that we can ensure in 3 weighings that all the labels are stuck correctly.

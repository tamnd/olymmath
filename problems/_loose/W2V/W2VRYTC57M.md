Composite Squares. Can you find two three-digit squares (with no zeros) that, when written consecutively, form a six-digit number which itself is a square? For example, from 324 and $900\left(18^{2}\right.$ and $\left.30^{2}\right)$ we get $324900\left(570^{2}\right)$, but the number 900 contains two zeros, which is prohibited by the condition.

The problem has only one solution.

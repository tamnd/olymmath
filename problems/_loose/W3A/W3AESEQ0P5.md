Let the function $f(x)$ satisfy $f(x+2\pi) = f(x)$ for all real numbers $x$. Prove that there exist 4 functions $f_i(x) (i=1,2,3,4)$ that satisfy:
(1) For $i=1,2,3,4$, $f_i(x)$ is an even function, and for any real number $x$, $f_i(x+\pi) = f_i(x)$;
(2) For any real number $x$, $f(x) = f_1(x) + f_2(x) \cos x + f_3(x) \sin x + f_4(x) \sin 2x$.

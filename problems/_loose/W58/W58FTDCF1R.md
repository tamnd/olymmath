In a $4 n \times 4 n\left(n \in \mathbf{N}_{+}\right)$ real number table, the absolute value of each number does not exceed 1, and the sum of all numbers is 0. It is known that the absolute value of the sum of each row and the absolute value of the sum of each column are not less than $c$. Find the maximum possible value of $c$.

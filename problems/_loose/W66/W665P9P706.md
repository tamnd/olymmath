Given a square table, in some cells of which there are crosses. Let's call a row of the table odd if it contains an odd number of crosses. Similarly, in an odd column, there is an odd number of crosses. a) Can it happen that in the table there are exactly 20 odd rows and 15 odd columns? b) Can 126 crosses be placed in a $16 \times 16$ table so that all rows and columns are odd?

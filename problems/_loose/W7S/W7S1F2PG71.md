Let $a$ and $b$ be integers. Write the number $b$ to the right of the number $a$. If the number $a$ is even, then divide it by 2; if it is odd, then subtract one from it and then divide it by 2. The resulting number $a_{1}$ write under the number $a$. To the right of the number $a_{1}$, write the number $2 b$. Perform the same operation on the number $a_{1}$ as on the number $a$, and, obtaining the number $a_{2}$, write it under the number $a_{1}$. To the right of the number $a_{2}$, write the number $4 b$ and so on. Continue this process until we get the number 1 in the left column. Prove that the sum of those numbers in the right column, to the left of which stand odd numbers, is equal to the product $a b$.

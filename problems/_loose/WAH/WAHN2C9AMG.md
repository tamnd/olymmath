A cube consisting of $(2 n)^{3}$ unit cubes is pierced by several spokes parallel to the edges of the cube. Each spoke pierces exactly $2 n$ cubes, and each cube is pierced by at least one spoke.

a) [6] Prove that it is possible to choose such $2 n^{2}$ spokes, going in one or two directions in total, so that no two of these spokes pierce the same cube.

b) [6] What is the maximum number of spokes that can be guaranteed to be chosen from the existing ones so that no two chosen spokes pierce the same cube?

(Nikita Gladkov, Alexander Zimin)

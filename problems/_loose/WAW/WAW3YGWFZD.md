Below is the standard method for evaluating solutions.

| Points | Correctness (incorrectness) of the solution |
| :---: | :--- |
| 7 | Fully correct solution. |
| $6-7$ | Correct solution, but with minor flaws that do not significantly affect the solution. |
| $5-6$ | The solution is generally correct. However, it contains errors or cases are omitted that do not affect the logic of the reasoning. |
| $3-4$ | In the case where the solution to the problem is divided into two equally important parts - the solution of one of the parts. |
| $2-3$ | Auxiliary statements that help in solving the problem have been proven. |
| $0-1$ | Individual cases have been considered in the absence of a solution. |
| 0 | The solution is incorrect, no progress has been made. |
| 0 | The solution is absent. |

It is important to note that any correct solution is evaluated at 7 points. Points should not be deducted for the solution text being too long, or for the correct solution differing from the one provided in the criteria or from other solutions known to the jury. At the same time, any solution text, no matter how long, that does not contain useful progress should be evaluated at 0 points.

7.1.

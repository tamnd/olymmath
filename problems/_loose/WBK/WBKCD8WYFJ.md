A finite set $H$ of non-negative real numbers is called closed if the following holds: if $x$ and $y$ are elements of $H$, then $x+y$ or $|x-y|$ is also an element of $H$. For example, the set $S(n, \alpha)=\{0, \alpha, 2 \alpha, \ldots, n \alpha\}$, where $\alpha>0$ is any real number and $n \geqq 0$ is an integer, is such a set. Prove that if $H$ is closed and not of the type $S(n, \alpha)$, then it has four elements.

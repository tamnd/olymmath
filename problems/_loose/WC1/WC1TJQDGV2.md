If we consider digits in different positions as different, then in a $d$-ary numeral system, $n d$ digits allow us to write $d^{n}$ numbers (from 0 to $d^{n}-1$). Which numeral system is the most economical in this respect, i.e., allows recording the largest number of numbers using a given number of digits? (When comparing numeral systems with bases $d_{1}$ and $d_{2}$, we consider only sets of $m$ digits, where $m$ is divisible by $d_{1}$ and $d_{2}$.)

See also problems $20.15,20.17$.

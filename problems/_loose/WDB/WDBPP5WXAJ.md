The function $y=f(x)$ is defined on $R$, and it has an inverse function. If the graph of the function is rotated $90^{\circ}$ counterclockwise around the origin in the $x O y$ plane, the new graph represents the function
(A) $y=-f^{-1}(-x)$.
(B) $y=-f^{-1}(x)$.
(C) $y=f^{-1}(x)$.
(D) $y=f^{-1}(-x)$.
(2nd "Hope Cup" National Mathematics Invitational Competition, 1991)

If $A=\{a_1,a_2,\ldots,a_p\}$ is a set of real numbers with $a_1>a_2>\ldots>a_p,$ we denote $s_A= \sum\limits_{k=1}^p (-1)^{k+1}a_k.$
Let $M \subset \mathbb{Z}_{\ge 0}$ be a set with $n$ elements ( $n$ is a positive integer). Prove that $2^{n-1}$ divides $\sum\limits_{A \subseteq M} s_A.$

We wrote one number on each of 10 discs, and the numbers $0,1,2,3,4$ each appear on two discs. Arrange the discs in a row so that for any two discs with the same number, there are as many other discs standing between them as the number written on them, for example, there are 3 other discs between the two 3s. - Let's also create those arrangements that meet the same requirement but are missing: I. one of the zero discs; II. both zero discs; III. both zero and both four discs.

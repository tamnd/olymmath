A water pool has two water inlet valves, A and B. If only valve A is opened, it takes 10 hours to fill the empty pool; if only valve B is opened, it takes 15 hours to fill the empty pool. Now, it is required to fill the empty pool in 7 hours. This can be done by opening only valve A for a certain number of hours, then opening only valve B for a certain number of hours, and finally opening both valves A and B simultaneously. How many hours should both valves A and B be opened simultaneously?

Let $\mathscr{S}$ be the set of all lines in the plane. Function $f$ satisfies that for every line $l \in \mathscr{D}, f(l)$ is a point on the line $l$. If for any point $X$ and any three lines $l_{1}, l_{2}, l_{3}$ passing through point $X$, the points $f\left(l_{1}\right), f\left(l_{2}\right), f\left(l_{3}\right), X$ lie on the same circle, prove: there exists a unique point $P$ such that for any line $l$ passing through point $P$, we have $f(l)=P$.

Let the first progression be: $a_{1}, a_{2}, \ldots, a_{2015}$; the second: $b_{1}, b_{2}, \ldots, b_{2015}$. The common difference of the first progression is denoted by $d$, and the second by $-\delta$. Then

$$
\left\{\begin{array} { l }
{ a _ { 1 } + 2 0 1 4 d = 4 b _ { 1 } , } \\
{ b _ { 1 } + 2 0 1 4 \delta = 4 a _ { 1 } , } \\
{ 2 a _ { 1 } + 2 0 1 4 d = 4 b _ { 1 } + 2 \cdot 2 0 1 4 \delta }
\end{array} \Longleftrightarrow \left\{\begin{array}{l}
2014 d=4 b_{1}-a_{1} \\
2014 \delta=4 a_{1}-b_{1} \\
7 a_{1}=2 b_{1}
\end{array}\right.\right.
$$

From which $\frac{d}{\delta}=\frac{4 b_{1}-a_{1}}{4 a_{1}-b_{1}}=26$.

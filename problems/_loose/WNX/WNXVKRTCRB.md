We know the following about three pioneers in a class:

(1) They have the first names Alex, Bodo, and Dietmar.

(2) Their last names are Neumann, Siebert, and Keller. The order of the first names does not necessarily correspond to the order of the last names.

(3) Alex is not named Neumann.

(4) The pioneer with the last name Keller is older than the pioneer with the first name Bodo.

(5) The mother of the pioneer Neumann is a born Mittag.

(6) The mother of Bodo has the maiden name Rößler.

Determine the last names that correspond to the first names of the pioneers!

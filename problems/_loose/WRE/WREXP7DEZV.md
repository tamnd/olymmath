Eight objects, denoted by $A_{1}, A_{2}, \ldots, A_{8}$, have been locked in two cabinets $S_{1}$ and $S_{2}$. To determine the distribution of the objects, the following statements are made. In cabinet $S_{1}$ are

(1) $A_{1}$ if and only if both $A_{3}$ and $A_{5}$ are in $S_{1}$;

(2) $A_{2}$ if and only if both $A_{3}$ and $A_{6}$ are in $S_{1}$;

(3) $A_{3}$ if and only if both $A_{4}$ and $A_{8}$ are in $S_{2}$;

(4) $A_{4}$ if and only if both $A_{1}$ and $A_{8}$ are in $S_{2}$;

(5) $A_{5}$ if and only if $A_{6}$ is in a different cabinet than $A_{7}$;

(6) $A_{6}$ if and only if $A_{4}$ is in a different cabinet than $A_{5}$;

(7) $A_{7}$ if and only if $A_{1}$ is in the same cabinet as $A_{2}$;

(8) $A_{8}$ if and only if $A_{5}$ is in the same cabinet as $A_{7}$;

Determine all the possible distributions of the eight objects into the two cabinets such that all statements (1) to (8) are true!

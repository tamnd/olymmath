In a set $X$ of 17 elements, a family of $N$ distinct non-empty subsets is selected such that each element of the set $X$ is contained in exactly two subsets from this family. What is the maximum value of $N$? Find the number of all possible different types of such families for the maximum $N$. Two families of subsets have different types if one cannot be obtained from the other by permuting the elements of $X$.

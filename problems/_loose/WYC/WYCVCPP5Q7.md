A sequence of $n (\geq 3)$ numbers is obtained by substituting the numbers $1, 2, 3, \ldots, n$ into the expression $a k^{2} + b k + c$, where $a$ is a positive number. Prove that:

$\alpha$ ) if $3a + b > 0$, then, except for $a_{1}$, every term in the sequence is greater than the one before it;

$\beta$ ) if $3a + b = 0$, then no term is less than the one before it;

$\gamma$ ) if $-(2n-1)a < b < -3a$, then there is a term such that there are larger terms both before and after it;

$\delta$ ) if $(2n-1)a + b = 0$, then no term is greater than the one before it;

$\varepsilon$ ) if $(2n-1)a + b < 0$, then every term is less than the one before it.

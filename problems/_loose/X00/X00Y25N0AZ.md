The expression $x_{1}: x_{2}: x_{3}: \ldots: x_{n}$ only has a definite meaning if we indicate, for example, by using parentheses, the order in which the divisions should be performed. Thus, the expression can be rewritten as

$$
\frac{x_{i_{1}} x_{i_{2}} \ldots x_{i_{k}}}{x_{j_{1}} x_{j_{2}} \ldots x_{j_{n-k}}}
$$

where $i_{1}, i_{2}, j_{2}, \ldots, j_{n-k}$ represent some permutation of the indices $1,2, \ldots, n$, with $i_{1}<i_{2}<\ldots<i_{k}$ and $j_{1}<j_{2}<\ldots<j_{n-k}$.

For example,

$$
\left(x_{1}:\left(x_{2}: x_{3}\right)\right): x_{4}=\frac{x_{1} x_{3}}{x_{2} x_{4}}, \left(\left(x_{1}: x_{2}\right): x_{3}\right): x_{4}=\frac{x_{1}}{x_{2} x_{3} x_{4}}
$$

How many different fractions of this form can be obtained from the above expression by placing the parentheses in different ways?

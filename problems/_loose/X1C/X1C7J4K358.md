Consider the function $f: \mathbb{C} \backslash\{1\} \rightarrow \mathbb{C}, f(z)=\frac{z^{2}-z-2}{z-1}$. Show that, if $z \neq 1$, then $f(z) \in \mathbb{R}$ if and only if $z \in \mathbb{R}$.

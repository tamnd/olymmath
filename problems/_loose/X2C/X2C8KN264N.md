10・100 Let $S$ be a non-empty set of points, all of which are integer points. In addition, a finite set of non-zero vectors with integer coordinates is given. It is known that when the starting points of all vectors in the set are placed at any point in $S$, the number of their endpoints that belong to $S$ is greater than the number of those that do not belong to $S$. Prove that $S$ must be an infinite set of points.

In a table with $m$ rows and $n$ columns, a horizontal move is defined as a permutation of the elements in the table such that each element remains in the same row it was in before the permutation; similarly, a vertical move is defined as a permutation where each element remains in the same column it was in before the permutation. Determine the smallest $k$ such that any permutation of the elements in the table can be achieved in $k$ moves (of any type), but there exists a permutation that cannot be achieved in fewer moves.

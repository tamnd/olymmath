\section*{Problem 6B - 141236B}

Let $p$ be a non-zero real number and $f$ a function defined for all real numbers $x$ with the property

$$
f(x+p)=\frac{f(x)}{3 f(x)-1}
$$

for all real $x$. (1)

a) Prove that any such function $f$ (if it exists) is periodic, i.e., there exists a non-zero real number $q$ such that $f(x+q)=f(x)$ for all real $x$. (2)

b) Provide a non-constant function $f$ for a specific value of $p$.

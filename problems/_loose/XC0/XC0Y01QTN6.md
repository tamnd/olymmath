${ }^{+}$Let $C$ be a closed curve in the plane, such that at any given point in the plane, it intersects itself at most once, and each such intersection is a proper crossing. If we can arrange these crossings so that they alternate between overcrossings and undercrossings as we travel along the curve, then we call $C$ alternating.
(i) Prove that every such curve is alternating, or provide a counterexample.
(ii) If the curve in (i) is not closed, does the conclusion change?

There can be no draws in a match. Jumbo and Dumbo must take turns pushing Pink and Bonk. Which of the following events is more likely:

$$
\begin{gathered}
A=\{\text { Jumbo wins only against Pink, and Dumbo - only against Bonk }\} \\
\text { or } \\
B=\{\text { Jumbo wins only against Bonk, and Dumbo - only against Pink }\} ?
\end{gathered}
$$

If we have $n$ ( $n \geqq 2$ ) natural numbers, we can perform the following operation: select some $z$ of them, but not all, and replace each of the $z$ selected numbers with their arithmetic mean. Determine whether it is possible to get all numbers the same after a finite number of steps for any initial n-tuple if $n$ equals
a) 2000,
b) 35,
c) 3,
d) 17.

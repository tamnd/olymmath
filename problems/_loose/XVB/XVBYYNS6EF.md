On the exam, each of the three students was given the same test consisting of 40 questions. We will call a question unmanageable if all answered it incorrectly; difficult if only one student answered correctly, easy if exactly two students answered correctly, and trivial if all three answered correctly. It is known that the number of easy questions is twice the number of unmanageable questions. What is the maximum number of unmanageable questions that the test can contain if the total number of correct answers is 64? Justify your answer.

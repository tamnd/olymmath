If $n$ is a positive integer, a Leistra sequence is a sequence $a_{1}, a_{2}, a_{3}, \ldots, a_{n-1}, a_{n}$ with $n$ terms with the following properties:

(P1) Each term $a_{1}, a_{2}, a_{3}, \ldots, a_{n-1}, a_{n}$ is an even positive integer.

(P2) Each term $a_{2}, a_{3}, \ldots, a_{n-1}, a_{n}$ is obtained by dividing the previous term in the sequence by an integer between 10 and 50, inclusive. (For a specific sequence, the divisors used do not all have to be the same.)

(P3) There is no integer $m$ between 10 and 50, inclusive, for which $\frac{a_{n}}{m}$ is an even integer.

For example,

$\left|\begin{array}{c}\text { Leistra sequences } \\ \hline 1000,50,2 \\ 1000,100,4 \\ 3000,300,30,2 \\ 106\end{array}\right|$

| Not Leistra sequences | Reason |
| :---: | :---: |
| $1000,50,1$ | (P1) fails - includes an odd integer |
| $1000,200,4$ | (P2) fails - divisor 5 falls outside range $\left(\frac{1000}{200}=5\right)$ |
| $3000,300,30$ | (P3) fails - can be extended with $\frac{30}{15}=2$ |
| 104 | (P3) fails - can be extended with $\frac{104}{13}=8$ |

(a) Determine all Leistra sequences with $a_{1}=216$.

(b) How many Leistra sequences have $a_{1}=2 \times 3^{50}$ ?

(c) How many Leistra sequences have $a_{1}=2^{2} \times 3^{50}$ ?

(d) Determine the number of Leistra sequences with $a_{1}=2^{3} \times 3^{50}$.

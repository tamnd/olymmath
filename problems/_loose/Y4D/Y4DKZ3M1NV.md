The ninety-ninth problem: Let $S$ be an infinite set of positive integers, and let $T=\{x+y \mid x, y \in S, x \neq y\}$. If $\{p \mid p$ is a prime, $p \equiv 1(\bmod 4)$, there exists $x \in T$, such that $p \mid x\}$ is a finite set, prove: The set $\{p \mid p$ is a prime, there exists $x \in S$, such that $p \mid x\}$ is an infinite set.

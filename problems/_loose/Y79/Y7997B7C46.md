$\mathrm{For}$ decorative purposes, identical cans of different types are to be arranged in several rows stacked on top of each other, such that the following conditions are met:

(1) Each row must contain exactly one more can than the row immediately above it.

(2) The top row contains exactly one can.

(3) Exactly three different types of cans are used.

(4) Exactly the same number of cans of each of the three types is used.

(5) Each row consists of cans of exactly one type.

(6) No two immediately adjacent rows contain cans of the same type.

Determine the smallest number of cans for which it is possible to simultaneously meet conditions (1) to (6)!

The Stirling number of the second kind $S_{N}^{n}$ is defined as the number of all possible partitions of a set of $N$ elements, say, $\{1,2, \ldots, N\}$, into $n$ non-empty subsets ${ }^{1}$.

Show that for $1 \leqslant n \leqslant N$ the following properties hold:

(a) $S_{N}^{1}=S_{N}^{N}=1, S_{N}^{2}=2^{N-1}-1, S_{N}^{N-1}=C_{N}^{2}$;

(b) $S_{N+1}^{n}=S_{N}^{n-1}+n S_{N}^{n}$;

(c) $S_{N+1}^{n}=\sum_{k=0}^{N} C_{N}^{k} S_{k}^{n-1} \left(S_{k}^{p}=0\right.$ when $\left.p>k\right)$;

(d) $S_{N}^{n}=\frac{1}{n!} \sum_{k=0}^{n}(-1)^{n-k} C_{n}^{k} k^{N}$;

(e) $S_{N}^{n}=\frac{1}{n!} \sum_{k=0}^{n}(-1)^{k} C_{n}^{k}(n-k)^{N}$;

(f) $S_{N}^{n} \leqslant n^{N-n} C_{N-1}^{n-1}$.

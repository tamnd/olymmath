The family of lines $\mathbf{z}$ is given by the equation $m(2 x-1)+(-x+2 y-2)=0, m \in \mathbb{R}$.

a) For $m=3$, write the equation of the line in explicit and intercept form, and draw it in the Cartesian coordinate system.

b) Write for which value of the parameter $m$ the point $A\left(-\frac{3}{2}, 4\right)$ lies on the given line.

c) Write for which value of the parameter $m$ the given line is parallel to the line $2 x+4 y-1=0$.

d) Write for which values of the parameter $m$ the given line is increasing.

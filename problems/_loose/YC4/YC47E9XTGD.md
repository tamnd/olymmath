43-1 (C54, Colombia) Let $n$ be any given positive integer, and $T$ be the set of all points $(x, y)$ in the plane satisfying $x+y<n$, where $x, y$ are non-negative integers. Each point $(x, y)$ in $T$ is colored either red or blue, such that if $(x, y)$ is red, then all points $\left(x^{\prime}, y^{\prime}\right)$ in $T$ satisfying $x^{\prime} \leqslant x, y^{\prime} \leqslant y$ are also red. If the $n$ blue points have distinct $x$-coordinates, then the set of these $n$ blue points is called an $X$-set; if the $n$ blue points have distinct $y$-coordinates, then the set of these $n$ blue points is called a $Y$-set. Prove that the number of $X$-sets is the same as the number of $Y$-sets.

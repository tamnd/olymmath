Points in the plane whose both coordinates are rational numbers are called rational points.

Prove: The set of all rational points in the plane can be divided into 3 pairwise disjoint sets, satisfying the conditions:
(1) In any circle centered at each rational point, there must be 3 points belonging to these 3 sets;
(2) On any straight line, it is impossible to have 3 points each belonging to these 3 sets.

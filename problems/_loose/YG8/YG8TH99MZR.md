(a) If $x_{1}, x_{2} \in\left(0, \frac{\pi}{2}\right)$, prove:

$$
\frac{\cos x_{1}+\cos x_{2}}{2} \leq \cos \frac{x_{1}+x_{2}}{2}
$$

(b) If $x_{1}, x_{2}, \ldots, x_{2^{k}} \in\left(0, \frac{\pi}{2}\right)$, prove:

$$
\frac{1}{2^{k}} \sum_{j=1}^{2^{k}} \cos x_{j} \leq \cos \left(\frac{1}{2^{k}} \sum_{j=1}^{2^{k}} x_{j}\right), \text { for } k \in \mathbf{N}
$$

(c) If $x_{1}, x_{2}, \ldots, x_{n} \in\left(0, \frac{\pi}{2}\right)$, prove:

$$
\frac{1}{n} \sum_{j=1}^{n} \cos x_{j} \leq \cos \left(\frac{1}{n} \sum_{j=1}^{n} x_{j}\right), \text { for } n \in \mathbf{N}
$$

Find all values of the numerical parameter $a$, for which the roots of the equation

$(a+1) x^{2}+2 c u+a+3=U$ are positive. Solution If $(a+1)=0$, then the equation will be linear, and its root at $a=-1$ is $\mathrm{X}$ $=1$. This works.

If $a \neq-1$, then the equation will be quadratic. According to Vieta's theorem, its roots are positive if and only if

$$
\left\{\begin{array} { l }
{ \frac { ( a + 1 ) } { u + 1 ) } > u . } \\
{ a } \\
{ a + 1 } \\
{ \alpha } \\
{ \cup / 4 = u ^ { 2 } - ( u + 1 ) ( a + 3 ) \geq U . }
\end{array} \Leftrightarrow \left\{\begin{array}{l}
a \in(-w,-5) \cup(-1 ;+\infty) . \\
a \in(1 ; U) . \\
a \in(-w,-3 / 4 .
\end{array} \Leftrightarrow u \in(1 ; 1 / 4]\right.\right.
$$

Taking into account the first case, we get the answer $a \in[-]:-1 / 4]$.

Consider the set $\mathrm{A}=\left\{1,2,2^{2}, 2^{3}, \ldots, 2^{99}\right\}$, the sum $\mathrm{S}=1+2+2^{2}+\ldots+2^{99}$, and the set $\mathrm{B}$ consisting of numbers that can be written as the sum of different elements from the set $\mathrm{A}$.

a) Determine the number of elements in the set A.

b) Show that $2015 \in$ B.

c) Show that $2 \mathrm{~S}=2+2^{2}+\ldots+2^{99}+2^{100}$ and calculate $S$.

d) Justify that $2^{100} \notin$ B.

A graph is a set of vertices, some of which are connected by edges (each edge connects exactly two vertices of the graph). A vertex coloring of a graph is called proper if no two vertices of the same color are connected by an edge. Suppose a certain graph is properly colored with $k$ colors, and it cannot be properly colored with fewer colors. Prove that in this graph there exists a path along which vertices of all $k$ colors appear exactly once.

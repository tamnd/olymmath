Given $n$ points, none of which are collinear. Some of the segments determined by them are colored red, and some are colored blue, such that traveling along the colored segments, one can get from any point to any other point, but in only one way. It is to be proven that the segments determined by the points, which have not yet been colored, can be colored blue or red so that among the sides of any triangle determined by the given points, there is an odd number of red ones.

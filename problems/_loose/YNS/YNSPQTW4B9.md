Prove: For a connected countable graph $G$, the following statements are equivalent:
(i) $G$ has a locally finite spanning tree.
(ii) $G$ has a locally finite normal spanning tree.
(iii) Every normal spanning tree of $G$ is locally finite.
(iv) There does not exist a finite separating set $X \subseteq V(G)$ such that $G-X$ has infinitely many components.

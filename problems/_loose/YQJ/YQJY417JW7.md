The random variable $X$ is given by the probability density function:

$$
f(x)=\left\{\begin{array}{ccc}
0 & \text { if } & x \leq \frac{\pi}{4} \\
2 \sin 2 x & \text { if } & \frac{\pi}{4} < x \leq \frac{\pi}{2} \\
0 & \text { if } & x > \frac{\pi}{2}
\end{array}\right.
$$

Find the distribution function $F(x)$.

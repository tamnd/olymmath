Let $f$ be a function of bounded variation on the interval $[a, b]$. For $x \in [a, b]$, consider the function $V(x) = \operatorname{Var}_{a}^{x}(f)$ (it is assumed that $V(a)=0$). Prove that the function $f$ is continuous at a point $x_{0} \in [a, b]$ if and only if the function $V$ is continuous at this point.

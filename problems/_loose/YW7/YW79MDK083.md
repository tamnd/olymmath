For six integers $a, b, c$ and $A, B, C$ the following correlations are true:
$$
b + c = A^2, c + a = B^2, a + b = C^2, C > B > A \geq 0.
$$
Find numbers $a, b, c$, for which the sum $A^2 + B^2 + C^2$ takes the smallest possible value.

- We call a linear order dense if there exists a third element between any two elements.
(i) Find or construct a countable dense linear order that has neither a maximum nor a minimum element.
(ii) Prove: This order is unique, i.e., any two such orders are order isomorphic. (How to define it?)
(iii) Prove: Among all countable linear orders, this order is universal. Is it homogeneous? (Provide appropriate definitions.)

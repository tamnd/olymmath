There are two non-empty stacks of $n$ and $m$ coins on a table. The following operations are allowed: $\bullet$ The same number of coins are removed from both stacks. $\bullet$ The number of coins in a stack is tripled.
For which pairs $(n, m)$ is it possible that after finitely many operations, no coins are more available?

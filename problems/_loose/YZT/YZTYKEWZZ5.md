A table is equipped with a finite number of switches and a light bulb. The bulb can light up in three colors: red, blue, and green. Each switch has three positions: red, blue, and green. If all switches are set to the same color, the bulb lights up in that color. If we change the position of all switches to another color in any switch position combination, the color of the bulb also changes. Show that there is a switch among them that alone determines the color of the bulb.

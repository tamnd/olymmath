23 Let $S$ be a finite set, and $f$ be a function defined on the power set $2^{S}$ of $S$. We say $f$ is monotonically decreasing if $X \subseteq Y \subseteq S$ implies $f(X) \geqslant f(Y)$. Prove: $f$ satisfies $f(X \cup Y)+f(X \cap Y) \leqslant f(X)+f(Y), X, Y \subseteq S$ if and only if for any $a \in S, g(X)=f(X \cup\{a\})-f(X)$ is a monotonically decreasing function on the power set $2^{S \backslash\{a\}}$ of $S \backslash\{a\}$.

Determine all natural numbers $m$ and $n$ for which it is possible to color a rectangular tile with $m$ rows and $n$ columns such that the following three conditions are satisfied:

- in each row, the number of black fields is equal to the number of white fields;
- if a column and a row intersect at a white field, then that column and row have the same number of white fields;
- if a column and a row intersect at a black field, then that column and row have the same number of black fields.

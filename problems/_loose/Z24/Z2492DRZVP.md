The number of unordered solutions $\left[n_{1}, \ldots, n_{N}\right]$ of the system $n_{1}+\ldots+n_{N}=n, n \geqslant 1, N \geqslant 1$, with non-negative integers $n_{i} \geqslant 0$, $i=1, \ldots, N$. What is the number of such solutions? What is the number of such solutions if only positive solutions $\left(n_{i}>0\right.$, $i=1, \ldots, N$ ) are allowed? What is the number of ordered solutions ( $n_{1}, \ldots, n_{N}$ ) of the same system $n_{1}+\ldots+n_{N}=n, n \geqslant 1, N \geqslant 1$, with positive $n_{i}$, $i=1, \ldots, N$ ?

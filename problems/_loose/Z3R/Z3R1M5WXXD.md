Let $\sigma(\mathrm{S})$ denote the sum of all elements in a non-empty set of integers $S$. Let $A=\left\{a_{1}, a_{2}, \cdots, a_{11}\right\}$ be a set of positive integers, and $a_{1}<a_{2}<\cdots<a_{11}$. If for each positive integer $n \leqslant 1500$, there exists a subset $S$ of $A$ such that $\sigma(S)=n$, find the minimum value of $a_{10}$ that satisfies the above requirement.

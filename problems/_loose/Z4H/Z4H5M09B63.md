Find all integers $n \geqslant 1$ for which the function:

$$
x \longmapsto x^{x}
$$

takes all possible values modulo $n$ as $x$ runs through $\llbracket 0, n-1 \rrbracket$.

We say that it is a surjection in $\mathbb{Z} / \mathrm{n} \mathbb{Z}$.

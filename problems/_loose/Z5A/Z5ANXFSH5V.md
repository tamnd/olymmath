Given the quadratic function $f(x)=x^{2}+x$, if the solution set of the inequality $f(-x)+f(x) \leqslant 2|x|$ is $C$.
(1) Find the set $C$;
(2) If the equation $f\left(a^{x}\right)-a^{x+1}=5(a>0, a \neq 1)$ has a solution in $C$, find the range of the real number $a$;
(3) Let the range of $f(x)$ on $C$ be $A$, and if $g(x)=x^{3}-3 t x+\frac{t}{2}, x \in[0,1]$ has a range $B$, and $A \subseteq B$, find the range of the real number $t$.

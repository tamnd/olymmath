The 90th question: Given a positive integer $\mathrm{n}$, create a set of cards according to the following rules: (1) Each card has a number of the form $\mathrm{m}!\left(\mathrm{m} \in \mathrm{Z}^{+}\right)$; (2) For any positive integer $\mathrm{t} \leq \mathrm{n}$!, it is possible to select some cards (possibly just one) from the set so that the sum of the numbers on the selected cards is $\mathrm{t}$. Find the minimum number of cards in this set.

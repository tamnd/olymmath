Determine the number of all positive ten-digit integers with the following properties:

- The number contains each of the digits 0, 1, 2, ..., 8, and 9 exactly once.
- Each digit, except for the 9, has a neighboring digit that is greater than it.

(Note. For example, in the number 1230, the digits 1 and 3 are the neighboring digits of 2, and 2 and 0 are the neighboring digits of 3. The digits 1 and 0 have only one neighboring digit.)

Let $a_1 \le a_2 \le ... \le a_n$ be real numbers for which $$\sum_{i=1}^{n} a_i^{2k+1} = 0$$ holds for all integers $0 \le k < n$. Show that in this case, $a_i = -a_{n+1-i}$ holds for all $1 \le i \le n$.

Find all functions $f:\mathbb{N}^{\ast}\rightarrow\mathbb{N}^{\ast}$ with
the properties:

- $ f(m+n) -1 \mid f(m)+f(n), \forall m,n\in\mathbb{N}^{\ast} $

- $ n^{2}-f(n)\text{ is a square } \;\forall n\in\mathbb{N}^{\ast} $

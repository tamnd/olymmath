In a chess tournament, each participant played two games with each other: one with white pieces, the other with black. At the end of the tournament, it turned out that everyone had scored the same number of points (1 point for a win, $-1 / 2$ point for a draw, 0 points for a loss). Prove that there will be two participants who won the same number of games with white pieces.

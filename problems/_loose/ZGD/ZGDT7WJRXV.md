Given that for any real number $x$, the function $f(x)$ is defined, and $f^{2}(x) \leqslant 2 x^{2} f\left(\frac{x}{2}\right)$, if the set $A=\left\{a \mid f(a)>a^{2}\right\}$ is not empty, try to prove that $A$ is an infinite set.

In a tug-of-war tournament, $n$ children are participating. Before the tournament begins, each child is given a number (first, second, ..., n-th competitor). The tournament will take place over two competitive days according to the following competition system:

- On the first day, the first and second competitors compete first; the winner competes with the third competitor; the winner competes with the fourth competitor; and so on...;
- On the second day, the n-th and (n-1)-th competitors compete first; the winner competes with the (n-2)-th competitor; the winner competes with the (n-3)-th competitor; and so on...;

Show that some two competitors will compete against each other on both the first and second day.

Consider the arbitrary triangle $A B C$. Let the lines $d_{1} \| A B, d_{2} \| A C, d_{3} \| B C$ and denote $d_{1} \cap (A C) = \{I\}, d_{1} \cap (B C) = \{F\}, d_{2} \cap (A B) = \{D\}, d_{2} \cap (B C) = \{G\}, d_{3} \cap (A B) = \{E\}$, $d_{3} \cap (A C) = \{H\}, d_{1} \cap d_{2} = \left\{A^{\prime}\right\}, d_{1} \cap d_{3} = \left\{B^{\prime}\right\}, d_{2} \cap d_{3} = \left\{C^{\prime}\right\}$. Assume that

$\operatorname{Area}(A E H) = \operatorname{Area}(C I F) = \operatorname{Area}(B D G) = \operatorname{Area}(A D G C) = \operatorname{Area}(B E H C) = \operatorname{Area}(A I F B)$.

$$
\text { Find } \frac{\operatorname{Area}\left(A^{\prime} B^{\prime} C^{\prime}\right)}{\operatorname{Area}(A B C)}
$$

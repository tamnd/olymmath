Prove the following two statements (a) and (b) for every acute triangle $ABC$ with a point $P$ located inside the triangle! The following notations are used:

| Angle | Size |
| :---: | :---: |
| $\angle PBA$ | $\delta$ |
| $\angle PCA$ | $\delta'$ |

| Angle | Size |
| :---: | :---: |
| $\angle PCB$ | $\epsilon$ |
| $\angle PAB$ | $\epsilon'$ |

| Angle | Size |
| :---: | :---: |
| $\angle PAC$ | $\varphi$ |
| $\angle PBC$ | $\varphi'$ |

a) If $\delta = \delta'$ and $\epsilon = \epsilon'$ and $\varphi = \varphi'$ hold, then $P$ is the orthocenter of triangle $ABC$. b) If $P$ is the orthocenter of triangle $ABC$, then the equations $\delta = \delta'$ and $\epsilon = \epsilon'$ and $\varphi = \varphi'$ hold.

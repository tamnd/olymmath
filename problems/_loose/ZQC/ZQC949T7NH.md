There are keys numbered $1,2, \cdots, 10$ and boxes numbered $1,2, \cdots, 10$. Each key can only open the box with the same number. Now all the keys are placed into these boxes, one key per box, and then locked. How many different ways are there, at least, such that at least two boxes need to be opened to open all the boxes? If exactly two boxes need to be opened to open all the boxes, how many ways are there?

The plane is referred to a Cartesian coordinate system $(0, \overrightarrow{1}, \vec{\jmath})$. Let $\mathcal{E}$ be the set of points with integer coordinates. Find all functions $f: \mathcal{E} \rightarrow \mathbb{R}$ such that $f(O)=0$ and $f(B)=$ $f(A)+f(C)$ for any rectangle $O A B C$ with $A, B, C \in \mathcal{E}$.

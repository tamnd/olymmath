For the point set $F_{n}=\left\{P_{i}\right\}_{i=1}^{n}$, connect the point pairs with distance equal to $d$ using line segments, resulting in the graph $G_{n}$. The number of edges passing through $P_{i}$ in $G_{n}$ is denoted as $d\left(P_{i}\right)$, then we have
$$
\left|m_{n}\right|=\frac{1}{2} \sum_{i=1}^{n} d\left(P_{i}\right) .
$$

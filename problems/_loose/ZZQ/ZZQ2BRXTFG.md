In $\triangle ABC$, $BC=a, CA=b, AB=c, P$ is any point on the plane. If $PA=\alpha, PB=\beta, PC=\gamma$, prove:
(1) $a \beta \gamma + b \gamma \alpha + c \alpha \beta \geqslant abc$;
(2) $\alpha bc + \beta ca + \gamma ab \geqslant \sqrt{3} abc$.

The cells of a $2 \times 2019$ table must be filled with numbers (exactly one number in each cell) according to the following rules. In the top row, there should be 2019 real numbers, none of which are equal, and in the bottom row, there should be the same 2019 numbers, but in a different order. In each of the 2019 columns, there should be two different numbers, and the sum of these two numbers should be a rational number. What is the maximum number of irrational numbers that could be in the first row of the table?

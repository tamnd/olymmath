If $P = \frac{s}{(1 + k)^n}$ then $n$ equals:
$\textbf{(A)}\ \frac{\log{\left(\frac{s}{P}\right)}}{\log{(1 + k)}} \textbf{(B)}\ \log{\left(\frac{s}{P(1 + k)}\right)} \textbf{(C)}\ \log{\left(\frac{s - P}{1 + k}\right)} \\ \textbf{(D)}\ \log{\left(\frac{s}{P}\right)} + \log{(1 + k)} \textbf{(E)}\ \frac{\log{(s)}}{\log{(P(1 + k))}}$

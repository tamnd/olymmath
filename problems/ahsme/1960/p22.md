$\textbf{(A)}\ a = 0, b \text{ } \text{has a unique non-zero value} \\ \textbf{(B)}\ a = 0, b \text{ } \text{has two non-zero values} \\ \textbf{(C)}\ b = 0, a \text{ } \text{has a unique non-zero value} \\ \textbf{(D)}\ b = 0, a \text{ } \text{has two non-zero values} \\ \textbf{(E)}\ a \text{ } \text{and} \text{ } b \text{ } \text{each have a unique non-zero value}$

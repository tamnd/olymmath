Let $S$ be the sum of the interior angles of a polygon $P$ for which each interior angle is $7\frac{1}{2}$ times the
exterior angle at the same vertex. Then
$\textbf{(A)}\ S=2660^{\circ} \text{ } \text{and} \text{ } P \text{ } \text{may be regular} \\ \textbf{(B)}\ S=2660^{\circ} \text{ } \text{and} \text{ } P \text{ } \text{is not regular} \\ \textbf{(C)}\ S=2700^{\circ} \text{ } \text{and} \text{ } P \text{ } \text{is regular} \\ \textbf{(D)}\ S=2700^{\circ} \text{ } \text{and} \text{ } P \text{ } \text{is not regular} \\ \textbf{(E)}\ S=2700^{\circ} \text{ } \text{and} \text{ } P \text{ } \text{may or may not be regular}$

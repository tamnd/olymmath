$\mathrm{(A)\ } 4x+3y=xy \mathrm{(B) \ }y=\frac{4x}{6-y} \mathrm{(C) \ } \frac{x}{2}+\frac{y}{3}=2 $
$\mathrm{(D) \ } \frac{4y}{y-6}=x \mathrm{(E) \ }\text{none of these}$

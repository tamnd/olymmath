(Assume each statement is either true or false.) Among them the number of false statements is exactly
$\textbf{(A)}\ 0 \textbf{(B)}\ 1 \textbf{(C)}\ 2 \textbf{(D)}\ 3 \textbf{(E)}\ 4$

$$\frac{DE}{DB}=\frac{m}{n},$$
where $m$ and $n$ are relatively prime positive integers, then $m+n=$
$\text{(A) } 25 \text{(B) } 128 \text{(C) } 153 \text{(D) } 243 \text{(E) } 256$

The increasing sequence of positive integers $a_1,a_2,a_3,\cdots$ has the property that
$$a_{n+2}=a_n+a_{n+1} \text{ for all } n\ge 1.$$
If $a_7=120$, then $a_8$ is
$\text{(A) } 128 \text{(B) } 168 \text{(C) } 193 \text{(D) } 194 \text{(E) } 210$

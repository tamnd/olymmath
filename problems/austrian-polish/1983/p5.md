Let $a_1 < a_2 < a_3 < a_4$ be given positive numbers. Find all real values of parameter $c$ for which the system $$ \begin{cases} x_1 + x_2 + x_3 + x_4 = 1
a_1x_1 + a_2 x_2 + a_3x_3 + a_4 x_4 = c
a_1^2x_1 + a_2^2 x_2 + a_3^2x_3 + a_4^2 x_4 = c^2\end{cases} $$ has a solution in nonnegative $(x_1,x_2,x_3,x_4)$ real numbers.

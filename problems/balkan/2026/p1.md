A set $S$ of positive real numbers is called Aristotelian if for any $x, y, z \in S$ satisfying $x < y < z$, we have
$$\frac{z - x}{y} \in S.$$
Find all integers $n \geq 4$ for which there exists an Aristotelian set with exactly $n$ elements.

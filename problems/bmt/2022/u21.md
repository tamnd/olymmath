Let $N$ be the answer to Problem 20. Define the polynomial $f(x) = x^{34} + x^{33} + x^{32} + \cdots + x + 1$. Compute the number of primes $p < N$ such that there exists an integer $k$ with $f(k)$ divisible by $p$.

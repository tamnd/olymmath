An ordered pair $(a, b)$ of real numbers is *$Z$-nice* if $x^3 + ax + b$ has $3$ distinct roots $p, q, r$ such that $|p - 2024| = |q - 2024| = |r - 2024| = Z$. Find the greatest possible real value of $Z$ such that there is exactly one $Z$-nice ordered pair.

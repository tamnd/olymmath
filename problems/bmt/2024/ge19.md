Consider an $n$-digit number $\underline{d_1}\,\underline{d_2}\,\underline{d_3}\ldots\underline{d_n}$ such that:

- there are no leading zeroes,
- the number formed from the first $k$ digits $\underline{d_1}\ldots\underline{d_k}$ is divisible by $k$ (for all $1 \le k \le n$), and
- all of the digits are either $0$, $2$, or $4$.

If the number ends in the digits $\underline{2}\,\underline{0}\,\underline{2}\,\underline{4}$, what's the minimum value the number can be?

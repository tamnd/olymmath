Let $X$ denote the set $\{-1, 0, 1, 2, 3, 4\}$, and let $\mathcal{P}(X)$ denote the set of all subsets of $X$. Compute the number of functions $f\colon \mathcal{P}(X) \to X$ such that $f(\varnothing) = 0$ and $f(A \cap B) + f(A \cup B) = f(A) + f(B)$ for any subsets $A$ and $B$ of $X$.

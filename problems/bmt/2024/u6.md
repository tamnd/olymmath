Compute $(x + y)^{100}$ given
$$\left(\frac{x^2 + 2xy + y^2}{y + z}\right)^{100} = 1, \quad \left(\frac{y^2 + 2yz + z^2}{x + z}\right)^{50} = 8, \quad \left(\frac{x^2 + 2xz + z^2}{x + y}\right)^{25} = 16.$$

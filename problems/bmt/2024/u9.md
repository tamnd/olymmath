Let $\log_2^*(n)$ be the number of times we need to apply $\log_2$ to $n$ to get a number less than $1$. This function grows very slowly, but a useful application is to extended exponentiation:

Let $a \uparrow^1 b = a^b$, and $a \uparrow^{n+1} b = \underbrace{a \uparrow^n (a \uparrow^n (\cdots (a \uparrow^n a)))}_{b-1\ \uparrow^n\text{'s}}$. For instance, $4 \uparrow^2 3 = 4 \uparrow^1 (4 \uparrow^1 4)$.

Compute $\log_2^*(2 \uparrow^3 4)$.

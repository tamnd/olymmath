The Lunarians (moon people) define the *lunatic* operation, $\circledast$, on positive integers with the same number of digits. For any two positive integers $\underline{a_1}\ldots\underline{a_n}$ and $\underline{b_1}\ldots\underline{b_n}$, each with $n$ digits,
$$\underline{a_1}\ldots\underline{a_n} \circledast \underline{b_1}\ldots\underline{b_n} = \underline{c_1}\ldots\underline{c_n},$$
where for each $1 \le i \le n$, $c_i$ is the units digit of the product $a_i b_i$. For example, $36 \circledast 82 = 42$, and $36 \circledast 820$ is not defined because $36$ and $820$ have different numbers of digits. For how many positive integers $a \le 2025$ does there exist a positive integer $b \le 2025$ for which $a \circledast b = 2025$?

Para cada permutação $a = (a_1, a_2, a_3, \dots, a_{2026})$ de $(1, 2, 3, \dots, 2026)$, considere os números a seguir:

$$\begin{aligned} &a_1 + 2a_2 + 3a_3 + \cdots + 2025a_{2025} + 2026a_{2026}, \\ &a_2 + 2a_3 + 3a_4 + \cdots + 2025a_{2026} + 2026a_1, \\ &\qquad\vdots \\ &a_{2026} + 2a_1 + 3a_2 + \cdots + 2025a_{2024} + 2026a_{2025}. \end{aligned}$$

Defina $f(a)$ como a quantidade de números distintos entre as 2026 somas acima. Qual o menor valor possível para $f(a)$ quando $a$ varia sobre todas as permutações de $(1, 2, 3, \dots, 2026)$?

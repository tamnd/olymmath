Dado un entero positivo $n$, determinar cuántas permutaciones $\sigma$ del conjunto $\{1, 2, \ldots, 2022n\}$ tienen la siguiente propiedad: para cada $i \in \{1, 2, \ldots, 2021n + 1\}$, el número

$$\sigma(i) + \sigma(i + 1) + \cdots + \sigma(i + n - 1)$$

es múltiplo de $n$.

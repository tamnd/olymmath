Uma lista de $n$ números inteiros positivos $a_1, a_2, a_3, \ldots, a_n$ é dita buena caso se verifique simultaneamente:

- $a_1 < a_2 < a_3 < \ldots < a_n$,
- $a_1 + a_2^2 + a_3^3 + \ldots + a_n^n \leq 2023$.

Para cada $n \geq 1$, determine quantas listas buenas de $n$ números existem.

Observação: $a_k^k = \underbrace{a_k \cdot a_k \cdot \ldots \cdot a_k}_{k \text{ vezes}}$.

Ak je $S$ obsah trojuholníka so stranami $a, b, c$ a $T$ je obsah trojuholníka so stranami $a + b, b + c, c + a$, potom platí $T \geqq 4S$. Dokážte a zistite, kedy nastane rovnosť.

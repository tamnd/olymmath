Nájdite všetky také trojice reálnych čísel $a, b, c$, že každá z rovníc

$$x_3^3 + (a + 1)x_2^2 + (b + 3)x + (c + 2) = 0,$$

$$x_3 + (a + 2)x_2 + (b + 1)x + (c + 3) = 0,$$

$$x + (a + 3)x + (b + 2)x + (c + 1) = 0$$

má v obore reálnych čísel tri rôzne korene, spolu je to však iba päť rôznych čísel.

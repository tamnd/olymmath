Určte, akú najmenšiu hodnotu môže nadobúdať výraz $V = (a - b)^2 + (b - c)^2 + (c - a)^2$, ak reálne čísla $a, b, c$ spĺňajú dvojicu podmienok

$$a + 3b + c = 6,$$

$$-a + b - c = 2.$$

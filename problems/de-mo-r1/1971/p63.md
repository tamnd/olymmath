Es seien $a, b, c, d, e, f, g, h$ sämtlich paarweise untereinander verschiedene einstellige natürliche Zahlen ungleich Null, und es gelte:

$$a + b = 10, c + d + e = 16, f + g + h = 14.$$

Welche einstellige natürliche Zahl (ungleich Null) wurde in diesen drei Aufgaben nicht verwendet? Gib für $a, b, c, d, e, f, g, h$ eine mögliche Lösung an!

Für die Buchstaben $a, b, c, d, e, f$ sind in den nachstehenden Aufgaben (1) bis (6) natürliche Zahlen so einzusetzen, daß richtig gerechnete Aufgaben entstehen. Dabei sollen gleiche Buchstaben gleiche Zahlen und verschiedene Buchstaben verschiedene Zahlen bedeuten. (1) $a + b + c = 21$, (2) $b \cdot c = 42$, (3) $c + d = 70 : b$, (4) $e : a = d$, (5) $c = 54 : 9$, (6) $a + b + c + d + e + f = 60$ Finde eine solche Eintragung und überprüfe, ob sie alle Forderungen erfüllt!

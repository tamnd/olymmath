Man gebe zwölf reelle Zahlen $a_1, ..., a_6, b_1, ..., b_6$ so an, daß für jede reelle Zahl $x$ die Gleichung

$$x^{12} + 1 = (x^2 + a_1x + b_1)(x^2 + a_2x + b_2)(x^2 + a_3x + b_3)$$

$$\cdot (x^2 + a_4x + b_4)(x^2 + a_5x + b_5)(x^2 + a_6x + b_6)$$

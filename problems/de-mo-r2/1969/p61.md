In einer 6. Klasse erhielt als Jahresendzensur im Fach Mathematik kein Schüler die Note 5, jeder neunte die Note 1, jeder dritte die Note 2 und jeder sechste die Note 4. Über die Schülerzahl $n$ dieser Klasse ist folgendes bekannt: 20 < n < 40.

Berechne die Anzahl der Schüler, die als Jahresendzensur die Note 3 erhielten!

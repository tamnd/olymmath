Gesucht sind vier natürliche Zahlen $a_1 < a_2 < a_3 < a_4$ so, daß jede der Zahlen

$$d_1 = a_4 - a_3; d_2 = a_3 - a_2; d_3 = a_2 - a_1; d_4 = a_4 - a_2; d_5 = a_3 - a_1; d_6 = a_4 - a_1$$

eine Primzahl ist, wobei auch gleiche Primzahlen auftreten dürfen.

Drei vorgegebene Strecken $AB, CD, EF$ und drei Strecken gesuchter Längen $a, b, c$ sollen die folgenden Eigenschaften haben: $AB = a + b = 5,6$ cm; $CD = a - b = 1,8$ cm; $EF = b + c = 6,2$ cm.

Zeichne drei derartige Strecken $AB, CD, EF$, und ermittle aus ihnen durch eine Konstruktion (nur mit Zirkel und Lineal) die gesuchten Längen $a, b$ und $c$!

Begründe, warum deine Konstruktion die gesuchten Längen $a, b, c$ ergibt, wenn sie die geforderten Eigenschaften haben!

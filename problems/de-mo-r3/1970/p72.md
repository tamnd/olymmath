Die Maßzahlen $a, b, c$ der Seitenlängen eines Dreiecks sollen die Bedingungen (I) $a + b = 38$, (II) $b + c = 46$, (III) $a + c = 42$ erfüllen.

Ermittle unter Berücksichtigung dieser Bedingungen

a) die Maßzahl jeder Seitenlänge!

b) Weise nach, daß ein Dreieck existiert, das den Bedingungen (I), (II), (III) genügt! (Gleiche Maßeinheiten seien wie üblich vorausgesetzt.)

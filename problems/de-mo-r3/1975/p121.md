In die 64 Felder eines Schachbretts sind die Zahlen 1, 2, ..., 64 so eingetragen, daß in der ersten waagerechten Reihe von links nach rechts die Zahlen 1, 2, ..., 8, in der zweiten waagerechten Reihe von links nach rechts die Zahlen 9, 10, ..., 16 u.s.w. in dieser Reihenfolge stehen.

Jemand soll nun acht Türme so auf Felder des Schachbretts stellen, daß keine zwei von ihnen einander schlagen können. Danach soll er die Summe $S$ der Zahlen bilden, die auf den von den Türmen besetzten Feldern stehen. Es sind alle dabei möglichen Werte von $S$ anzugeben.

Anmerkung: Zwei Türme können einander genau dann schlagen, wenn sie auf einer gemeinsamen waagerechten oder senkrechten Felderreihe stehen.

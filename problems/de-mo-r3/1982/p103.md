Ermitteln Sie alle diejenigen geordneten Paare $(a;b)$ reeller Zahlen, die das folgende Gleichungssystem erfüllen!

$$[a] + 2b = 6,6$$

$$[2a] + 3b = 11,9.$$

Hinweis: Ist $r$ eine reelle Zahl, so wird mit $[r]$ diejenige ganze Zahl $g$ bezeichnet, für die $g \le r < g + 1$ gilt. So ist z.B. $[4,01] = 4$, da $4 \le 4,01 < 5$ gilt; [7] = 7, da $7 \le 7 < 8$ gilt; $[-\pi]=-4$, da $-4 \le - \pi<-3$ gilt.

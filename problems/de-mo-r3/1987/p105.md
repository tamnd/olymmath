Beweisen Sie folgende Aussage:

Wenn $n$ eine natürliche Zahl mit $1 \le n \le 5$ ist, so gilt: Wird eine Kugel von $n$ Ebenen geschnitten, so entstehen auf der Kugeloberfläche höchstens 22 Teilflächen.

Untersuchen Sie, ob es zu jeder geraden Pyramide $P = ABCDS$ mit quadratischer Grundfläche $ABCD$ eine Ebene $e$ so gibt, daß die Schnittfigur von $P$ mit $e$ ein gleichseitiges Dreieck ist!

Hinweis: Gibt es nicht zu jeder Pyramide $P$ eine solche Ebene $e$, so ist für eine Pyramide $P$ diese Unmöglichkeit zu beweisen; gibt es aber zu jeder Pyramide eine solche Ebene $e$, so ist anzugeben, wie eine Ebene $e$ gefunden werden kann und daß jede so gefundene Ebene $e$ die geforderte Bedingung erfüllt.

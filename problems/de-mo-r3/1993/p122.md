Man beweise: Zu jeder Primzahl $p$ gibt es eine reelle Zahl $c$, mit der Zahlenfolge $(a_k)_{k = 1,2,3,\ldots}$, die durch

$$a_1 = c, a_{k + 1} = a_k^2 + c (k = 1,2,3,\ldots)$$

definiert wird, periodisch ist und die Zahl $p$ als kleinste Periodenlänge hat.

Hinweis: Eine Zahlenfolge $(a_k)_{k = 1,2,3,\ldots}$ heißt genau dann *periodisch*, wenn es eine positive ganze Zahl $n$ gibt, mit der für alle $k = 1,2,3,\ldots$ die Gleichung $a_k = a_{k + n}$ gilt. Ist das der Fall, so heißt jede positive ganze Zahl $n$, mit der das zutrifft, eine Periodenlänge der Zahlenfolge $(a_k)_{k = 1,2,3,\ldots}$

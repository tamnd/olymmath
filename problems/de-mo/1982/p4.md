Es sei $f(x) = a_0 + a_1x + a_2x^2 + ... + a_nx^n$ ein Polynom mit reellen Koeffizienten $a_0$, $a_1$, ..., $a_n$, wobei $n \geq 1$ und $a_n \neq 0$ gelte. Man setze

$$r = \frac{|a_0| + |a_0| + ... + |a_{n-1}|}{|a_n|}$$

und beweise:

a) Ist $r \geq 1$, so liegt jede reelle Nullstelle von $f(x)$ (falls eine solche existiert) im Intervall $-r \leq x \leq r$.

b) Ist $r \leq 1$, so liegt jede reelle Nullstelle von $f(x)$ (falls eine solche existiert) im Intervall $-1 \leq x \leq 1$.

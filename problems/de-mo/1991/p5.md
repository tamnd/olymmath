Man ermittle ein Polynom

$$f(x) = a_0 + a_1 x + a_2 x^2 + ... + a_n x^n \quad (a_0, a_1, ..., a_n \text{ reell; } a_n \neq 0), \tag{1}$$

das die Bedingungen

$$\begin{gathered} f(-4) = 0, \quad f(-3) = 1, \quad f(-2) = 0, \quad f(-1) = -1, \quad f(0) = 0, \\ f(1) = 1, \quad f(2) = 0, \quad f(3) = -1, \quad f(4) = 0 \end{gathered} \tag{2}$$

erfüllt und dabei möglichst niedrigen Grad $n$ hat.

Man beweise: Wenn reelle Zahlen $a$, $b$, $c$ das Gleichungssystem

$$\begin{aligned} a+b+c&=2, \\ ab+ac+bc&=1 \end{aligned}$$

erfüllen, so gilt

$$0 \leq a \leq \frac{4}{3}, \qquad 0 \leq b \leq \frac{4}{3}, \qquad 0 \leq c \leq \frac{4}{3}.$$

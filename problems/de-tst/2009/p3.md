Auf einer Tafel stehe am Anfang eine positive ganze Zahl. Wenn eine Zahl $x$ auf der Tafel steht, darf man die Zahlen $2x + 1$ und $\frac{x}{x+2}$ dazuschreiben. Irgendwann stehe auch die Zahl 2008 auf der Tafel.

Man beweise, dass sie von Anfang an dastand.

<!-- S1 -->
Initially, on a board there a positive integer. If board contains the number $x,$ then we may additionally write the numbers $2x+1$ and $\frac{x}{x+2}.$ At some point 2008 is written on the board. Prove, that this number was there from the beginning.

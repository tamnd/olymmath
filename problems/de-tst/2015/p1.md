Man bestimme die kleinste positive ganze Zahl $n$, für die es ein Polynom

$$P(X) = a_{2n} X^{2n} + a_{2n-1} X^{2n-1} + \ldots + a_1 X + a_0$$

mit reellen Koeffizienten gibt, das die beiden folgenden Eigenschaften aufweist:

- Für $i = 0, 1, \ldots, 2n$ gilt $2014 \le a_i \le 2015$.

- Es gibt eine reelle Zahl $\xi$ mit $P(\xi) = 0$.

<!-- S1 -->
Find the least positive integer $n$ , such that there is a polynomial $$ P(x) = a_{2n}x^{2n}+a_{2n-1}x^{2n-1}+\dots+a_1x+a_0 $$ with real coefficients that satisfies both of the following properties:
- For $i=0,1,\dots,2n$ it is $2014 \leq a_i \leq 2015$ .
- There is a real number $\xi$ with $P(\xi)=0$ .

For an integer $n$, let $\tau(n)$ denote the number of positive integer divisors of $n$. For each positive integer $k$, let $S_k = \{\tau(k), \tau(2k), \tau(3k), \cdots\}$. If $S_a = S_b$ for two positive integers $a$ and $b$, prove that $\tau(a^n) = \tau(b^n)$ for all positive integers $n \ge 1$.

*Two sets are equal if and only if every number which appears in one set also appears in the other set.*

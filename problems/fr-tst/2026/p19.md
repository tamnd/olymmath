Dans chaque case d’un tableau $10\times 10$, on inscrit un nombre réel. On suppose que pour chaque rectangle horizontal $1\times 3$, la somme des réels inscrits dans les cases du rectangle est négative ou nulle. On suppose également que pour chaque rectangle vertical $3\times 1$, la somme des réels inscrits dans les cases du rectangle est positive ou nulle.

Déterminer le nombre maximal de nombres réels strictement positifs parmi les $100$ réels inscrits dans le tableau.

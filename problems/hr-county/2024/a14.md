Ako za realne brojeve $a,b,c$ vrijedi $(a + b + c)^3 = a^3 + b^3 + c^3$, dokaži da je

$$(a + b)^2ab + (b + c)^2bc + (c + a)^2ca + 4abc(a + b + c) = 0.$$

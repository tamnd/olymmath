Odredi sve četvorke realnih brojeva $(a,b,c,d)$ koje zadovoljavaju sustav jednadžba:

$$a + b + c = d^2$$

$$b + c + d = a^2$$

$$c + d + a = b^2$$

$$d + a + b = c^2.$$

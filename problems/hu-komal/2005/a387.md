We have $n$ marbles that look all alike, but we know that one of them is radioactive. We want to find that marble. We also have a detector that can determine whether any chosen subset of the marbles contains the radioactive marble or not. We want to choose a measurement strategy for which the expected number of measurements is a minimum. Find that smallest expected value possible.

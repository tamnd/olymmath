A teacher instructed the students to count from 1 to 1000 while keeping the following rules. In each calculation step, one can choose to either multiply the previous result by a fixed one digit number $a$ selected in advance, or just add 1 to it. Which number should be chosen to be $a$ in order to be able to reach 1000 in the least number of steps?

In how many different ways is it possible to write the numbers 1, 2, 3, 4, 5, 6, 7 and 8 on the vertices of a cube, so that the sum of the four numbers is the same around each face of the cube? (Two solutions are considered the same if each number has the same neighbours adjacent to it.)

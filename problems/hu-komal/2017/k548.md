We have four boxes numbered 1 to 4, and four cards with the numbers 1, 2, 3, 4 on them. We place one card in each box, according to the following rule: every card shows the number of the box that contains the card corresponding to the number of the box containing it. In how many different ways is it possible to place the cards in the boxes?

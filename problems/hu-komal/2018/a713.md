We say that a sequence $a_1,a_2,\dots$ is expansive if for all positive integers $j$, $i<j$ implies $|a_i-a_j|\ge \frac1{j}$. Find all positive real numbers $C$ for which one can find an expansive sequence in the interval $[0,C]$.

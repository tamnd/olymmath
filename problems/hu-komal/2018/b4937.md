In the plane, a set of lattice quadrilaterals with the following property is selected: however the lattice points are coloured with a finite number of colours, there will always be a selected quadrilateral whose vertices all have the same colour. Prove that there are infinitely many selected lattice quadrilaterals, no two of which have a vertex in common.

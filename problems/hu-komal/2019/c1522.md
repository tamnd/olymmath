The positive integers are arranged in three rows as follows: $$\begin{align*} &1 \ \ 4 \ \ 7 \ \ 10 \ \ 13 \ \ 16\ldots\\ &2 \ \ 5 \ \ 8 \ \ 11 \ \ 14 \ \ 17\ldots\\ &3 \ \ 6 \ \ 9 \ \ 12 \ \ 15 \ \ 18\ldots \end{align*}$$ Prove that it is possible to select an infinite geometric sequence out of each row.

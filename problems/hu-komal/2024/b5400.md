In a $3\times 3$ magic square we increased one of the nine entries by 1. Find the least number of additional entries that has to be changed to obtain a magic square again. (The $3\times 3$ magic square is a number grid in which all three numbers in each of the rows, columns, and diagonals add up to the same number.)

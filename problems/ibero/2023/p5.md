Uma sequência $P_1, \ldots, P_n$ de pontos no plano (não necessariamente distintos) é carioca se existe uma permutação $a_1, \ldots, a_n$ dos números $1, \ldots, n$ para a qual os segmentos

$$P_{a_1}P_{a_2}, P_{a_2}P_{a_3}, \ldots, P_{a_n}P_{a_1}$$

têm todos o mesmo comprimento.

Determine o maior número $k$ tal que para qualquer sequência de $k$ pontos no plano é possível adicionar $2023 - k$ pontos de modo que a sequência de 2023 pontos seja carioca.

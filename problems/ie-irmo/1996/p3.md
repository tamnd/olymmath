Let $K$ be the set of all real numbers $x$ such that $0\leq x\leq 1$. Let $f$ be a function from $K$ to the set of all real numbers $\mathbb{R}$ with the following properties

(a) $f(1)=1$;

(b) $f(x)\geq 0$ for all $x\in K$;

(c) if $x,y$ and $x+y$ are all in $K$, then

$$f(x+y)\geq f(x)+f(y).$$

Prove that $f(x)\leq 2x$, for all $x\in K$.

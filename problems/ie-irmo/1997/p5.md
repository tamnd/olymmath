Let $S$ be the set of all odd integers greater than one. For each $x\in S$, denote by $\delta(x)$ the unique integer satisfying the inequality

$$2^{\delta(x)}<x<2^{\delta(x)+1}.$$

For $a,b\in S$, define

$$a\ast b=2^{\delta(a)-1}(b-3)+a.$$

[For example, to calculate $5\ast 7$, note that $2^2<5<2^3$, so $\delta(5)=2$, and hence $5\ast 7=2^{2-1}(7-3)+5=13$. Also $2^2<7<2^3$, so $\delta(7)=2$ and $7\ast 5=2^{2-1}(5-3)+7=11$].

Prove that if $a,b,c\in S$, then

(a) $a\ast b\in S$ and

(b) $(a\ast b)\ast c=a\ast(b\ast c)$.

(a) In how many ways can $1003$ distinct integers be chosen from the set $\{1,2,\ldots,2003\}$ so that no two of the chosen integers differ by $10$?

(b) Show that there are $(3(5151)+7(1700))101^7$ ways to choose $1002$ distinct integers from the set $\{1,2,\ldots,2003\}$ so that no two of the chosen integers differ by $10$.

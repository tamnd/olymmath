Starting from a positive integer $n$, we perform any sequence of operations from the following list:

$A$: If the number is even, we can divide it by $2$.

$B$: We can place the digit $0$ at the end of the number.

$C$: We can place the digit $8$ at the end of the number.

For example, starting with $n=8$, we can obtain the number $90$ by performing the sequence of operations $AAACAB$, as follows: $8\xrightarrow{A}4\xrightarrow{A}2\xrightarrow{A}1\xrightarrow{C}18\xrightarrow{A}9\xrightarrow{B}90$.

(a) Prove that the number $2026$ can be obtained starting from $8$.

(b) Can any positive integer $n$ be obtained starting from $8$?

(BUL 7) ${ }^{\mathrm{IMO} 5}$ Let $f$ and $\varphi$ be real functions defined on the set $\mathbb{R}$ satisfying the functional equation $$ f(x+y)+f(x-y)=2 \varphi(y) f(x) $$ for arbitrary real $x, y$ (give examples of such functions). Prove that if $f(x)$ is not identically 0 and $|f(x)| \leq 1$ for all $x$, then $|\varphi(x)| \leq 1$ for all $x$.

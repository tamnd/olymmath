Given any real number a > 1 construct a bounded infinite sequence $x_0$, $x_1$, $x_2$, ... such that $|x_i$ - $x_j$| |i - $j|^a$ ≥ 1 for every pair of distinct i, j. [An infinite sequence $x_0$, $x_1$, $x_2$, ... of real numbers is bounded if there is a constant C such that $|x_i$| < C for all i.]

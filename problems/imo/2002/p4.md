The positive divisors of the integer n > 1 are $d_1$ < $d_2$ < ... < $d_k$, so that $d_1$ = 1, $d_k$ = n. Let d = $d_1d_2$ + $d_2d_3$ + ... + $d_{k-1}d_k$. Show that d < $n^2$ and find all n for which d divides $n^2$.

A5 (KOR) Let $\mathbb{R}^{+}$be the set of all positive real numbers. Find all functions $f: \mathbb{R}^{+} \rightarrow \mathbb{R}^{+}$that satisfy the following conditions: (i) $f(x y z)+f(x)+f(y)+f(z)=f(\sqrt{x y}) f(\sqrt{y z}) f(\sqrt{z x})$ for all $x, y, z \in$ $\mathbb{R}^{+}$. (ii) $f(x)<f(y)$ for all $1 \leq x<y$.

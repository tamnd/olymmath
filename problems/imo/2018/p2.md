Find all integers $n\geq 3$ for which there exist real numbers $a_{1},a_{2},\ldots ,a_{n}$ satisfying

$$a_{i}a_{i + 1} + 1 = a_{i + 2}$$

for $i = 1,2,\ldots ,n$ , where indices are taken modulo $n$

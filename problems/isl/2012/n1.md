Call admissible a set $A$ of integers that has the following property: $$ \text { If } x, y \in A \text { (possibly } x=y \text { ) then } x^{2}+k x y+y^{2} \in A \text { for every integer } k \text {. } $$ Determine all pairs $m, n$ of nonzero integers such that the only admissible set containing both $m$ and $n$ is the set of all integers.

<!-- S5 -->
Eine Menge $A$ von ganzen Zahlen heißt zulässig, wenn sie folgende Eigenschaft hat:

Für $x, y \in A$ ($x = y$ ist erlaubt) gilt $x^2 + kxy + y^2 \in A$ für jede ganze Zahl $k$.

Man bestimme alle Paare $m, n$ von Null verschiedener ganzer Zahlen, für welche die einzige zulässige Menge, die sowohl $m$ als auch $n$ enthält, die Menge $\mathbb{Z}$ aller ganzer Zahlen ist.

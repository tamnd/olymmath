Sia $x$ un numero reale maggiore di 1 tale che $(x - 1)(x + 1)^{2012}_{2012} = 1$. Allora:

(A) $1 < x < 1 + 1/3^{2012}$ (B) $1 + 1/3^{2012} < x < 1 + 1/2$

(C) $1 + 1/2^{2012} < x < 1 + 1/3$ (D) $1 + 1/3 < x < 1 + 1/2$ (E) $x > 2$

Siano $x, y$ numeri reali positivi. Quale delle seguenti condizioni è sufficiente per garantire che $x^y > y^x$?

(A) $1 < x < y$ (B) $1 < y < x$ (C) $x < 1 < y$ (D) $x < y < 1$ (E) $y < x < 1$.

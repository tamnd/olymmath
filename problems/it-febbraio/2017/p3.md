Siano $a < b < c < d < e$ cinque numeri primi in progressione aritmetica di ragione 6 (ovvero $b = a + 6, c = b + 6, d = c + 6$ e $e = d + 6$). Quali delle seguenti affermazioni è falsa?

(A) $a + b + c + d + e$ è multiplo di 5. (B) $abcde > 10^4$. (C) $a + b + c + d + e$ è multiplo di 29. (D) $abcde$ è multiplo di 29. (E) L’unico quadrato perfetto che divide $abcde$ è 1. Nota. Si ricorda che un intero $n$ è detto quadrato perfetto se esiste un intero $a$ tale che $n = a^2$.

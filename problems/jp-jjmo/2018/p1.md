Let $k\geq 3$ be an integer. Using a regular $k$ - gon, A and B play the following game. They repeat the following operation $k$ times : A chooses one integer between 1 and 100, and B writes that integer to a vertex with no integers.
If there are three vertices with the same number of entries that form an isosceles triangle, B wins; otherwise, A wins. Find all the values of $k$ that B can always win regardless of A's actions.

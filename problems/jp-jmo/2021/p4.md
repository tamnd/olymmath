Let $a_1,a_2,\dots,a_{2021}$ be $2021$ integers which satisfy
$$ a_{n+5}+a_n>a_{n+2}+a_{n+3}$$
for all integers $n=1,2,\dots,2016$. Find the minimum possible value of the difference between the maximum value and the minimum value among $a_1,a_2,\dots,a_{2021}$.

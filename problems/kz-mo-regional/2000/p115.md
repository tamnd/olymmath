Найдите все пары $(a, b)$ действительных чисел, удовлетворяющих следующей системе уравнений:
$$
\left\{
\begin{array}{rcl}
2^{a^4 + b^2 } + 2^{a^2 + b^4 } = 8, \cr
a + b = 2. \cr
\end{array}
\right.
$$

Для произвольных положительных действительных чисел $a$, $b$, $c$, удовлетворяющих равенству $a+b+c=1$, докажите следующее неравенство:
$$\frac{{a^3 }}
{{a^2 + b^2 }} + \frac{{b^3 }}
{{b^2 + c^2 }} + \frac{{c^3 }}
{{c^2 + a^2 }} \geq \frac{1}
{2}.$$

Пусть $a, b, c$ - неотрицательные действительные числа, для которых $$\frac{1}{{a^2 + 1}} + \frac{1}{{b^2 + 1}} + \frac{1}{{c^2 + 1}} = 2.$$ Докажите неравенство $ab + bc + ca \leq \frac{3}{2}$.

Докажите, что для любых неотрицательных действительных чисел $x$, $y$ и $z$ справедливо неравенство
$\sqrt {2{x^2} + 3{y^2} + 4{z^2}} + \sqrt {3{x^2} + 4{y^2} + 2{z^2}} + \sqrt {4{x^2} + 2{y^2} + 3{z^2}} \ge $ ${\left( {\sqrt x + \sqrt y + \sqrt z } \right)^2}$

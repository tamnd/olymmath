Пусть $a,$ $b,$ $c$ - положительные целые числа такие, что $24a^2 + 2b^2 + 21c^2 = 24a + 2b + 21c.$ Найдите наименьшее значение выражения $$A = \sqrt {\frac{a}{{b(24 + 2b + 21c)}}} + \sqrt {\frac{b}{{c(24a + 2 + 21c)}}} + \sqrt {\frac{c}{{a(24 + 2b + 21)}}} .$$

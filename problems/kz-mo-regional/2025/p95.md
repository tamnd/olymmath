В файл $B$ записаны все произведения $ab$, где $a$ и $b$ - два различных числа из файла $A$ (если для нескольких пар результат совпадает, то он записывается в файл $B$ ровно один раз; таким образом, все числа в файле $B$ попарно различны). Какое наименьшее количество чисел может содержать файл $B$?

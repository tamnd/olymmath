Дано натуральное число $n\geq 2$. Найдите все действительные решения $\left( {x_1 ,x_2 ,x_3 , \ldots,x_n } \right)$ уравнения
$$
\left( {1 - x_1 } \right)^2 + \left( {x_1 - x_2 } \right)^2 + \ldots + \left( {x_{n - 1} - x_n } \right)^2 + x_n ^2 = \frac{1}
{{n + 1}}.
$$

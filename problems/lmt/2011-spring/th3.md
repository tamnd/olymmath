Zaroug is taking a test and must select the four noble gases from the set { Helium, Argon,
Boricon, Neon, Radium, Xenon } and then arrange them in order of increasing mass. However,
he only knows that there are exactly four noble gases in the set and that all six elements have
different masses. Thus, he picks four elements from the set at random and then arranges them
randomly. What is the probability he picks the four noble gases and orders them correctly?

Denote by $\sqrt{\mathbb{N}}$ the set $\{\sqrt{1} ,\sqrt{2} ,\sqrt{3} ,\sqrt{4} ,\ldots \, \}$, i.e. the set of all square roots of positive integers. Let $S$ be the set of real numbers $a$ for which both $a\in \sqrt{\mathbb{N}}$ and $36/a\in \sqrt{\mathbb{N}}$ hold. What is the product of the elements of the set $S$?

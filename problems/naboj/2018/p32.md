When cleaning the attic, Ben found an old calculator, which showed only the first two digits after the decimal point for each result, but was able to compute square roots. So for example, for $\sqrt{4}$ the machine displayed $2.00$ and for $\sqrt{6} =2.44949\ldots \,$ it showed $2.44$. What is the smallest positive integer, which is not a square of an integer, but for whose square root would Ben’s calculator show two zeros after the decimal point?

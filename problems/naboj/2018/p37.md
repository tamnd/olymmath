When dividing the polynomial $x^3 +x^5 +x^7 +x^9 +x^{11} +x^{2017} +x^{2018}$ by the polynomial $x^2 -1$ there is a remainder. Find the value of the variable $x$ for which the numerical value of that remainder is $1111$.

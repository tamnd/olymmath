In the cryptarithm $\mathrm{FOUR} +\mathrm{FIV} E=\mathrm{NINE}$ each letter represents only one digit throughout the problem and different letters represent different digits. Furthermore, it is known that

- $\mathrm{FOUR}$ is divisible by four,

- $\mathrm{FIV} E$ is divisible by five,

- $\mathrm{NINE}$ is divisible by three.

Find all possible values of $\mathrm{NINE}$.

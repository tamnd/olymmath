We have two boxes: the first one contains five perfect light bulbs and nine faulty ones, whereas the second one contains nine perfect and five faulty bulbs. The perfect bulbs work always, whereas the faulty ones only with a probability $p$ (where $0<p<1$), which is the same for all of them. Find the value of $p$, for which the following events have the same probability:1.A randomly chosen bulb from the first box works.2.Two randomly chosen bulbs from the second box both work.

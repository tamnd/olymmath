a) La $x$, $y$ og $z$ være reelle tall slik at $x + y + z = 0$. Vis at $x^3 + y^3 + z^3 = 3xyz$.

b) La $a$, $b$, $c$ og $d$ være ikkenegative reelle tall slik at $a + b + c + d = 4$. Vis at
$$\sqrt{a + b + c} + \sqrt{b + c + d} + \sqrt{c + d + a} + \sqrt{d + a + b} \ge 6.$$

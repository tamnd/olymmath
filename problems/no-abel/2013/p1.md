(a) Find all real numbers $a$ such that the inequality
$$3x^2 + y^2 \ge -ax(x + y)$$
holds for all real numbers $x$ and $y$.

(b) The sequence $a_1, a_2, a_3, \ldots$ is defined so that $a_1 = 1$ and
$$a_{n+1} = \frac{a_1 + a_2 + \cdots + a_n}{n} + 1 \qquad \text{for } n \ge 1.$$
Show that for every positive real number $\beta$ we can find a $k$ so that $a_k < \beta k$.

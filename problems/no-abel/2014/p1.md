(a) Assume that $x, y \ge 0$. Show that
$$x^2 + y^2 + 1 \le \sqrt{(x^3 + y + 1)(y^3 + x + 1)}.$$

(b) Find all functions $f\colon \mathbb{R} \setminus \{0\} \to \mathbb{R}$ which satisfy
$$(1 + y)f(x) - (1 + x)f(y) = yf(x/y) - xf(y/x)$$
for all real $x, y \ne 0$, and which take the values $f(1) = 32$ and $f(-1) = -4$.

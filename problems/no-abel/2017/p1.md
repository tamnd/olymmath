(a) Find all functions $f : \mathbb{R} \to \mathbb{R}$ which satisfy
$$f(x)f(y) = f(xy) + xy$$
for all $x, y \in \mathbb{R}$.

(b) Find all functions $f : \mathbb{R} \to \mathbb{R}$ which satisfy
$$f(x)f(y) = f(x + y) + xy$$
for all $x, y \in \mathbb{R}$.

(a) Find all polynomials $P$ such that $P(x) + 3P(x + 2) = 3P(x + 1) + P(x + 3)$ for all real numbers $x$.

(b) Find all polynomials $P$ such that
$$\begin{aligned} &P(x) + \binom{2018}{2}P(x + 2) + \cdots + \binom{2018}{2016}P(x + 2016) + P(x + 2018) \\ &= \binom{2018}{1}P(x+1) + \binom{2018}{3}P(x+3) + \cdots + \binom{2018}{2015}P(x+2015) + \binom{2018}{2017}P(x+2017) \end{aligned}$$
for all real numbers $x$.

The binomial coefficients are given by $\dbinom{n}{k} = \dfrac{n!}{k!(n-k)!}$.

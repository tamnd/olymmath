(a) Show that for all $n \ge 3$ there are $n$ different positive integers $x_1, \ldots, x_n$ such that
$$\frac{1}{x_1} + \frac{1}{x_2} + \cdots + \frac{1}{x_n} = 1.$$

(b) If $a_1, \ldots, a_n, b_1, \ldots, b_n$ are real numbers satisfying $a_1^2 + \cdots + a_n^2 \le 1$ and $b_1^2 + \cdots + b_n^2 \le 1$, show that
$$\bigl(1 - (a_1^2 + \cdots + a_n^2)\bigr)\bigl(1 - (b_1^2 + \cdots + b_n^2)\bigr) \le \bigl(1 - (a_1b_1 + \cdots + a_nb_n)\bigr)^2.$$

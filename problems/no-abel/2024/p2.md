(a) Positive integers $a_0 < a_1 < \ldots < a_n$, are to be chosen so that $a_j - a_i$ is not a prime for any $i$, $j$ with $0 \le i < j \le n$. For each $n \ge 1$, determine the smallest possible value of $a_n$.

(b) Find all functions $f\colon \mathbb{R} \to \mathbb{R}$ satisfying
$$xf\bigl(f(x) + y\bigr) = f(xy) + x^2$$
for all $x, y \in \mathbb{R}$.

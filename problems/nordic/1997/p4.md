Let $f$ be a function defined in the set $\{0,1,2, \ldots\}$ of non-negative integers, satisfying $f(2 x)=2 f(x), f(4 x+1)=4 f(x)+3$, and $f(4 x-1)=2 f(2 x-1)-1$. Show that $f$ is an injection, i.e. if $f(x)=f(y)$, then $x=y$.

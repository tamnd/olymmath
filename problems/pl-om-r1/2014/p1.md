Wykazać, że jeśli liczby całkowite $a, b, c$ spełniają równanie

$$(a + 3)^2 + (b + 4)^2 - (c + 5)^2 = a^2 + b^2 - c^2,$$

to wspólna wartość obu stron jest kwadratem liczby całkowitej.

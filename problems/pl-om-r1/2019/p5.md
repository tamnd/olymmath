Wyznaczyć wszystkie szóstki $a_1,a_2,a_3,b_1,b_2,b_3$ liczb rzeczywistych o następującej własności: dla $i = 1,2,3$ liczby $a_{i + 1}$ i $b_{i + 1}$ są różnymi pierwiastkami równania $x^2 + a_ix + b_i = 0$, przy czym przyjmujemy $a_4 = a_1$ oraz $b_4 = b_1$.

Wszystkie liczby postaci $x^2 + y^2$, gdzie $x,y$ są względnie pierwszymi dodatnimi liczbami całkowitymi, ustawmy w ciąg rosnący $z_1 < z_2 < z_3 < \ldots$ Przykładowo:

$z_1 = 2 = 1^2 + 1^2,z_2 = 5 = 2^2 + 1^2,z_3 = 10 = 3^2 + 1^2,z_4 = 13 = 3^2 + 2^2,\ldots$ Dowieść, że istnieje nieskończenie wiele takich dodatnich liczb całkowitych $n$, że liczby $z_n,z_{n + 1},\ldots,z_{n + 2019}$ są nieparzyste.

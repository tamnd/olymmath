Dana jest liczba całkowita $n \geqslant 1$ oraz liczby rzeczywiste $x_1,x_2,\ldots,x_{2n + 1}$. Załóżmy, że $x_i + x_{i + 1} \geqslant 0$ dla każdego $i = 1,2,\ldots, 2n + 1$ (przyjmujemy $x_{2n + 2} = x_1$). Wykazać, że

$$|x_1| + |x_2| + \ldots + |x_{2n + 1}| \leqslant (2n + 1)(x_1 + x_2 + \ldots + x_{2n + 1}).$$

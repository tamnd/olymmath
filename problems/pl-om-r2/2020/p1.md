Załóżmy, że parami różne liczby rzeczywiste $a,b,c,d$ spełniają warunek $(a^2 + b^2 - 1)(a + b) = (b^2 + c^2 - 1)(b + c) = (c^2 + d^2 - 1)(c + d)$. Udowodnić, że $a + b + c + d = 0$.

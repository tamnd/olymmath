Dowieść, że jeżeli $a_1 < a_2 < \ldots < a_n$ i $b_1 < b_2 < \ldots < b_n$, gdzie $n \geq 2$, to
$$(a_1 + a_2 + \ldots + a_n)(b_1 + b_2 + \ldots + b_n) < n(a_1b_1 + a_2b_2 + \ldots + a_nb_n).$$

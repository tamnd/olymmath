Niech $a_1, a_2, ..., a_n, b_1, b_2, ..., b_n$ będą liczbami całkowitymi. Udowodnić, że

$$\sum_{1 \leq i < j \leq n} (|a_i - a_j| + |b_i - b_j|) \leq \sum_{1 \leq i,j \leq n} |a_i - b_j|\ .$$

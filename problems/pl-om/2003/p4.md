Dana jest liczba pierwsza $p$ oraz takie liczby całkowite $x$, $y$, $z$, że

$$0 < x < y < z < p.$$

Wykazać, że jeśli liczby $x^3$, $y^3$, $z^3$ dają takie same reszty przy dzieleniu przez $p$, to liczba $x^2 + y^2 + z^2$ jest podzielna przez $x + y + z$.

Dana jest liczba rzeczywista $c > -2$. Dowieść, że jeżeli liczby $x_1, x_2, \dots, x_n$ $(n \ge 2)$ są dodatnie oraz

$$\begin{aligned} &\sqrt{x_1^2 + c x_1 x_2 + x_2^2} + \sqrt{x_2^2 + c x_2 x_3 + x_3^2} + \dots + \sqrt{x_n^2 + c x_n x_1 + x_1^2} = \\ &\qquad = \sqrt{c+2}\,(x_1 + x_2 + \dots + x_n), \end{aligned}$$

to $c = 2$ lub $x_1 = x_2 = \dots = x_n$.

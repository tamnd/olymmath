Diz-se que um número inteiro positivo $n$ é BOM, se existe uma permutação dos inteiros de $1$ a $n$, $(a_1, a_2, \dots, a_n)$ tal que, para todo o $k$, $k + a_k$ é um quadrado perfeito. Por exemplo $5$ é um número BOM, uma vez que a permutação $(3, 2, 1, 5, 4)$ verifica a condição: $1 + 3 = 2^2$, $2 + 2 = 2^2$, $3 + 1 = 2^2$; $4 + 5 = 3^2$ e $5 + 4 = 3^2$.

Descobre todos os números BONS até $12$.

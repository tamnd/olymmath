Let there be $320$ points arranged on a circle, labled $1,2,3,\ldots,8,1,2,3,\ldots,8,\ldots$ in order. Line segments may only be drawn to connect points labelled with the same number. What thethe largest number of non-intersecting line segments one can draw? (Two segments sharing the same endpoint are considered to be intersecting).

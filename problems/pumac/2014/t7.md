Let us consider a function $f:N\to N$ for which $f(1)=1$, $f(2n)=f(n)$ and $f(2n+1)=f(2n)+1$. Find the number of values at which the maximum value of $f(n)$ is attained for integer $n$ satisfying $0<n<2014$.

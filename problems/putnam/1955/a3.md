3. Suppose that $ \sum_{i=1}^{\infty} x_{i} $ is a convergent series of positive terms which monotonically decrease (that is, $ x_{1} \geq x_{2} \geq x_{3} \geq \cdots $ ). Let $ P $ denote the set of all numbers which are sums of some (finite or infinite) subseries of $ \sum_{i=1}^{\infty} x_{i} $. Show that $ P $ is an interval if and only if
$$
x_{n} \leq \sum_{i=n+1}^{\infty} x_{i} \text { for every integer } n . \text { (page 403) }
$$

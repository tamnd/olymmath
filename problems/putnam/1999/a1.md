Find polynomials $f(x),g(x)$, and $h(x)$, if they exist, such that for all $x$,
$$
|f(x)| - |g(x)| + h(x) = \begin{cases}
-1 & \text{if } x < -1 \\
3x + 2 & \text{if } -1 \leq x \leq 0 \\
-2x + 2 & \text{if } x > 0.
\end{cases}
$$

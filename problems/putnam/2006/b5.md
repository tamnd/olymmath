For each continuous function $f : [0, 1] \to \mathbb{R}$, let $I(f) = \int_0^1 x^2 f(x) dx$ and $J(f) = \int_0^1 x (f(x))^2 dx$. Find the maximum value of $I(f) - J(f)$ over all such functions $f$.

Let $f: [0, 1] \to \mathbb{R}$ be a function for which there exists a constant $K > 0$ such that $|f(x) - f(y)| \leq K|x - y|$ for all $x, y \in [0, 1]$. Suppose also that for each rational number $r \in [0, 1]$, there exist integers $a$ and $b$ such that $f(r) = a + br$. Prove that there exist finitely many intervals $I_1, \ldots, I_n$ such that $f$ is a linear function on each $I_i$ and $[0, 1] = \bigcup_{i=1}^n I_i$.<|end_of_box|>

Considerăm un număr natural nenul $n$ şi funcţia
$$f : \mathbb{N} \to \mathbb{N},\ f(x) = \begin{cases} \dfrac{x}{2}, & \text{dacă } x \text{ este par} \\[2mm] \dfrac{x-1}{2} + 2^{n-1}, & \text{dacă } x \text{ este impar} \end{cases}.$$

Determinaţi mulţimea
$$A = \{x \in \mathbb{N} \mid (\underbrace{f \circ f \circ \ldots \circ f}_{\text{de } n \text{ ori } f})(x) = x\}.$$

Consider a nonzero integer number $n$ and the function $f:\mathbb{N}\to \mathbb{N}$ by
$$ f(x) = \begin{cases}
\frac{x}{2} & \text{if } x \text{ is even}
\frac{x-1}{2} + 2^{n-1} & \text{if } x \text{ is odd}
\end{cases}.
$$ Determine the set: $$
A = \{ x\in \mathbb{N} \mid \underbrace{\left( f\circ f\circ ....\circ f \right)}_{n\ f\text{'s}}\left( x \right)=x \}.
$$

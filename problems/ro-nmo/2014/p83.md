Se consideră mulţimea $A = \{n, n+1, n+2, \ldots, 2n\}$, unde $n \ge 4$ este un număr natural. Determinaţi cea mai mică valoare a lui $n$ pentru care $A$ conţine cinci elemente $a < b < c < d < e$ astfel încât
$$\frac{a}{c} = \frac{b}{d} = \frac{c}{e}.$$

<!-- S2 -->
Find the smallest integer $n$ for which the set $A = \{n, n +1, n +2,...,2n\}$ contains five elements $a<b<c<d<e$ so that $$ \frac{a}{c}=\frac{b}{d}=\frac{c}{e} $$

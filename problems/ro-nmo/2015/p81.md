Arătaţi că pentru orice numere reale $a, b, c > 0$ cu $a + b + c = 3$ are loc inegalitatea:
$$2(ab + bc + ca) - 3abc \ge a\sqrt{\frac{b^2 + c^2}{2}} + b\sqrt{\frac{c^2 + a^2}{2}} + c\sqrt{\frac{a^2 + b^2}{2}}.$$

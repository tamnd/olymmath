Dacă $a$, $b$ şi $c$ sunt lungimile laturilor unui triunghi, arătaţi că
$$\frac{3}{2} \le \frac{b + c}{b + c + 2a} + \frac{a + c}{a + c + 2b} + \frac{a + b}{a + b + 2c} < \frac{5}{3}.$$

If $a, b$ and $c$ are the length of the sides of a triangle, show that $$ \frac32 \le \frac{b + c}{b + c + 2a}+
\frac{a + c}{a + c + 2b}+
\frac{a + b}{a + b + 2c}\le \frac53. $$

Fie $f : [0, \infty) \longrightarrow \mathbb{R}$ o funcţie continuă, constantă pe $\mathbb{N}$. Dacă pentru orice numere reale $0 \le a < b < c < d$, pentru care $f(a) = f(c)$ şi $f(b) = f(d)$ are loc $f\left(\frac{a+b}{2}\right) = f\left(\frac{c+d}{2}\right)$, arătaţi că $f$ este constantă.

<!-- S2 -->
Let $f:[0, \infty) \to \mathbb{R}$ a continuous function, constant on $\mathbb{Z}_{\geq 0}.$ For any $0 \leq a < b < c < d$ which satisfy $f(a)=f(c)$ and $f(b)=f(d)$ we also have $f \left( \frac{a+b}{2} \right) = f \left( \frac{c+d}{2} \right).$
Prove that $f$ is constant.

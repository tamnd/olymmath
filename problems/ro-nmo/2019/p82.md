Arătaţi că dacă numerele $a, b, c \in (0, \infty)$ verifică relaţia $a + b + c = 3$, atunci:
$$\frac{a}{3a + bc + 12} + \frac{b}{3b + ca + 12} + \frac{c}{3c + ab + 12} \le \frac{3}{16}.$$

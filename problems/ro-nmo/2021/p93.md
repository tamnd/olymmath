Fie $a, b, c$ numere strict pozitive, astfel încât $a + b + c = 1$. Arătaţi că
$$\frac{1}{abc} + \frac{4}{a^2 + b^2 + c^2} \ge \frac{13}{ab + bc + ca}.$$

A table of dimensions $n \times n$, on whose fields the numbers $1,2, \ldots, n^{2}$ are placed (each field has exactly one number and each number is on exactly one field) is called a Nishka if the product of any $n$ "scattered" fields gives the same remainder when divided by $n^{2}+1$. Does a Nishka table exist for:

(a) $n=8$;

(b) $n=10$?

($n$ fields are "scattered" if no two are in the same row or the same column.)

(Marco Đikić)

An $n\times n$ table whose cells are numerated with numbers $1, 2,\cdots, n^2$ in some order is called Naissus if all products of $n$ numbers written in $n$ scattered cells give the same residue when divided by $n^2+1$. Does there exist a Naissus table for
$(a) n = 8;$
$(b) n = 10?$
($n$ cells are scattered if no two are in the same row or column.)

Let's call natural numbers similar if they are written using the same set of digits (for example, for the set of digits 1, 1, 2, similar numbers will be 112, 121, 211). Prove that there exist three similar 1995-digit numbers, in the notation of which there are no zeros, such that the sum of two of them is equal to the third.

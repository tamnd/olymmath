$\left\{a_{1}, a_{2}, \ldots, a_{20}\right\}$ - a set of positive integers.

We construct a new set of numbers $\left\{b_{0}, b_{1}, b_{2}, \ldots\right\}$ according to the following rule:

$b_{0}$ - the number of elements in the original set that are greater than 0,

$b_{1}$ - the number of elements in the original set that are greater than 1,

$b_{2}$ - the number of elements in the original set that are greater than 2,

and so on, until zeros start appearing. Prove that the sum of all numbers in the original set is equal to the sum of all numbers in the new set.

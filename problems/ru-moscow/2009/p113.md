On the plane, there are coordinate axes with the same but unmarked scale, and the graph of the function

$$
y=\sin x, x \in(0 ; \alpha)
$$

How can one construct a tangent to this graph at a given point using a compass and a ruler if: a) $\alpha \in\left(\frac{\pi}{2} ; \pi\right)$; b) $\alpha \in\left(0 ; \frac{\pi}{2}\right)$?

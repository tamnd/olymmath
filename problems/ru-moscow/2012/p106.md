Рассмотрим граф, у которого вершины соответствуют всевозможным трёхэлементным подмножествам множества $\{1, 2, 3, \ldots, 2^k\}$, а ребра проводятся между вершинами, которые соответствуют подмножествам, пересекающимся по ровно одному элементу. Найдите минимальное количество цветов, в которые можно раскрасить вершины графа так, чтобы любые две вершины, соединённые ребром, были разного цвета.

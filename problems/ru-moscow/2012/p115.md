Для $n = 1, 2, 3$ будем называть числом $n$-го типа любое число, которое либо равно 0, либо входит в бесконечную геометрическую прогрессию $1, (n + 2), (n + 2)^2, \ldots$, либо является суммой нескольких различных её членов. Докажите, что любое натуральное число можно представить в виде суммы числа первого типа, числа второго типа и числа третьего типа.

In the laboratory, 120 visually indistinguishable test tubes are standing on a shelf, 118 of which contain a neutral substance, one contains poison, and one contains an antidote. The test tubes have been randomly mixed, and it is necessary to find the test tube with the poison and the test tube with the antidote. For this purpose, the services of an external testing laboratory can be used, to which several mixtures of liquids from any number of test tubes (one drop from each test tube) can be sent simultaneously, and for each mixture, the laboratory will report the result: +1 if the mixture contains poison and no antidote; -1 if the mixture contains an antidote but no poison; 0 in all other cases. Is it possible, by preparing 19 such mixtures and sending them to the laboratory in a single shipment, to guarantee the determination of which test tube contains the poison and which contains the antidote based on the reported results?

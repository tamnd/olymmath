У барона Мюнхгаузена есть набор гирь $1000$ различных целых весов, по $2^{1000}$ гирь каждого веса. Барон утверждает, что если взять по одной гире каждого веса, то общий вес этих $1000$ гирь будет меньше $2^{1010}$, причём этот вес невозможно набрать гирями из этого набора другим способом. Могут ли слова барона оказаться правдой?

Let $\left (H_{\alpha} \right ) $ be a system of sets of integers having the property that for any $\alpha _1 \neq \alpha _2 , H_{\alpha _1}\cap H_{\alpha _2}$ is a finite set and $H_{{\alpha} _1} \neq H_{{\alpha} _2}$ . Prove that there exists a system $\left (H_{\alpha} \right )$ of this kind whose cardinality is that of the continuum. Prove further that if none of the intersections of two sets $H_\alpha$ contains more than $K$ elements, then the system $\left (H_{\alpha} \right ) $ is countable ( $K$ is an arbitrary fixed integer). **(St. 4)**

Let $a, b, c \in \mathbb{R}$ be such that $$ a + b + c = a^2 + b^2 + c^2 = 1, \hspace{8px} a^3 + b^3 + c^3 \neq 1. $$ We say that a function $f$ is a *Palić function* if $f: \mathbb{R} \rightarrow \mathbb{R}$ , $f$ is continuous and satisfies $$ f(x) + f(y) + f(z) = f(ax + by + cz) + f(bx + cy + az) + f(cx + ay + bz) $$ for all $x, y, z \in \mathbb{R}.$ Prove that any Palić function is infinitely many times differentiable and find all Palić functions.

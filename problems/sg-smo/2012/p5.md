There are $2012$ distinct points in the plane, each of which is to be coloured using one of $n$ colours, so that the numbers of points of each colour are distinct. A set of $n$ points is said to be *multi-coloured*if their colours are distinct. Determine $n$ that maximizes the number of multi-coloured sets.

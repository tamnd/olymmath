Nick and Moor participate in a typing challenge. When given the same document to type, Nick finishes typing it $5$ minutes before Moor is done. They compete again using a second document that is the same length as the first, but now Nick has to type an extra $1200$-word document in addition to the original. This time, they finish at the same time. How fast (in words per minute) does Nick type? (Assume that they both type at constant rates.)

We say that a set of positive integers $S$, all greater than $1$, *covers* an integer $x$ if for every pair of integers $k$ and $l$ such that $2\leq k<l\leq x$, we have $\left\lceil\frac{k}{y}\right\rceil\neq\left\lceil\frac{l}{y}\right\rceil$ for at least one integer $y$ in $S$. How many numbers are in the smallest set $S$ which covers $30$?

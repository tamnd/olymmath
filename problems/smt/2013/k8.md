The function $f(x)$ is defined for all $x\ge 0$ and is always nonnegative. It has the additional property that if any line is drawn from the origin with any positive slope $m$, it intersects the graph $y=f(x)$ at precisely one point, which is $\frac{1}{\sqrt{m}}$ units from the origin. Let $a$ be the unique real number for which $f$ takes on its maximum value at $x=a$ (you may assume that such an $a$ exists). Find $\displaystyle\int_0^a f(x)\,dx$.

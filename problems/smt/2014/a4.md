For any 4-tuple $(a_1,a_2,a_3,a_4)$ where each entry is either 0 or 1, call it *quadratically satisfiable* if there exist real numbers $x_1,\ldots,x_4$ such that $x_1x_2^2+x_2x_4+x_3=0$ and for each $i=1,\ldots,4$, $x_i$ is positive if $a_i=1$ and negative if $a_i=0$. Find the number of *quadratically satisfiable* 4-tuples.

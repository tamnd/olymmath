Call a function $g$ lower-approximating for $f$ on the interval $[a,b]$ if for all $x\in[a,b]$, $f(x)\geq g(x)$. Find the maximum possible value of $\int_1^2 g(x)\,dx$ where $g(x)$ is a linear lower-approximating function for $f(x)=x^x$ on $[1,2]$.

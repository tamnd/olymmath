Morris plays a game using a fair coin. He starts with $\$2$ and proceeds using the following rules:

- If Morris flips a heads, he gains $\$2$.
- If Morris flips a tails, he loses half his money.
- If Morris flips two tails in a row, the game ends (but he doesn’t lose any more money)

For instance, if Morris flips the sequence THTT, he will end up with $\$1.50$. What is the expected amount of money in dollars Morris will have after the game ends?

Let $f(x,y)=(\cos x+y\sin x)^2$. We may express $\max_x f(x,y)$, the maximum value of $f(x,y)$ over all values of $x$ for a given fixed value of $y$, as a function of $y$, call it $g(y)$. Let the smallest positive value $x$ which achieves this maximum value of $f(x,y)$ for a given $y$ be $h(y)$. Compute

$$
\int_{1}^{2+\sqrt{3}}\frac{h(y)}{g(y)}\,dy.
$$

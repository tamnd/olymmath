Frank is trying to sort his online friends into groups of sizes $n$ and $n+2$, for some unknown positive integer $n$, such that each friend is placed into exactly one group; there can be any number of groups of each of the two sizes. He finds that it is impossible to do so with his current number of friends, but would be possible if he had any *even* number of additional friends. If Frank has less than $400$ friends, what is the maximum possible number of friends he has currently?

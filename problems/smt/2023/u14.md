Suppose Bob randomly fills in a $45\times45$ grid with the numbers from $1$ to $2025$, using each number exactly once. For each of the $45$ rows, he writes down the largest number in the row. Of these $45$ numbers, he writes down the second largest number. The probability that this final number is equal to $2023$ can be expressed as $\frac{p}{q}$ where $p$ and $q$ are relatively prime positive integers. Compute the value of $p$.

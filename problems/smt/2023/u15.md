$f$ is a bijective function from the set $\{0,1,2,\cdots,11\}$ to $\{0,1,2,\cdots,11\}$, with the property that whenever $a$ divides $b$, $f(a)$ divides $f(b)$. How many such $f$ are there? *A bijective function maps each element in its domain to a distinct element in its range.*

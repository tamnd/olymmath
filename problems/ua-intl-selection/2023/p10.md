Нехай $a_0$ - деяке натуральне число. Визначимо нескінченну послідовність натуральних чисел $(a_n)$, де $n \in \mathbb{N}$, таким чином: нехай уже визначені для деякого натурального числа $n$ члени послідовності $a_0, a_1, \ldots, a_{n-1}$, то $a_n$ - це найменше натуральне число, для якого число $\sqrt[n]{a_0 a_1 \ldots a_n}$ є натуральним. Доведіть, що існують натуральні числа $k$ та $c$, для яких справджується умова $a_n = c$ для всіх натуральних чисел $n \geqslant k$.

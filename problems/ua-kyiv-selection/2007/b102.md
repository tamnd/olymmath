Задано деяку нескінченну монотонно зростаючу послідовність чисел: $1 = x_1 < x_2 < x_3 < \ldots < x_n < \ldots$, причому для будь-якого натурального $k$ $x_{k+1} \le 2k$. Довести, що кожне натуральне число $m$ можна подати у вигляді $m = x_i - x_j$, де $x_i, x_j$ -деякі члени послідовності.

Для додатних чисел $a, b, c$ таких, що $a + b + c = 3$, довести нерівність

$$\frac{a^3}{(a+b)(a+c)} + \frac{b^3}{(b+c)(b+a)} + \frac{c^3}{(c+a)(c+b)} \ge \frac{3}{4}.$$

Натуральні числа $a, b, c, d$ задовольняють умови:

$$a > b > c > d \text{та} (ac + bd) \vdots (a + b - c + d).$$

Довести, що для натурального $m$ та натурального непарного $n$ число $a^n b^m + c^m d^n$ не є простим числом.

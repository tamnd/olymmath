Визначте найбільшу підмножину $M \subseteq \mathbb{R}$ таку, що нерівність
$$\sqrt{ab} + \sqrt{cd} \geqslant \sqrt{a + b} + \sqrt{c + d}$$
справджується для всіх $a, b, c, d \in M$.
А чи справджуватиметься нерівність
$$\sqrt{ab} + \sqrt{cd} \geqslant \sqrt{a + c} + \sqrt{b + d}$$
для всіх $a$, $b$, $c$, $d$, що належать знайденій підмножині $M$?

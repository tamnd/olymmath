Для додатних чисел $a$, $b$, $c$, сума яких дорівнює $3$, доведіть нерівність
$$\frac{a^3 + 2}{b + 2} + \frac{b^3 + 2}{c + 2} + \frac{c^3 + 2}{a + 2} \geqslant 3.$$

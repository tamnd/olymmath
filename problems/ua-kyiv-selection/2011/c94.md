Нехай для функції $f : \mathbb{N} \to \mathbb{R}$ для кожного натурального числа $n$ та його простого дільника $p$ справджується рівність
$$f(n) = f\left(\frac{n}{p}\right) - f(p).$$

Відомо, що $f(2^{2007}) + f(3^{2008}) + f(5^{2009}) = 2006$.

Обчисліть значення $f(2007^2) + f(2008^3) + f(2009^5)$.

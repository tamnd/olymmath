Послідовність цілих чисел $a_0, a_1, a_2, \ldots$ задано такими співвідношеннями:
$$a_0 = 1; a_1 = 3; a_{n+1} = a_n + a_{n-1}, n \geqslant 1.$$
Знайдіть усі натуральні $n$, для яких
$$\text{НСД}(na_{n+1} + a_n, na_n + a_{n-1}) > 1.$$

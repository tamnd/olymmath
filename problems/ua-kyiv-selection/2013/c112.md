Послідовність натуральних чисел $(a_1, a_2, \ldots, a_k)$ назвемо універсальною для заданого натурального числа $n$, якщо з неї викреслюванням деяких її членів можна отримати довільну перестановку чисел $\{1, 2, \ldots, n\}$. Наприклад, для $n = 3$ послідовність $(1, 2, 3, 1, 2, 1, 3)$ - універсальна, а послідовність $(1, 2, 3, 2, 1, 3, 1)$ - ні, бо з неї неможливо отримати перестановку $(3, 1, 2)$. Позначимо $f(n)$ довжину найкоротшої універсальної послідовності. Доведіть, що
$$n^2 - n + 1 \geqslant f(n) \geqslant \frac{1}{2} n (n + 1).$$

Для набору чисел $a_1,\ a_2,\ \ldots,\ a_N$ позначимо через $S_n = a_1 + a_2 + \ldots + a_n$ для всіх $n = \overline{1, N}$. Відомо, що для будь-яких $k,\ m \in \mathbb{N}$ виконується рівність $\dfrac{S_m}{S_k} = \dfrac{m^2}{k^2}$. Доведіть, що для будь-яких $k,\ m \in \mathbb{N}$ справджується також відношення $\dfrac{a_m}{a_k} = \dfrac{2m - 1}{2k - 1}$.

Послідовність $(a_n)$, $n = 0, 1, 2, \ldots$, задана умовами $a_0 = 2$, $a_1 = 4$ та $a_{n+1} = \dfrac{1}{2}a_n a_{n-1} + a_n + a_{n-1}$ для всіх натуральних $n$. Знайдіть усі прості числа $p$, для яких існує натуральне $m$ таке, що $p$ ділить число $a_m - 1$.

Числа $(a_1, a_2, \ldots, a_{100})$ - перестановка чисел $(1, 2, \ldots, 100)$. Для кожної трійки $(a_i, a_{i+1}, a_{i+2})$, $1 \leqslant i \leqslant 98$, сусідніх значень середнє за величиною число трійки зафарбовано жовтим. Наприклад, для трійки $(a_i = 7, a_{i+1} = 98, a_{i+2} = 22)$ зафарбовано число $a_{i+2} = 22$. Якого найменшого значення може набувати сума $S$ усіх жовтих чисел?

*Примітка.* Число, яке є жовтим для двох або більше трійок чисел, ураховувати в сумі один раз.

Натуральне число $d$ називають *$k$-кратним дільником* числа $N$, якщо для деякого натурального числа $q$, що не кратне $d$, справджується рівність $N = d^k q$. Знайдіть таке число $n$, для якого число $2^n$ має $1993$ різних $1994$-кратних дільники.

Послідовність цілих чисел $g(n)$, $n = 0, 1, 2, \ldots$ задається такими умовами:
$$g(0) = 0, g(n) = n - g(g(n-1)), n = 1, 2, \ldots$$
Доведіть, що:

а) для кожного натурального $k$ справджується нерівність $g(k) \geqslant g(k-1)$;

б) не існує такого натурального $k$, для якого $g(k+1) = g(k) = g(k-1)$.

Для додатних чисел $a, b, c$, таких що $abc = 1$, довести нерівність:
$$\frac{a^2 + b^2}{c^2 + a + b} + \frac{b^2 + c^2}{a^2 + b + c} + \frac{c^2 + a^2}{b^2 + c + a} \ge 2.$$

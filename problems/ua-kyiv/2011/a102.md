Відомо, що $x_1$, $x_2$, $x_3$ - попарно різні дійсні числа.

а) Числа $x_2$, $x_3$ є нулями функції $f_1(x) = x^2 + p_1x + q_1$; числа $x_3$, $x_1$ є нулями функції $f_2(x) = x^2 + p_2x + q_2$; числа $x_1$, $x_2$ є нулями функції $f_3(x) = x^2 + p_3x + q_3$. Чи обов'язково функція $f(x) = f_1(x) + f_2(x) + f_3(x)$ має нулі?

б) Числа $x_2$, $x_3$ є нулями функції $f_1(x) = a_1x^2 + b_1x + c_1$; числа $x_3$, $x_1$ є нулями функції $f_2(x) = a_2x^2 + b_2x + c_2$; числа $x_1$, $x_2$ є нулями функції $f_3(x) = a_3x^2 + b_3x + c_3$. Чи обов'язково функція $f(x) = f_1(x) + f_2(x) + f_3(x)$ має нулі?

Для додатних чисел $a$, $b$, $c$ доведіть нерівність
$$(a + 1)^2 + (b + 1)^2 + (c + 1)^2 \geqslant 3\left(1 + a\sqrt[3]{b} + b\sqrt[3]{c} + c\sqrt[3]{a}\right).$$

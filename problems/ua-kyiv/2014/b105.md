Нехай $p > 3$ - просте число. Відомо, що числа $a + b + c + d$ та $a^3 + b^3 + c^3 + d^3$ діляться на $p$ для деяких натуральних чисел $a$, $b$, $c$, $d$. Доведіть, що число $a^n + b^n + c^n + d^n$ ділиться на $p$ для довільного непарного $n$.

Для додатних чисел $x, y, z$ доведіть нерівність
$$2\left(\frac{x}{2x + y}\right)^2 + 2\left(\frac{y}{2y + z}\right)^2 + 2\left(\frac{z}{2z + x}\right)^2 + \frac{9xyz}{(2x + y)(2y + z)(2z + x)} \leqslant 1.$$

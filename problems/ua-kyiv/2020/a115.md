Для додатних чисел $a$, $b$, $c$, що задовольняють умову $a^2 + b^2 + c^2 + abc = 4$, доведіть нерівність
$$(4 - a^2)(4 - b^2)(4 - c^2) a^2b^2c^2 \leqslant (2a + bc)(2b + ca)(2c + ab).$$

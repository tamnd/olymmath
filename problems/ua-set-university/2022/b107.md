Для послідовності натуральних чисел $(a_n)$, $\forall n \in \mathbb{N}$, справджуються умови:

$$a_n + a_{2n} = a_{3n}, a_n + a_{3n-1} = a_{2n} + a_{2n-1}, a_n + a_{3n+1} = a_{2n} + a_{2n+1}.$$

Відомо, що числа $a_1, a_{14}, a_{17}$ та $a_{21}$ є простими. Знайдіть такий індекс $k$, для якого $a_{2024} = a_k$.

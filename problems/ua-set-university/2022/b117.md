Знайдіть усі функції $f: \mathbb{Z} \to \mathbb{Z}$, для яких при довільних цілих $m$, $n$ справджується рівність

$$f(m - n + f(n)) = f(m) + f(n).$$

У відповіді запишіть найбільше можливе значення, якого може набувати $f(2022)$ для знайдених функцій.

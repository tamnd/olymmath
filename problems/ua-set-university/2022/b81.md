Для кожної пари натуральних чисел $a$, $b$ визначено операцію $a \oplus b$ з такими властивостями:

1) $a \oplus a = a + 2$;
2) $a \oplus b = b \oplus a$;
3) $\dfrac{a \oplus (a + b)}{a \oplus b} = \dfrac{a + b}{b}$.

Знайдіть значення виразу $3 \oplus 5$.

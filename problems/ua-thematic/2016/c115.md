Нехай $S$ - множина всіх трійок цілих невід'ємних чисел. Про функцію $f:S\to\mathbb{Z}^+$ відомо, що:

1) для будь-яких $a, b \in \mathbb{Z}^+$

$$f(a,b,0)=f(a,0,b)=f(0,a,b)=\begin{cases} a!, & \text{якщо } a=b, \\ 0, & \text{якщо } a\ne b; \end{cases}$$

2) для будь-яких $a, b, c \in \mathbb{Z}^+$

$$f(a,b,c)=b\cdot f(a-1,b-1,c)+c\cdot f(a-1,b,c-1).$$

Доведіть, що $f(a,b,c)=f(b,a,c)$ для будь-яких $a, b, c \in \mathbb{Z}^+$.

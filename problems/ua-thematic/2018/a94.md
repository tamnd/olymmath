Для додатних чисел $a, b, c < \dfrac{1}{2}$, що задовольняють умову $a + b + c = 1$, та для довільних дійсних чисел $x, y, z$ доведіть нерівність
$$abc(x+y+z)^2 \geqslant ayz(1-2a) + bxz(1-2b) + cxy(1-2c).$$

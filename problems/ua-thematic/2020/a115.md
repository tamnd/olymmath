Розглянемо таке твердження: якщо додатні числа $x_1, x_2, \ldots, x_n$, $n \geqslant 3$, задовольняють умову $x_1 + x_2 + \ldots + x_n = n$, то
$$\frac{x_2}{\sqrt{x_1 + 2x_3}} + \frac{x_3}{\sqrt{x_2 + 2x_4}} + \ldots + \frac{x_n}{\sqrt{x_{n-1} + 2x_1}} + \frac{x_1}{\sqrt{x_n + 2x_2}} \geqslant \frac{n}{\sqrt{3}}.$$
Для яких $n$ це твердження обов'язково справджується?

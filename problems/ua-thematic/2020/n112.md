Для натуральних чисел $a$, $b$, $c$, у яких $(a, b, c) = 1$, позначимо через $g(a, b, c)$ найбільше натуральне число, яке не можна подати у вигляді суми $ax + by + cz$, де $x$, $y$, $z$ - довільні натуральні числа. Доведіть, що $g(a, b, c) \geqslant \sqrt{2abc}$.

*Примітка.* Тут через $(a, b, c)$ позначено НСД чисел $a$, $b$, $c$.

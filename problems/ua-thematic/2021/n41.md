Групу дітей вишикували в шеренгу. Спочатку їх попросили розрахуватися на "перший-другий", тобто по черзі зліва направо сказати "$1, 2, 1, 2, 1, 2, \ldots$". Після цього їх попросили розрахуватися на "перший-другий-третій", тобто по черзі зліва направо сказати "$1, 2, 3, 1, 2, 3, 1, 2, 3, \ldots$". Скільки щонайбільше дітей було в цій групі, якщо рівно $10$ дітей під час обох розрахунків сказали "$2$"?

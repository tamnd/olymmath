Дано відмінні від нуля дійсні числа $a$, $b$, $c$, для яких $a^2 = c^3 - c^2 + cb^2$, $b^2 = a^3 - a^2 + ac^2$, $c^2 = b^3 - b^2 + ba^2$. Доведіть, що
$$\frac{a^2 + b^2}{2a^5 + 2b^5 + a^2 + b^2} + \frac{b^2 + c^2}{2b^5 + 2c^5 + b^2 + c^2} + \frac{c^2 + a^2}{2c^5 + 2a^5 + c^2 + a^2} \le 1.$$

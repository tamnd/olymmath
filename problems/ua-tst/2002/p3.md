Знайдіть усі натуральні $n \ge 2$ та - для таких $n$ - усі такі відповідні набори натуральних чисел $a_1, a_2, \ldots, a_n$, що
$$\frac{99}{100} = \frac{a_0}{a_1} + \frac{a_1}{a_2} + \ldots + \frac{a_{n-1}}{a_n},$$
де $a_0 = 1$ та $\left(a_{k+1} - 1\right) a_{k-1} \ge a_k^2 \left(a_k - 1\right)$ для $k = 1, 2, \ldots, n - 1$.

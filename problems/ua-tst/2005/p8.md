Нехай $x$, $y$ і $z$ - додатні дійсні числа. Доведіть нерівність
$$\frac{xy}{x^2 + xy + yz} + \frac{yz}{y^2 + yz + zx} + \frac{zx}{z^2 + zx + xy} \ge \frac{x}{z + 2x} + \frac{y}{x + 2y} + \frac{z}{y + 2z}.$$

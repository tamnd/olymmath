Послідовність натуральних чисел $a_1 < a_2 < a_3 < \ldots$ задовольняє умову: для кожного натурального $k$ число $a_{k+1}$ ділить вираз $2(a_1 + a_2 + \ldots + a_k)$. Припустимо, що існує нескінченно багато простих чисел $p$, для яких існує такий індекс $k$, що $a_k \vdots p$. Доведіть, що для довільного натурального $n$ існує такий індекс $k$, що $a_k \vdots n$.

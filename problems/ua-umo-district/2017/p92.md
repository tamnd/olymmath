Відомо, що квадратні рівняння $x^2 + a_1 x + b_1 = 0$, $x^2 + a_2 x + b_2 = 0$ та $x^2 + a_3 x + b_3 = 0$ мають відповідно корені $\{x_0, x_1\}$, $\{x_0, x_2\}$ та $\{x_0, x_3\}$. Визначте корені рівняння $3x^2 + (a_1 + a_2 + a_3)x + (b_1 + b_2 + b_3) = 0$ через значення $x_0, x_1, x_2, x_3$.

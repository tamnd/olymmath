Нехай $n$ - деяке натуральне число. Розглянемо послідовності чисел $a_0, a_1, \ldots, a_k$ та $b_0, b_1, \ldots, b_k$, що задовольняють такі умови: $a_0 = b_0 = 1$, $a_k = b_k = n$, для кожного $i$ від $1$ до $k$ пара чисел $(a_i, b_i)$ дорівнює або парі $\left(1 + a_{i-1}, b_{i-1}\right)$, або парі $\left(a_{i-1}, 1 + b_{i-1}\right)$.

Розглянемо для кожного $i$ від $1$ до $k$ послідовність

$$c_i = \begin{cases} a_i, \text{ якщо } a_i = a_{i-1}; \\ b_i, \text{ якщо } b_i = b_{i-1}. \end{cases}$$

Чому дорівнює сума $c_1 + c_2 + \ldots + c_k$?

У відповіді запишіть значення виразу при $n = 100$.

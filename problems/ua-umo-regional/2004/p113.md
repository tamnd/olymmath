Відомо, що $\frac{\cos x + \cos y + \cos z}{\cos\left(x + y + z\right)} = \frac{\sin x + \sin y + \sin z}{\sin\left(x + y + z\right)} = a$. Доведіть, що $\cos\left(x + y\right) + \cos\left(y + z\right) + \cos\left(z + x\right) = a$.

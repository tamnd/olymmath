Нехай $a, b, c$ та $\alpha, \beta, \gamma$ - додатні дійсні числа такі, що $\alpha + \beta + \gamma = 1$. Доведіть, що $$\alpha a + \beta b + \gamma c + 2\sqrt{(\alpha\beta + \beta\gamma + \gamma\alpha)(ab + bc + ca)} \le a + b + c.$$

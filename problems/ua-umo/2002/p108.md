Знайдіть найбільше значення $K$, для якого нерівність $$\dfrac{1}{(x + y + z)^2} + \dfrac{1}{x^2} + \dfrac{1}{y^2} + \dfrac{1}{z^2} \ge \dfrac{K}{\sqrt{(x + y + z)xyz}}$$ виконується для всіх додатних дійсних чисел $x, y, z$.

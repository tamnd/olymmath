Розв'яжіть систему рівнянь $$\begin{cases} \operatorname{tg} x + \sin y + \sin z = 3x, \\ \sin x + \operatorname{tg} y + \sin z = 3y, \\ \sin x + \sin y + \operatorname{tg} z = 3z, \end{cases}$$ якщо $0 \le x < \frac{\pi}{2}$, $0 \le y < \frac{\pi}{2}$, $0 \le z < \frac{\pi}{2}$.

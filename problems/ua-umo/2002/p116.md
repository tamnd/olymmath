Нехай $(a_1; a_2; \ldots; a_{10})$, $(b_1; b_2; \ldots; b_{10})$, $(c_1; c_2; \ldots; c_{10})$, $(d_1; d_2; \ldots; d_{10})$ - чотири перестановки чисел $1, 2, \ldots, 10$.

*а)* Чи може статися так, що $$a_1 b_1 + a_2 b_2 + \ldots + a_{10} b_{10} = 2\left(c_1 d_1 + c_2 d_2 + \ldots + c_{10} d_{10}\right)?$$

*б)* Чи може статися так, що $$45\left(a_1 b_1 + a_2 b_2 + \ldots + a_{10} b_{10}\right) = 76\left(c_1 d_1 + c_2 d_2 + \ldots + c_{10} d_{10}\right)?$$

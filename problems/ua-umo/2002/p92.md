Для додатних дійсних чисел $x, y, z$ доведіть нерівність $$\dfrac{x^3 + y^3}{x^2 + y^2} + \dfrac{y^3 + z^3}{y^2 + z^2} + \dfrac{z^3 + x^3}{z^2 + x^2} \ge x + y + z.$$

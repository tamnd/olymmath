Доведіть, що для будь-яких додатних чисел $a$, $b$, $c$ виконується нерівність $$\frac{a^2 + b^2}{c^2 + ab} + \frac{b^2 + c^2}{a^2 + bc} + \frac{c^2 + a^2}{b^2 + ca} \ge 3.$$

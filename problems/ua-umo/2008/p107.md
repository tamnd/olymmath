Для довільних додатних чисел $a, b, c$ довести нерівність:

$$\frac{a^2}{bc(a^2 + b^2)} + \frac{b^2}{ca(b^2 + c^2)} + \frac{c^2}{ab(c^2 + a^2)} \ge \frac{9}{2},$$

якщо вони задовольняють умову:

**а)** $a^2 + b^2 + c^2 = 1$;

**б)** $ab + bc + ca = 1$.

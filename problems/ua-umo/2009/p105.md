Попарно різні дійсні числа $a, b, c$ задовольняють умову
$$a + \frac{1}{b} = b + \frac{1}{c} = c + \frac{1}{a}.$$
Знайдіть, яких значень може набувати добуток $abc$:

**а)** для довільних дійсних $a, b, c$;

**б)** для додатних дійсних $a, b, c$?

Нехай $x$, $y$, $z$ - додатні дійсні числа такі, що $xyz = 1$. Доведіть нерівність
$$(-x + y + z)(x - y + z) + (x - y + z)(x + y - z) + (x + y - z)(-x + y + z) \leqslant 3.$$

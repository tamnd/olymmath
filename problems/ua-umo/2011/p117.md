Доведіть, що для довільних дійсних чисел $a$, $b$ і $c$, менших від $1$ і таких, що
$$2(a + b + c) + 4abc = 3(ab + bc + ca) + 1,$$
виконується нерівність $a + b + c \leqslant \dfrac{3}{4}$.

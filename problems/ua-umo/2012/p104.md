Нехай $n \geqslant 3$ - задане натуральне число. Послідовність із $2n$ чисел $a_1$, $a_2$, $\ldots$, $a_{2n}$ будемо називати *вдалою*, якщо виконуються такі три умови:

1) усі числа $a_1$, $a_2$, $\ldots$, $a_n$ є попарно різними елементами множини $\{1; 2; \ldots; n\}$;

2) $a_k = a_{n+k}$ для всіх $k = \overline{1, n}$;

3) існують такі $i_1 < i_2 < \ldots < i_n$ із множини $\{1; 2; \ldots; 2n\}$, що $a_{i_k} = k$ для всіх $k = \overline{1, n}$.

Наприклад, для $n = 5$ послідовність $1, 3, 4, 2, 5, 1, 3, 4, 2, 5$ є вдалою, а послідовність $2, 1, 3, 5, 4, 2, 1, 3, 5, 4$ - ні. Для кожного $n \geqslant 3$ знайдіть кількість вдалих послідовностей.

Для додатних чисел $a$, $b$, $c$, що задовольняють умову $a + b + c + 2 = abc$, доведіть нерівність $\dfrac{a}{b+1}+\dfrac{b}{c+1}+\dfrac{c}{a+1} \geqslant 2$.

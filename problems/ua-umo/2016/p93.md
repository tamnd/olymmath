Для додатних чисел $x_1, x_2, \ldots, x_n$, що задовольняють умову
$$x_1^{n-1} + x_2^{n-1} + \ldots + x_n^{n-1} = x_1 x_2 \ldots x_n,$$
доведіть нерівність
$$(x_1 - n + 1)(x_2 - n + 1) \ldots (x_n - n + 1) \geqslant 1.$$

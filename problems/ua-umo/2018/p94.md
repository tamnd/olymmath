Дільники складеного натурального числа $n$, яке не є квадратом простого числа, позначимо в порядку зростання таким чином: $1 < d_1 < d_2 < \ldots < d_{l-1} < d_l < n$, $l \geqslant 2$. Для яких $n$ існують натуральні числа $a$, $b$ та $N$, що задовольняють умови $d_1 + d_2 = N^a$ та $d_{l-1} + d_l = N^b$?

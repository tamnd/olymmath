Для довільного натурального $n \geqslant 3$ знайдіть такі цілі числа $a_1 < a_2 < \ldots < a_n$, для яких справджується рівність

$$\frac{a_1}{a_1} + \frac{a_1}{a_2} + \frac{a_1}{a_3} + \ldots + \frac{a_1}{a_n} = \frac{a_2}{a_1} + \frac{a_2}{a_2} + \frac{a_2}{a_3} + \ldots + \frac{a_2}{a_n}.$$

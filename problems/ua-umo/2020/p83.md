а) Відомо, що для ненульових цілих чисел $a$, $b$, $c$ справджується умова $\frac{a^2}{b}+\frac{b^2}{c}+\frac{c^2}{a}=\frac{a^2}{c}+\frac{c^2}{b}+\frac{b^2}{a}$. Чи обов'язково має справджуватися рівність $\frac{a}{b}+\frac{b}{c}+\frac{c}{a}=\frac{a}{c}+\frac{c}{b}+\frac{b}{a}$?

б) Розглянемо всі трійки ненульових цілих чисел $(a, b, c)$, кожне з яких знаходиться в межах від $-2020$ до $2020$ включно. З'ясуйте, для скількох із них умови $a + b + c = 0$ та $\frac{a^2}{b}+\frac{b^2}{c}+\frac{c^2}{a}=\frac{a^2}{c}+\frac{c^2}{b}+\frac{b^2}{a}$ рівносильні, тобто для скількох таких трійок чисел $(a, b, c)$ ці твердження справджуються чи не справджуються одночасно.

Let $A B C D$ be a cyclic quadrilateral. Prove that there exists a point $X$ on segment $\overline{B D}$ such that $\angle B A C=\angle X A D$ and $\angle B C A=\angle X C D$ if and only if there exists a point $Y$ on segment $\overline{A C}$ such that $\angle C B D=\angle Y B A$ and $\angle C D B=\angle Y D A$.
